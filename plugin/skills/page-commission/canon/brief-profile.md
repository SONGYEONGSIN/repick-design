# 타입 프로파일 — `profile` (개인·주체 프로필 페이지)

> 전 타입 공통 규칙은 [[page-brief-core]]. 이 문서는 프로필 페이지 고유 기준만 정의한다.
> 초안 출처: `auto-profile-r1`·`r2` 두 라운드의 판정. 이 타입은 **한 주체를 신뢰할 수 있는지 판단시키는** 화면이다 — [[brief-product-detail]]이 물건을, 이쪽은 사람(또는 팀·전략)을 다룬다.

## 0. 상품 상세 기준과의 관계

| brief-product-detail 요구 | 프로필에서 |
|---|---|
| 가격+CTA 이중 상시노출 | **신뢰 통계**가 그 자리를 차지한다 — §2 참조 |
| 변형 선택기가 가격·스펙 재계산 | **전역 토글**(기간·베이스라인·상태)이 통계·차트·목록을 재계산 |
| 시각 자료가 변형을 반영 | 활동 시각화(히트맵·추이)가 선택 구간을 반영 |
| 전체 스펙 첫 섹션 사전 오픈 | 대표 산출물 목록이 클릭 없이 보인다 |

## 1. 페이지 구조 (필수 요소)

1. **정체 블록** — 이름·핸들·한 줄 소개·검증 배지. 아바타는 생성형(해시 시드)이면 충분하다
2. **신뢰/도달 통계** — 이 주체를 판단할 수치 묶음(팔로워·설치수·평점·활동 기간·수익률 등). §2의 하드 기준 대상
3. **활동 시각화** — 기여 히트맵·월별 추이 등. 기간 토글이 있으면 이것도 함께 재계산된다
4. **산출물 목록** — 발행물·연동·전략 등 이 주체가 만든 것. 정렬·필터 가능
5. **소개 본문** — 통계가 답하지 못하는 맥락
6. **행동 유도** — 팔로우·복사·문의 중 하나. 통계 근처에 둔다

## 2. 이 타입의 핵심 판정 기준

- **신뢰 통계의 고정 상시노출 (하드)** — 핵심 신뢰/도달 통계(`dl` 클러스터)는 **사이드바나 히어로에 고정해 전 스크롤 깊이·전 상태에서 보여야** 하고, 탭이나 클릭 뒤에 두면 안 된다.
  근거: `auto-profile-r1`에서 이 기준이 3렌즈 중 2렌즈(준수·상용완성도)의 승자 판정 근거였고, `r2`에서 3후보 **전원이 준수**했다(a=sticky identity bar, b=sticky scoreboard band, c=sticky identity bar). 렌즈1이 32프레임 전수 검사로 전원 준수를 확인 — 위반 사례 0.
  > 재현의 성격에 주의: 이 delta는 "위반이 재발해서"가 아니라 **"패턴이 유지돼서"** 승격됐다. 다른 타입의 L2들(가격+CTA 이중노출, 단일 계산 상태 공유)은 r2에서 위반한 후보가 감점되며 재현됐다. 전원 준수가 규칙의 자명함을 뜻하는지 강함을 뜻하는지는 다음 라운드가 판단할 몫이다.
- **전역 토글 → 이질적 산출물 동시 재계산** — 소수의 전역 토글(기간·베이스라인·상태)이 **단일 데이터소스에서 파생된 여러 표현형**(통계쌍·차트·테이블·목록)을 동시에 다시 계산해야 한다. 후보 단위의 지역 상태가 아니라 **페이지 전역의 공유 상태**다.
  근거: `auto-profile-r2`에서 완성도(렌즈2)와 아키타입 차별성(렌즈3) 두 렌즈가 동시에 만족된 유일한 구조였다. 필터→단일 그리드 재정렬(catalog 이식)이나 탭 전환(스토어프론트 이식)보다 이 조합이 신규성과 상용 완성도를 함께 얻었다.
- **주체의 종류를 좁게 잡을 것** — "개발자 프로필"은 GitHub 이식으로 수렴하기 쉽다. 트레이딩 전략·감사관·프리랜서처럼 **판단 기준이 다른 주체**를 잡으면 통계 묶음 자체가 달라진다

## 3. 레이아웃 아키타입 (라운드 내 중복 금지)

- **좌 정체 사이드바 + 우 활동/산출물** — 고전적 프로필
- **상단 sticky 스코어보드 밴드 + 본문** — 통계가 가로 밴드로 상주
- **케이스로그 스파인** — 시간순 사례 기록이 페이지의 축
- **케이스스터디 그리드** — 산출물이 카드 그리드로 주인공

## 4. 인터랙션 (최소 3종)

기간 토글 → 시각화·통계 재계산 · 베이스라인/비교 대상 전환 · 산출물 정렬·필터 · 상태 필터(검증/베타/커뮤니티) · 산출물 선택 → 상세 중 **3개 이상**. 전부 `'use client'` 실동작 + 결정론 + `motion-reduce` 게이팅.

## 5. 스크롤 연동 연출
