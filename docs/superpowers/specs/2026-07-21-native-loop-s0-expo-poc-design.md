## 1. 확정된 결정

| 결정 | 선택 | 근거 |
|---|---|---|
| 첫 네이티브 스택 | **React Native / Expo** | 루프 React 역량 재사용, JS/npm 툴체인, Expo Web 미리보기 |

## 2. 핵심 통찰 — Mac/시뮬레이터 벽 우회

Expo Web(`react-native-web`)은 RN 컴포넌트를 **시뮬레이터 없이 브라우저에 렌더**한다. 따라서 S0의 세 단계 — 생성·타입체크·Expo Web 미리보기 — 는 **전부 Node 환경만 요구하며 Mac에 묶이지 않는다**(클라우드 Linux 샌드박스에서도 동일 실행). Mac이 필수인 단계(iOS 시뮬레이터/실기기 렌더·빌드)는 **S0 비범위**다. 이 성질이 "클라우드에서 네이티브 불가" 벽을 Expo Web 한정으로 무력화한다 — S0 성공 시 네이티브(Expo) 라운드도 클라우드 무인으로 열린다.

**단계별 Mac 의존성**
| 단계 | Mac 필수 | S0 포함 |
|---|:--:|:--:|
| 생성(RN/TS 코드) | ✗ | ✅ |
| 타입체크(tsc) | ✗ | ✅ |
| Expo Web 미리보기(expo start --web) | ✗ | ✅ |
| iOS 시뮬레이터 렌더 | ✓ | ✗(비범위) |
| iOS 실기기 빌드(.ipa) | ✓ | ✗(비범위) |

## 3. 아키텍처

- **별도 Expo 워크스페이스 신설**: 레포 루트에 `native/`(기존 `app/` Next.js와 분리 — 툴체인·의존성 충돌 방지). Expo는 순수 npm 패키지, Xcode 불필요.
- **PoC 화면 1개**: repick DNA 토큰(near-monochrome·단일 액센트·순백 라이트)을 쓴 최소 RN 스크린 — 웹 코드를 옮긴 게 아니라 RN 관용구(`View`/`Text`/`Pressable`/`StyleSheet` 또는 NativeWind)로 새로 작성. 소재는 repick 도메인(예: AI 매칭 결과 카드 리스트).
- **미리보기 경로**: `expo start --web` → `react-native-web` 웹 번들 → localhost URL → 이 URL을 iframe으로 로드(기존 gallery WorkCard의 iframe 미리보기 경로가 네이티브 타깃에도 성립함을 실증).

## 4. S0 검증 (성공 기준 = 실현성 게이트)

1. **툴체인**: Expo 프로젝트 생성·의존성 설치 성공 (npm only, Xcode 무관). `native/`에서 `npm install` 클린.
2. **타입체크**: `cd native && npx tsc --noEmit` 클린 (RN 화면의 컴파일 게이트 — 웹 static-check 대응).
3. **Expo Web 서빙**: `expo start --web`(또는 `expo export -p web` 정적 서빙)가 PoC 화면을 HTTP 200으로 서빙 + 스크린샷에 실제 렌더 확인(빈 화면 아님 — 텍스트·카드 보임).
4. **iframe 미리보기**: 그 Expo Web URL을 iframe으로 로드 성공(갤러리 미리보기 경로가 네이티브에 성립).
5. **재현 절차 문서화**: 위 1~4를 반복 실행하는 절차를 `native/README.md`(또는 스킬 노트)로 남김 — S1(자동 생성)의 입력.

**클라우드 병행 확인(선택, S0 여력 시)**: 위 2·3이 Node만으로 도는지 확인(Mac 특이 의존 없음) — S4의 "네이티브 클라우드 무인 가능" 근거.

## 6. 리스크와 중단 조건

- **중단 조건**: 검증 4단계 중 하나라도 근본적으로 불가하면(예: react-native-web가 이 Node/의존성에서 안 뜸) S0를 실패로 선언하고 **스택 재선택**(Flutter web 등)으로 방향 전환 — 이게 S0를 첫 조각으로 둔 이유.
- react-native-web 렌더 차이: 일부 RN 컴포넌트는 웹에서 미묘하게 다르게 렌더될 수 있음 — S0 PoC는 기본 컴포넌트만 써 이 리스크 회피.
- 의존성 무게: Expo가 `app/node_modules`와 별개로 `native/node_modules`를 가짐 — 디스크·설치시간 증가하나 격리가 이득.
