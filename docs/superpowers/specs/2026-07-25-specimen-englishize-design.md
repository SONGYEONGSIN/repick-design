## 3. 작품별 절차 (동일 적용)

1. 타깃 tsx/ts 전수에서 한글 식별.
2. **렌더 UI 텍스트** → 자연스러운 영문: 라벨·헤딩·버튼·배지·빈상태·**sr-only 접근성 문구**·caption·`aria-label`·데이터 라벨(차트/테이블/목록의 표시 문자열).
3. **코드 주석**(`//`, `/* */`, JSDoc) → 영문.
4. **로직 보존**: 한글 문자열이 객체 키·React `key`·`switch`/비교·Map 키·조건 분기에 쓰이면 **전 사용처를 일관 번역**해 동작 불변. (표시용과 로직용이 같은 문자열이면 함께 바꾼다.)
5. **디자인 불변**: 색·간격·레이아웃·구조·**수치 데이터**(값)·클래스 변경 금지 — **언어만**.
6. **결정론 유지**: `Date.now()`/`Math.random()`/`new Date()` 도입 금지.
7. **자가 검증**: `grep -P '[가-힣]' <타깃>` = 0 (한글 잔존 0).

- **Phase 1 (Translate, 병렬)**: 14 에이전트, 각 1작품 §3 절차 수행(공유 트리에서 분리 파일 편집). 작품당 self-check(grep=0) + 결과 리포트(변경 파일 수·잔존 한글·로직키 번역·레이아웃 위험 문자열).
- **Phase 2 (컨트롤러 검증, 워크플로우 후)**:
