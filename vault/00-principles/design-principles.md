# Design Principles — repick 랜딩 (v0)

> 이 문서가 "현재의 우리 디자인 DNA"다. LEARN 단계가 여기를 surgical하게 갱신한다.

## Voice / Tone
- 한 줄로: 신뢰감 있는 미니멀 — 과장 없이 정보 위계로 승부
- 방향성(1회차 C 승리): **에디토리얼 타이포 위계 우선** — 색은 near-monochrome(무채색 위계 + accent 극소량)로 절제하고, 크기·굵기·자간으로 리듬을 만든다. 그라데이션 장식보다 타이포 스케일 대비로 임팩트를 낸다.
- 방향성 보강(R2 a 승리): Hero는 **비대칭 좌측정렬 + clamp 초대형 스케일 대비**가 중앙정렬보다 강하다. accent 확장 시도(R2 b)는 그라데이션 남발·near-mono 이탈로 감점 — **accent는 극소량 고정**.
- 방향성 보강(R3 a 승리): **에디토리얼 밀도**(12-col 비대칭 그리드 + ghost 넘버 + Fig 캡션 + quote mark)가 여백만 극대화보다 강하다. 라인아트/브래킷 장식은 블루프린트 감으로 감점. accent는 극소량이되 **정지 상태에서 존재감 유지**(hover로 숨기지 말 것).
- 방향성 보강(R4 c 승리): **에디토리얼 구조·밀도가 테마(다크/라이트)보다 지배적** — 라이트(R4 a)가 다크 챔피언과 19:20 근소차. 다크 기본 유지, 라이트도 유효 대안. 트래킹 3단 스케일(eyebrow 0.28em/캡션 0.16em/스탯 0.12em)·넘버링 포맷 통일이 완성도를 높임.

## Typography
- 헤딩: Inter / 700 / letter-spacing -0.02em
- 본문: Inter / 400 / line-height 1.6

## 접근성/견고성 (R5 요건 승격)
- 모든 인터랙티브 요소에 accent focus-visible 링 (다크 배경 기본 아웃라인 약함 보완).
- 초대형 헤드라인은 모바일 375px에서 오버플로 방지 clamp 분리(<lg vs lg 별도), 데스크톱 룩 보존.
- 헤드라인 폰트는 Inter 유지(세리프 도입은 R5 c에서 감점).

## Spacing
- 섹션 상하 패딩 최소 96px (데스크톱)
- 컨텐츠 최대폭 1120px

## Landing 구조 기본형
1. Hero (헤드라인 + 서브 + 단일 CTA)
2. 가치 3분할
3. 소셜프루프
4. 마무리 CTA

## 금지 (anti-slop)
- 의미 없는 그라데이션 남발 X
- 3개 초과 폰트 웨이트 X
  - ⚠️ 다음 회차 정리 대상(1회차): 승자 C가 4종(light/400/semibold/bold) 사용. 타이포 위계는 살리되 웨이트는 3종으로 좁혀 재현할 것 — "타이포 위계 우선 ≠ 웨이트 남발".
