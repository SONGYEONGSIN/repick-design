# Design Principles — 랜딩 (v1)

> **페이지 타입 프로파일: `landing`.** 전 타입 공통 규칙은 [[page-brief-core]]에 있고, 이 문서는 그 위에 얹히는 **랜딩 고유 DNA**(보이스·컬러 토큰·타이포 스케일·히어로 형태·구조 기본형·anti-slop)만 정의한다.
>
> 현재의 "디자인 DNA". LEARN 단계가 surgical하게 갱신한다.
> 라운드별 상세 학습 이력은 [[AUTO-RUN-LOG]]와 각 [[MEMORY|결정 노트]]에 보존 — 이 문서는 그 정제본이다.

## Voice / Tone
- 카피 언어는 **영문 전용** — 근거·전문은 [[page-brief-core]] §1(전 타입 공통).
- 한 줄로: **신뢰감 있는 미니멀 — 에디토리얼 타이포 위계로 승부**. 과장 없이 정보 위계로.
- **near-monochrome**: 무채색으로 위계를 만들고 accent는 극소량. 단 accent는 정지 상태에서도 존재감 유지(hover로 숨기지 말 것).
- 임팩트는 **타이포 스케일 대비**로 낸다 — 그라데이션·라인아트 장식은 지양(블루프린트 감으로 감점).

## Layout / 밀도
- **Hero**: 비대칭 좌측정렬 + `clamp` 초대형 스케일 대비 (중앙정렬보다 강함).
- **에디토리얼 밀도**: 12-col 비대칭 그리드 + ghost 넘버 + Fig 캡션 + quote mark. (여백만 극대화보다 강함)
- 구조가 테마보다 지배적 — **다크 기본, 라이트도 유효 대안**(구현 밀도가 같으면 대등).

## Typography
- 헤딩: **Inter**(세리프 금지) / 700~800 / letter-spacing -0.02em
- 본문: Inter / 400 / line-height 1.6
- **폰트 웨이트 정확히 3종** (예: 400 / 600 / 800). 위계는 크기·자간·색으로.
- **디스플레이 활자 1종 선택 가능**: 헤드라인 등 라틴 대형 텍스트에 한해 화이트리스트(`--font-display-grotesk` / `-wide` / `-mono`) 중 하나. 본문·한글은 Pretendard 고정, 한 작품에 두 종 이상 금지. 세리프는 여전히 금지(§금지).
- 트래킹 3단 스케일: eyebrow 0.28em / 캡션 0.16em / 스탯 0.12em.

## 접근성 / 견고성
- 모든 인터랙티브 요소에 accent `focus-visible` 링 (다크 배경 기본 아웃라인 약함 보완).
- 초대형 헤드라인은 모바일 375px 오버플로 방지 `clamp` 분리(<lg vs lg), 데스크톱 룩 보존.
- 공통 접근성·견고성(단일 h1 · 대비 AA · 색+텍스트 병행 · 키보드 · reduced-motion · 상태 분기 대비 · sr-only 앵커)은 [[page-brief-core]] §3에 있다. 랜딩도 히어로에 테이블을 쓰면 sr-only 앵커 규칙이 그대로 적용된다(auto-landing-r7/a의 390px page-overflow가 같은 계열).

## Spacing
- 섹션 상하 패딩 최소 96px (데스크톱)
- 컨텐츠 최대폭 1120px

## Landing 구조 기본형
1. **Hero** (헤드라인 + 서브 + 단일 CTA)
2. **제품 프리뷰** — 상품 카드를 리치하게: AI 매칭 근거 태그 + 컨디션 등급 + 판매자 인증 배지 + before/after 할인율. "AI가 왜 골랐나" 증명 = 전환 설득력. **배지 배치**: 매칭%·등급·인증·할인 배지를 사진 위 절대배치 오버레이(특히 좌상단)로 두지 말고, 사진과 분리된 별도 행 또는 사진 프레임 하단 스크림에 배치한다 — 이미지 로드 실패 시 브라우저 기본 alt 텍스트가 자유 흐름으로 배치되어 오버레이 배지와 겹쳐 판독 불가가 된다. 컨테이너 예약은 §에셋·인터랙션 이미지 규율 참조. (auto-landing-r7 관찰 → r8 재현 확정, [[questions-queue]] Q9 승격 → L2 편입)
3. **가치 3분할**
   - **조작 = 가치 체감** — 히어로/프리뷰의 인터랙션은 특정 위젯(슬라이더·계산기·세그먼트)에 국한된 규칙이 아니다. 판정 기준은 "**조작이 표시되는 핵심 증명/비교 데이터를 실시간으로 갱신하는가**"라는 기능 조건이고, 슬라이더든 카테고리 탭+표 재계산이든 그 조건을 채우면 동등하다. 증명은 상시-노출이 기본값이고, 조작은 그 증명을 지연시키는 게 아니라 강화해야 한다. 판정 렌즈 쪽 대응 기준은 [[curation-criteria]] "축적된 기준" 참조. (auto-landing-r3/r4 2라운드 재현 → L2 편입)
4. **소셜프루프**
5. **마무리 CTA**

- 세리프 헤드라인

## 에셋·인터랙션 (랜딩 — 표현 상한 없음)
- **에셋 적극**: 히어로 이미지·제품샷·아바타(next/image, 고정 URL·alt·크기 명시)와 생성형 SVG/CSS(키네틱 타입·시차 배경·마스크 연출)를 표현적으로. dash와 달리 연출·무드를 허용.
- **framer-motion 적극**: 설치돼 있으나 미활용 — 스크롤 연동 연출·시차(parallax)·진입 시퀀스·제스처에 적극 사용. 단 결정론(랜덤 금지)·`motion-reduce` 게이팅·진입 opacity:0 잔존 금지.
- **인터랙션 최소 4종**: 히어로 인터랙션·스크롤 트리거·제품 프리뷰 상호작용·폼/퀴즈 등 4개+. 데코가 아니라 전환·설득에 기여.
- **이미지 규율**: 원시 `<img>` 금지 → `next/image`. `unoptimized` 금지. alt 필수. **컨테이너 예약**: 이미지 컨테이너는 고정 aspect-ratio + 배경색을 미리 예약해 로드 실패·지연 시에도 레이아웃이 무너지지 않게 한다 — 배지 배치 규칙(§Landing 구조 기본형 2번)과 함께 적용해야 CDN 장애·느린 연결에서 프리뷰 카드가 판독 가능하다. (auto-landing-r8 → L2 편입)
