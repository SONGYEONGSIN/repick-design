# Stripe — Landing Design Principles

## Voice / Tone
- 신뢰를 주는 전문적 톤이지만 딱딱하지 않음 — "금융 인프라"라는 무거운 주제를 명료한 문장으로 풀어낸다.
- 헤드라인은 비전/스케일을 말하고(예: "Financial infrastructure for the internet"), 서브헤드가 구체 기능으로 즉시 내려온다.
- 숫자/고객 로고로 신뢰를 증명하는 것을 선호 (추상적 주장보다 구체적 증거).

## Color / Palette
- 기본 배경은 화이트/라이트 그레이 — 밝고 정제된 인상.
- 히어로/섹션 구획에 컬러풀한 멀티톤 그라디언트(보라·핑크·오렌지·블루가 섞인 메시 그라디언트)를 포인트 배경으로 사용, 나머지 UI는 뉴트럴 유지.
- 텍스트는 거의 검정에 가까운 진한 네이비/그레이(#0A2540류)로, 순수 블랙보다 부드러운 대비.
- 브랜드 퍼플(#635BFF)을 CTA·링크·강조 요소에 일관되게 사용.

## Typography
- 헤딩에 굵은 웨이트의 산세리프(Stripe 자체 커스텀 폰트 계열, 대체로 Inter/Sohne류)를 사용, 본문은 가독성 높은 레귤러 웨이트.
- 헤딩 크기 대비가 크고(대형 히어로 타이틀 48~72px), 서브텍스트는 확연히 작고 옅은 톤.
- 문단은 짧게 끊어 스캔 가능하게, 리스트/카드로 정보를 쪼갬.

## Layout / Spacing
- 넉넉한 좌우/상하 여백으로 콘텐츠에 "숨 쉴 공간"을 준다 — 밀도보다 명료함 우선.
- 정보 위계가 명확한 섹션 구조: 히어로 → 신뢰 로고 바 → 기능 그리드(아이콘+짧은 설명) → 코드/개발자 예시 → CTA.
- 코드 스니펫을 실제 다크 카드로 삽입해 "개발자 친화적" 신호를 시각적으로 제공.
- 카드/버튼의 라운드 코너를 일관되게 사용 (8~16px), 그림자는 매우 은은하게.

## Signature details (이 브랜드다움)
- 멀티컬러 메시/블롭 그라디언트 배경이 가장 강한 시그니처 — 단색이 아닌 부드러운 색 전환.
- 결제/금융 UI 목업(카드, 대시보드, 체크아웃 폼)을 실사 수준으로 랜딩에 노출.
- 애니메이션 그래디언트나 인터랙티브 SVG 다이어그램으로 "인프라"라는 추상 개념을 시각화.
- 개발자용 코드 예시와 비개발자용 비즈니스 카피가 한 페이지에 공존 (두 오디언스 동시 타겟).

## 랜딩에 훔칠 것 (actionable)
- 히어로 배경에 멀티톤 블롭/메시 그라디언트를 넣되, 본문 텍스트 영역은 화이트/뉴트럴로 유지해 가독성 확보.
- 신뢰 로고 바(고객사 로고 나열)를 히어로 바로 아래 배치해 즉시 사회적 증거 제공.
- 기능 설명은 아이콘 + 1~2문장 카드 그리드로 짧게 쪼개기.
- 다크 코드 스니펫 카드를 섹션 하나에 삽입해 기술 신뢰도 보강.
- 헤딩은 크고 굵게, 서브텍스트는 작고 옅게 하여 대비로 위계를 만든다.
