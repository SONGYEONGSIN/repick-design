# Notion — Landing Design Principles

## Voice / Tone
- 친근하고 대화체에 가까운 톤 — 도구를 자랑하기보다 "당신의 일상/팀에 어떻게 스며드는가"를 이야기.
- 문장이 짧고 사람 냄새 나는 표현 ("당신의 팀이 다음에 만들 것은?") 을 사용, 과한 기술 용어 지양.
- 유저 사례/커뮤니티 목소리(트위터 인용, 팀 로고, 사용 후기)를 카피의 일부처럼 자연스럽게 배치.

## Color / Palette
- 따뜻한 화이트/오프화이트 배경(#FFFFFF ~ #FBFBFA)에 짙은 잉크블랙에 가까운 텍스트(#191919)로 종이 질감의 대비.
- 파스텔에 가까운 뉴트럴 액센트(살구/베이지/연블루/연핑크)를 섹션 배경이나 태그 컬러로 순환 사용 — 채도 낮고 부드러움.
- 원색을 거의 안 쓰고, 쓰더라도 일러스트 안에서만 컬러풀하게 등장.

## Typography
- 세리프에 가까운 느낌을 주는 커스텀/유사 산세리프(Notion Sans류)로 헤딩에 약간의 개성(휴머니스트 곡선)을 부여.
- 본문은 매우 읽기 편한 자연스러운 산세리프, 줄간격을 넉넉히(1.5~1.7) 잡아 문서를 읽는 느낌을 재현.
- 헤딩 웨이트가 과하게 굵지 않음 — "타이핑된 문서"에 가까운 절제된 굵기.

## Layout / Spacing
- 손그림/스케치풍 일러스트와 실제 제품 UI 스크린샷을 나란히 배치해 "작업 도구 + 창의성"을 동시에 전달.
- 카드/블록 요소의 라운드 코너를 크게(12~20px) 잡아 부드럽고 편안한 인상.
- 콘텐츠를 문서 블록처럼 쌓는 구조 (텍스트 블록 → 이미지 블록 → 인용 블록) — 제품 자체의 UX 철학을 랜딩 레이아웃에 반영.
- 여백은 넉넉하지만 아기자기한 디테일(작은 이모지, 아이콘)로 채워 심심하지 않게 함.

## Signature details (이 브랜드다움)
- 손으로 그린 듯한 일러스트/캐릭터(사람, 동물, 사물)를 곳곳에 배치해 친근함을 시각화.
- 이모지를 UI 요소(페이지 아이콘, 불릿)로 실제 사용 — 장식이 아니라 제품 정체성의 일부.
- 파스텔 색 블록으로 구획된 카드들이 "노션 페이지의 블록"을 은유.
- 실제 유저/팀의 워크스페이스 스크린샷을 큐레이션해 다양성과 신뢰를 동시에 보여줌.

## 랜딩에 훔칠 것 (actionable)
- 배경을 순백 대신 미세하게 따뜻한 오프화이트로, 텍스트는 순검정 대신 잉크블랙톤으로.
- 파스텔 뉴트럴 팔레트(3~4색 순환)를 섹션 배경/태그 컬러에 적용해 부드러운 리듬 만들기.
- 카드 라운드를 크게(12~20px) 잡아 편안하고 친근한 형태감 확보.
- 손그림풍 일러스트나 이모지를 텍스트 옆 포인트로 배치해 딱딱함 완화.
- 콘텐츠를 "블록" 단위로 쌓는 구조(텍스트-이미지-인용 교차)로 제품 철학을 레이아웃에 반영.
