# Linear — Landing Design Principles

## Voice / Tone
- 절제되고 단정한 단문. 마케팅 수사보다 제품의 스펙/철학을 담백하게 진술한다.
- "빠르다", "잘 만들었다"를 형용사로 주장하지 않고 UI 자체의 밀도와 마감으로 증명한다.
- 카피는 짧고 단정적 (한 문장 = 한 주장). 느낌표·이모지 거의 없음.

## Color / Palette
- 거의 순흑에 가까운 다크 배경 (#08090A ~ #0C0D0F 대) 위에 순백/거의흰 텍스트로 고대비 확보.
- 채도 낮은 보라/인디고 계열 단일 액센트 (Linear 브랜드 퍼플)를 포인트로만 사용 — 배경 전체를 물들이지 않는다.
- 그라디언트는 "면"이 아니라 "글로우"로 사용 — 카드 모서리나 히어로 배경 뒤에 은은하게 번지는 blur 처리된 광원 1~2개.
- 뉴트럴 그레이 스케일을 세분화해 텍스트 위계(제목/본문/보조)를 색으로만 구분.

## Typography
- 산세리프 단일 패밀리 (Inter류) 로 통일, 웨이트 대비로 위계 표현 (제목 590~650 semi-bold, 본문 400~450).
- 자간을 좁게(-0.01~-0.03em) 잡아 헤딩을 촘촘하고 단단하게 보이게 함.
- 본문 크기는 작게 유지 (14~16px), 헤딩과의 크기 차이를 크게 벌려 스캔 가능한 위계를 만듦.

## Layout / Spacing
- 좁은 콘텐츠 폭 (~720~960px) 중앙 정렬로 "제품 데모/UI 스크린샷"이 화면을 압도하지 않게 프레이밍.
- 카드/패널에 1px 미세 보더(회색 10~15% 투명도) + 라운드 8~12px로 다크 배경 위 표면을 구분.
- 섹션 간 여백은 넉넉하되 장식적이지 않음 — 여백 자체가 콘텐츠의 밀도를 돋보이게 하는 도구.
- UI 스크린샷/제품 캡처를 실제 크기 그대로, 축소·워터마크 없이 노출해 신뢰도를 만든다.

## Signature details (이 브랜드다움)
- 다크 모드가 기본값이며 라이트 모드는 부차적 — 다크가 "프로 도구" 인상을 만든다.
- 키보드 단축키/커맨드 팔레트(⌘K) 비주얼을 랜딩에 노출해 "속도"를 형태로 증명.
- 미세 애니메이션 (hover 시 subtle glow 이동, 텍스트 fade-in)은 있지만 바운스/과장 모션은 없음.
- 아이콘은 얇은 선(1.5px stroke) 기하학적 스타일로 통일.

## 랜딩에 훔칠 것 (actionable)
- 다크 배경 + 단일 액센트 컬러(보라/인디고 1개) + 고대비 텍스트 조합을 기본 팔레트로 채택.
- 히어로 배경에 채도 낮은 blur 그라디언트 글로우 1개만 배치, 여러 색 혼합 금지.
- 본문 텍스트는 14~15px로 작게, 헤딩과 자간을 좁혀 "촘촘하고 정밀한" 인상 만들기.
- 실제 제품 UI 스크린샷을 얇은 보더 카드로 감싸 히어로 하단에 그대로 노출.
- 카피는 형용사 대신 짧은 명제형 문장으로 (예: "Linear is a better way to build products").
