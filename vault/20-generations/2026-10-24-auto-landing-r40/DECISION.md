## 5. LEARN

One delta extracted from the winning candidate's own judging record (lens 2's strongest-defect finding on the winner):

> Closing-CTA (or any section) copy that makes a **blanket/universal liveness claim** — e.g. literally "every number on this page — including this one — moves with it" — is a verifiable content-logic defect whenever ANY other number rendered elsewhere on the page is sourced from a collection the live manipulation does not touch (e.g. aggregate social-proof/testimonial stats, or a static hero showcase drawn from a different dataset than the one the device filters). This repo's existing causal-consistency rule only checks that *some* live value reaches the closing CTA — it does not check that the CTA's own wording doesn't overclaim beyond what is actually threaded. Audit literal "every/all" language in device-adjacent copy against the real prop-threading, not just the primary instrumented value.

Appended as `auto-landing-r40/b`, L1, provisional, confidence high (independently traced and confirmed against source by the judging lens itself, not an orchestrator inference) — see `landing-deltas-provisional.jsonl`.
