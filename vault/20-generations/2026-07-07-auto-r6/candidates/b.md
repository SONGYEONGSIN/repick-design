- 카드 표면·보더·라운드는 기존 토큰 재사용(`bg-white/[0.03]`, `border-white/10`, `rounded-md`) — 신규 색상 토큰 0개.
- 신규 상품 이미지/외부 리소스 없음 — CSS grid 플레이스홀더로만 구성, 오프라인 렌더 제약 준수.
- nav에 "미리보기" 링크 추가(방식 앞), 흐름: 미리보기 → 방식 → 신뢰 → 시작하기.
