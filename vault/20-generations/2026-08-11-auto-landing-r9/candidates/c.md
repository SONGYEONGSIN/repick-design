# 후보 c — "Judge us by what we refuse"

**한 줄**: 12개 매물이 한 평면에 — 채택 4장과 반려 8장이 각각 반려 사유 라벨을 달고 함께 놓이고, 가드레일을 끄면 반려가 되살아나면서 신뢰 지표 네 개가 함께 무너진다.

- 배정: 조작 어휘 = **제외 사유 토글** / 매크로 골격 = **채택+반려가 한 평면 + 상단 사유 바** / 다크 · `--font-display-wide`
- 축 조합(Q6 기준): **제외 기준(가드레일) on/off × 반려 매물 부활 + 신뢰 지표 동반 하락** — 기존 6종과 미겹침. **부정 증거로 증명하는 랜딩은 카탈로그 41작품에 없다.**
- 파일: `page.tsx`(서버 셸·operators·마감 CTA·푸터) · `FieldWork.tsx`(클라이언트 히어로·가드레일 패널·보드·대가 3분할) · `data.ts`(12매물 + `summarize`/`warningLine`/`groupBoard` 전역 함수) · `Ghost.tsx`(SVG 에디토리얼 넘버)

## 인터랙션 (6종)

| # | 조작 | 동시 갱신 증거면 |
|---|---|---|
| 1 | 제외 사유 스위치 ×4(`role="switch"`, `aria-checked`) | ① 해당 카드가 `Filtered out` → `Admitted by override`(아이콘·배지 텍스트·보더·마크 톤 동시) ② 히어로 4판독값 — Board size 4→12, Verified sellers 100%→75%, Median condition A-→B, **Median discount 40%→46%** ③ 칩별 카운트 `3 blocked` ↔ `3 admitted` ④ 3분할 Now 수치 3개 + "Override in effect" 보더 ⑤ `aria-live` 산문 경고 ⑥ By-status 그룹 재편성 — **6면** |
| 2 | Drop all four / Restore all four | 위 6면을 1클릭으로 최악치까지. 보드 3배 + 검증 판매자 25pt 하락 |
| 3 | 보드 그루핑 세그먼트(By status / By guardrail) | 12장 재그룹 + 그룹 제목·노트 교체. **좁히는 필터가 아니라 축만 바꾼다 — 아무것도 숨기지 않는다**(금지 조항 준수) |
| 4 | 카드 hover | `transform` + `border-color`만, 200ms ease-out |
| 5 | Scroll reveal | 헤더·3분할 stagger(0.06s, 3자녀), `whileInView` + `once:true`, `useReducedMotion` → `initial={false}` 게이팅 |
| 6 | focus-visible 링 | 전 컨트롤 `outline-2 offset-2 #B6A6F0`, `outline-none` 단독 0 |

**접근성 배정 준수**: 약화 표현에 `opacity-*`를 **일절 쓰지 않았다.** 반려 카드는 dashed 보더 + 어두운 셸 + 마크 톤 `#3F3F46` + 제목 `#D4D4D8`로만 약화되고 본문·메타는 `#A1A1AA`(7.6:1) 유지. 상태는 색 + 아이콘 + 문장 3중. `dl`은 전부 `dl > div > (dt, dd)`, `overflow-x-auto` 0건.

## 브리프에 없던 것

1. **매물 총 개수와 채택/반려 비율** — ② 12장 = 채택 4 / 반려 8 ③ 채택은 브리프가 3~4장으로 못박았고, 반려는 "채택보다 확실히 많아야 걸러냈다는 사실이 논증이 된다"고 판단. 임의.
2. **사유별 차단 건수(verification 3 / price 2 / condition 2 / photos 1)** — ③ 브리프 예시는 "6 listings"였으나 중앙값이 실제로 움직이도록 등급 분포를 역산해 정했다. 6/6/6/6이면 보드가 28장이 되어 카드 무덤이 된다. 임의(제약 역산).
3. **신뢰 지표의 종류와 개수** — ② Board size / Verified sellers % / Median condition / Median discount 4개 + 3분할의 Audit exceptions ③ 브리프는 둘만 예시로 줬다. **Median discount(40%→46%)를 추가한 것은 의도적 반론 장치** — 가드레일을 풀면 "더 싸진다"는 사실을 숨기지 않아야 나머지 지표의 하락이 정직하게 읽힌다. 임의.
4. **중앙값의 정의** — ② 하위 중앙값(lower median) ③ 보간하면 등급 아닌 값(B+.5)이 나오고 할인율에 소수점이 붙어 "표시 흔들림 없게" 지시를 어긴다. 관행.
5. **컨디션 등급 체계** — ② A/A-/B+/B/C/C- 6단계, 점수 6~1 ③ 브리프는 "below B"·"B+ → C"만 언급하고 전체 스케일이 미정. 브리프에 등장한 값을 모두 포함하도록 설계. 관행.
6. **통화 표기** — ② `KRW 412,000`(ASCII) ③ **`₩`(U+20A9)를 쓰면 정적 검사가 이모지로 오탐할 위험이 있다**(직전 라운드에 `©`가 같은 이유로 걸린 전례). 방어적 임의.
7. **경고 문장의 문법 분기** — ② 0개/1개/2개 이상 각각 다른 문형 + 복수형 분기 ③ 브리프는 1개 케이스 예문만 줬다. 임의.
8. **두 번째 조작(그루핑 컨트롤)의 존재 자체** — ③ 브리프에 없다. **단일 장치 페이지가 이 루프의 최근 결함으로 지목됐고**, "필터로 목록을 좁히지 마라"는 금지를 지키면서 사유 축을 두 번째로 읽히게 하는 방법이 필요했다. 자율 판단.
9. **일괄 조작 버튼(Drop all four)** — ③ "최악의 대가"를 한 번에 보여주는 것이 논증을 가장 강하게 만든다. 임의.
10. **경고·위험용 세 번째 색 `#E0A82E`** — ① DNA 팔레트에 override·risk 토큰이 없다 ② 앰버(9.2:1) ③ accent 바이올렛을 "선택됨"에 이미 썼으므로 "override로 들어옴"에 같은 색을 쓰면 의미가 뭉갠다. near-monochrome을 깨는 유일한 추가 색이며 override 상태에만 쓴다. 임의(DNA 확장).
11. **밝은 accent 틴트 `#B6A6F0`** — ① **DNA accent `#6E56CF`는 `#0B0B0F` 위에서 3.73:1로 본문 크기 텍스트에 AA 미달** ② 소형 텍스트·아이콘용으로 `#B6A6F0`(9.1:1) 파생, `#6E56CF`는 CTA 배경·대형 인용부호(3:1 기준 통과)에만 ③ **DNA 값을 그대로 쓰면 a11y 하드게이트가 깨지는 정면 충돌** — 규칙 우선 판단.
12. **반려 상태의 시각 어휘** — ① 브리프가 `opacity`를 금지했지만 무엇을 쓰라고는 안 함 ② dashed 보더 + 셸 `#0D0D12` + 마크 톤 `#3F3F46` + 제목만 white→`#D4D4D8` + Ban 아이콘 + "Filtered out" 문장 ③ **SVG가 이미 near-monochrome이라 `grayscale()` 필터는 아무 효과가 없어** 톤 교체로 대체. 자율 판단.
13. **사진 대신 생성형 SVG와 마크 4종의 형태** — ② 채워진 도형 4변형 ③ 카드 12장에 원격 이미지를 물리면 LCP·재고 리스크가 커진다. 외곽선을 피한 것은 라인아트 감점 조항 때문. 브리프 근거 + 임의.
14. **ghost 넘버를 SVG로 렌더** — ② `<svg><text fill="#2E2E38">` ③ HTML로 두면 대비 스윕에 잡히고 `aria-hidden`이 axe에서 면제되는지 확신할 수 없었다. SVG는 웨이트 집계에서 제외된다고 브리프가 명시. 방어적 임의.
15. **섹션 카피 전문과 헤드라인** — ② h1 "Judge us by / what we refuse.", 섹션 제목 5개, Fig. 캡션 3개 ③ 브리프는 논지만 줬고 문장은 안 줬다. 임의.
16. **판매자 표기 방식** — ② 미검증 건은 이름 대신 **상태 서술**("Account opened this week", "No payout history", "Unresolved identity"), 검증 건은 가공 상호 4개 ③ 실존 인물명 금지를 넘어, 미검증 판매자에 아무 이름이나 붙이면 **그 자체가 정보가 없다는 사실을 가린다**. 자율 판단.
17. **브랜드명 사용 여부** — ② 전부 일반명사로 통일(초안의 "Aeron"·"Leica"는 되돌림) ③ 반려만 익명이고 채택만 실브랜드면 "좋은 건 진짜, 나쁜 건 가짜"라는 비대칭이 생긴다. 자율 판단.
18. **소셜프루프 인용문·귀속·통계** — ② 전부 창작, 귀속은 개인명 없이 역할+주문수 ③ 브리프에 요구만 있고 내용이 없다. 임의.
19. **`role="switch"`의 극성** — ② `aria-checked={!isOff}` — 켜짐 = 가드레일 작동 ③ 시각 라벨이 On/Off라 스크린리더와 화면이 같은 방향을 읽어야 한다. 관행.
20. **판독값 캡션 문구** — ② 히어로 "Baseline 100%", 3분할 "All four on". 임의.
21. **그리드 브레이크포인트** — ② 1 / sm 2 / lg 3 / xl 4 ③ 390px에서 배지 4개가 한 카드 안에서 접히지 않는 최소 폭을 역산. 제약 역산.
