# 후보 b — "순서가 곧 모델"

**한 줄**: 5개 평가 기준의 *순위*가 그대로 가중치(×5…×1, 합 15)가 되고, 좌측 레일에서 한 칸 올리는 순간 우측 랭킹·기여도 막대·요약 문장·1위 근거가 동시에 다시 계산되는 라이트 에디토리얼 랜딩.

- 배정: 조작 어휘 = **기준 우선순위 재배열** / 매크로 골격 = **좌 기준 레일 + 우 결과 랭킹** / 라이트 · `--font-display-grotesk`
- 축 조합(Q6 기준): **평가 기준의 순위 재배열 × 랭킹 재정렬 + 기여도 분해** — 기존 6종과 미겹침
- 파일: `page.tsx`(서버·metadata + 소셜프루프 + 마감 CTA) · `ranking-board.tsx`(클라이언트 히어로 + 가치 3분할) · `parts.tsx`(데이터 + 순수 정수 스코어링 + 생성형 SVG)

## 인터랙션 (5종)

| # | 조작 | 갱신 증거면 |
|---|---|---|
| 1 | 기준 위/아래 이동(버튼 1차 경로, `aria-label` + `aria-live`) | ① 랭킹 순서(1위 실제 교체) ② 4장 기여도 스택 막대 + pts/% 범례 ③ 요약 문장 ④ 1위 강조 + "Why it leads" ⑤ ×가중치 배지 ⑥ 매칭 근거 태그 ⑦ 3분할 패널 3개 — **7면** |
| 2 | 프리셋 4종(Balanced/Bargain hunter/Collector/Trust first, `aria-pressed`) | 위 7면 + 순열 점프. 프리셋별 1위가 턴테이블/선반/턴테이블/카메라로 갈림 |
| 3 | "Break this one down"(카드별 토글) | 3분할 2번 패널의 분해 테이블 + caption 교체, 카드 테두리 강조 |
| 4 | framer `layout` 재배치 | 기준·랭킹·막대 세그먼트가 transform 이동(tween 300ms easeOut, **오버슈트 없음**, `useReducedMotion` 게이팅) |
| 5 | 진입 시퀀스 + hover 마이크로 | CSS `rise`(0/80ms 스태거, `motion-reduce:animate-none`), CTA `-translate-y-px` |

첫 페인트에 기본 순위와 완성 랭킹·근거가 전부 노출(증명 지연 없음). 사진 미사용, 배지는 전부 프레임 바깥 별도 행.

**접근성 배정 준수**: 드래그를 유일 경로로 만들지 않고 위/아래 버튼을 1차 경로로 뒀으며, `aria-live`로 결과를 알리고 랭킹에 오버슈트 스프링을 쓰지 않았다.

## 브리프에 없던 것

1. **순서 → 숫자 가중치 변환식** — ② 5/4/3/2/1 선형(합 15) ③ 정수 유지로 `total/15` 한 번만 반올림하면 부동소수 흔들림이 사라진다. 지수형(8/4/2/1)도 검토했으나 1위 독주로 순위 역전이 안 일어나 조작 체감이 죽는다. 임의.
2. **match%의 정의** — ② 가중평균을 0~100 반올림 ③ 순서를 바꿔도 스케일이 고정돼야 카드 간 비교가 성립. 관행.
3. **매물 4종 × 기준 5개 = 20개 서브스코어** — ② 프리셋 4개가 서로 다른 1위를 내도록 **역설계** ③ r8 학습("순서가 실제로 안 바뀌면 조작이 체감 안 됨")을 데이터 레벨에서 보장하려고. 임의.
4. **기여도 반올림 잔차** — ② 마지막 세그먼트가 `100 − 누계`를 흡수 ③ share 합이 항상 100이어야 막대와 텍스트가 안 어긋난다. 관행.
5. **근거 태그 산출식** — ② `(점수×4 − 세트합) × 가중치` 상위 2개 ③ 단순 기여도 상위 2개로 하면 가중치가 지배해 네 카드가 전부 같은 태그를 달아 태그가 무의미해진다. 임의.
6. **프리셋 존재 자체와 4개 순열** — ③ 버튼만으로 순열을 크게 바꾸려면 4~8클릭이라 첫 방문자가 "1위가 바뀐다"를 보기까지 거리가 멀다. 관행(세그먼트 컨트롤).
7. **5개 기준의 최종 명칭·설명문** — ② 브리프 예시 그대로 + 1줄 blurb 창작 ③ 예시로만 제시돼 확정값이 없었다.
8. **매물·판매자·가격 데이터 전부** — ② 브랜드명 없는 일반 명사구 + 상호형 핸들(northline supply 등) ③ 실존 인물명 금지를 넓게 해석해 **실존 브랜드도 회피**. 임의.
9. **통화 단위** — ② USD, 로케일 비의존 수동 3자리 구분 ③ 영문 전용 + 과거 라운드의 ₩ 글리프 누락 + `toLocaleString`은 서버 ICU에 따라 하이드레이션이 갈릴 수 있다. 과거 학습.
10. **이미지 미사용 결정** — ② `next/image` 대신 생성형 SVG(라인아트 금지라 면 채움 도형) ③ r7 학습 + 로드 실패 시 alt 흐름 문제를 원천 제거. 브리프가 선택을 허용한 지점.
11. **framer `whileInView` 미사용 결정** — ② 진입은 CSS `rise`, framer는 `layout`·제스처 전담 ③ **"framer 적극"과 "진입 `opacity:0` 잔존 금지"가 충돌**하는데 IntersectionObserver가 안 뜨는 캡처 환경에서 하드페일이 나므로 게이트 쪽에 가중치를 뒀다. *"브리프가 판정하지 않은 충돌을 내가 임의 해소했다."*
12. **위/아래 버튼 경계 처리** — ② `disabled` 대신 `aria-disabled` + 클릭 무시 ③ 이동 후 버튼이 disabled가 되면 포커스가 body로 날아가 키보드 사용자가 위치를 잃는다. 관행.
13. **`aria-live` 문구 포맷** — ② `"{기준} moved to position {n}. Top pick is now {매물} at {n} percent match."` ③ 브리프 예시는 순위 이동만 알렸는데 이 후보의 핵심 증명이 1위 교체라 그것까지 읽어줘야 스크린리더 사용자가 같은 증거를 받는다. 임의 확장.
14. **3분할 패널의 구체 지표** — ② (1) 위치별 가중치·비중 (2) 선택 매물 분해 테이블 (3) 기본 순서 대비 변경 순위 수·최대 이동·1위·2위 격차 ③ 무엇을 세 칸에 넣을지 미정. 임의.
15. **"Break this one down" 추가** — ② 지정된 4개 증거면에 없던 5번째 입력 ③ 분해 테이블이 1위 고정이면 "1위만 설명하는 페이지"가 되어 나머지 3장의 풀태깅이 장식으로 읽힌다. 임의.
16. **Fig 번호·ghost 넘버(01~04)와 마감 CTA만 다크 밴드** — ③ DNA가 Fig 캡션·ghost 넘버를 요구했으나 부여 규칙이 없었고, 라이트 테마에서 종결부 대비를 만드는 관행.
17. **폰트 웨이트 3종의 확정값** — ② 400/600/800 ③ 브리프가 "예:"로만 제시. `font-medium`/`font-bold` 전 파일 0건이고 모든 `h1~h3`·`th`에 명시 클래스(UA 기본 700이 4종째로 잡히는 함정 회피).

## designer 자체 신고 — 미검증

턴 예산 안에서 `lint`/`tsc`/실제 렌더를 돌리지 못했다. 정적 위험(금지 토큰·`font-medium`·`<img>`·`dark:`·비결정론)은 grep으로 0건 확인했고 390px 폭은 손으로 계산(카드 콘텐츠 열 ≈ 318px)해 모바일에서 마크를 상단 96px로 분리했으나, **실측 sweep은 게이트가 확인해야 한다**고 명시했다.
