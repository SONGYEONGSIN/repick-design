## b — 궤도(Trajectory) · 세로 스크롤 여정 타임라인

**아키타입.** 페이지 전체를 "취향 등록 → AI 매칭 → 전문 검수 → 안심 배송 → 후기 → 시작"으로 이어지는 사용자 여정의 챕터형 타임라인으로 구성했다. 데스크톱(xl+)에서는 좌측에 고정형 세로 진행률 레일(트랙 라인 + 챕터 마커 6개)이 뷰포트 중앙에 상주하고, 스크롤에 따라 accent(#6E56CF) 라인이 위에서 아래로 채워지며 현재 챕터 마커가 하이라이트된다. 각 마커는 해당 섹션으로 점프하는 버튼이기도 하다. 모바일·태블릿(xl 미만)에서는 이 세로 레일을 sticky 헤더 하단의 가로 진행바(현재 챕터 번호·라벨 + `n / 6` + accent 채움 라인)로 적응시켜 375~390px에서도 잘림 없이 동작한다. v3-magazine의 "목차→챕터→풀인용" 롱폼 리듬과 달리, 여기서는 **여정의 순차적 진행 상태(프로그레스) 자체가 시각적 척추**다 — 스크롤이 곧 실제 서비스 이용 과정을 라이브로 되짚는 행위가 된다.

**핵심 인터랙션.** (1) 레일 채움은 `useScroll()` 페이지 진행률을 `useSpring`으로 부드럽게 감쇠시켜 `scaleY`(세로)·`scaleX`(가로)에 바인딩했다. (2) 활성 챕터는 각 섹션 `motion.section`의 `onViewportEnter`(viewport margin `-45%` → 뷰포트 중앙 밴드 진입 감지)로 판정해 상·하행 스크롤 모두에서 정확히 갱신된다. (3) 각 챕터는 뷰포트 진입 시 근거를 드러낸다 — AI 매칭 챕터는 종합 94% 스코어와 4개 세부 지표 바(취향/사이즈/예산/브랜드)가 좌→우로 차오르고, 검수 챕터는 6개 항목 체크리스트 + S/A/B/C 등급 스케일(현 매물 A 하이라이트), 배송 챕터는 done/active/todo 상태의 세로 스테퍼가 "도착까지 남은 1단계"를 실시간 추적처럼 보여준다. 모든 모션은 `useReducedMotion`으로 가드했다.

**필수 요소 배치.** Hero(00, 비대칭 좌측정렬 + `clamp(2.4rem,8vw,5rem)` 초대형 헤드라인 + 단일 CTA + ghost "RE:" 넘버) → 가치 3분할("세 가지 약속": 94% 매칭·12단계 검수·100% 실측, 헤어라인 그리드) → 제품 프리뷰(AI 매칭 챕터의 리치 매물 카드: 매칭 근거 태그 3종 + 컨디션 A급 배지 + 판매자 인증 배지 + before/after 할인율 -40% 전부 포함) → 소셜프루프(지표 3 + 후기 3, 모노그램 아바타) → 마무리 CTA(accent 패널). "AI가 왜 이걸 골랐나"를 스코어 바 + Fig 캡션으로 증명해 전환 설득력을 확보했다.

**기술적 결정 근거.** 정본 DNA(near-monochrome 다크)를 따라 bg #0B0B0F / fg #FFFFFF / muted #A1A1AA에 accent #6E56CF만 극소량으로 배치하되, 레일 채움·활성 마커·CTA·핵심 수치에서 accent가 정지 상태에서도 존재감을 유지하도록 했다(hover로 숨기지 않음). 폰트 웨이트는 정확히 3종(400/600/800)만 사용하고 위계는 크기·자간(eyebrow 0.28em / 캡션 0.16em / 스탯 tabular)·색으로 냈다. 임팩트는 그라데이션·라인아트 장식 없이 타이포 스케일 대비로만 확보. 전역 Pretendard(`font-sans`)를 사용하며 `next/font` import·`font-serif`는 쓰지 않았고, 모든 데이터는 결정론(고정 문자열/숫자, `Math.random`·`Date.now`·`new Date` 미사용), 아이콘은 `lucide-react`, 애니메이션은 `framer-motion`으로 처리했다. 실이미지는 매물 카드 1장(next/image, 설정에 허용된 unsplash)으로 최소화해 v0/v1의 이미지 몰입형과 차별화하고 여정 구조·타이포 근거를 전면에 세웠다. 레일은 `xl:grid`의 sticky 컬럼으로 구현해 fixed 오버랩 없이 콘텐츠와 정렬되며, 좁은 뷰포트에서는 가로 진행바로 우아하게 접힌다.
