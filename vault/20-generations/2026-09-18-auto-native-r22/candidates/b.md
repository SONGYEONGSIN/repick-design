## Concept

**Active Sessions** is an account-security device manager: a single scrolling `FlatList` of the account's signed-in sessions, with the current device pinned above the list via `ListHeaderComponent` (device name, type, location, "Active now", and a "This device" badge) and no sign-out control on it, since you cannot remotely end the session you're reading the screen on. Every other row shows device name, type + approximate location, and a fixed last-active label, plus a "Sign out" button. Tapping "Sign out" never opens a native `Alert` — it converts that exact row, in place, into an inline `Cancel` / `Confirm sign out` pair with an announced confirmation sentence (`accessibilityRole="alert"` nested in an `accessibilityLiveRegion="polite"` container). Confirming swaps the row into a brief "Signed out" acknowledgement (same live-region pattern) for 900ms, then removes it from the list. Only one row may be non-idle at a time — requesting sign-out on a second row while a first is still confirming or winding down forces the first to resolve immediately, so exactly one live region is ever active. The screen has no fixed bottom band anywhere; the current device, section labels, and every other session all scroll together inside one `FlatList`.
