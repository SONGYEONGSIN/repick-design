# Candidate C

다크 테마 + 스카이블루 액센트의 리세일 검증 랜딩: "Pulse" 파형 하나로 5개 검증 체크의 토글 상태 → 합성 신뢰도 % → 제안 오퍼 플로어(달러) → 클로징 CTA까지 같은 state가 그대로 흘러가는 구조.

## 브리프에 없던 것

- 오프(미검증) 상태 점수값
  무엇: 체크를 껐을 때 합성 신뢰도에 들어가는 기본 점수가 브리프에 없음.
  선택: 5개 체크 공통 16점으로 고정(온 점수는 88~96 범위로 개별 설정).
  이유: 레퍼런스 없는 임의값. "꺼짐=거의 미검증"을 직관적으로 보여주는 낮은 공통값을 택함.

- 오퍼 플로어 공식
  무엇: 신뢰도 점수를 실제 달러 금액으로 바꾸는 변환 공식이 브리프에 없음.
  선택: listedPrice × (0.6 + 0.4 × composite/100). 즉 60%는 항상 보장, 나머지 40%는 신뢰도에 비례.
  이유: "manipulation = value realization"을 만족하면서 ValueSection 카피에서 그대로 설명 가능한 가장 단순한 선형식을 임의로 선택.

- 파형 세그먼트 폭 = 토글 칩 폭
  무엇: 파형이 가로축에서 체크별로 얼마만큼씩 구간을 차지할지 규칙이 브리프에 없음.
  선택: 각 체크의 weight(합성 가중치)를 파형 세그먼트 폭과 토글 칩의 flex-grow 폭에 동시에 사용.
  이유: 레퍼런스 없는 디자인 결정. "칩이 넓을수록 파형에서 차지하는 구간도 넓다"는 시각적 1:1 대응을 만들기 위함.

- 액센트 대비 수치 (브리프 요구사항 — 계산 기록)
  베이스 #2FB6FF: 화이트 대비 2.27:1(흰 배경 텍스트로는 미사용) / 다크 잉크(#0B0B0F) 대비 8.66:1(큰 텍스트·채움·보더·파형 선에 사용).
  틴트 #8FD9FF: 다크 잉크 대비 12.68:1(작은 텍스트·아이콘·포커스링에 사용) / 화이트 대비 1.44:1(미사용).
  이유: 브리프가 "두 대비 모두 계산해서 기록"을 직접 요구함 — 공식대로 계산해 사용처를 나눔.

- 포커스 가시성 구현
  무엇: Tailwind v4에서 bare ring/outline-none 조합이 투명하게 렌더되는 문제를 어떻게 피할지.
  선택: outline-none을 전혀 쓰지 않고, 모든 포커스 가능 요소에 focus-visible:outline-2 + outline-offset-2 + 실제 색상(#8FD9FF) 조합만 적용.
  이유: 브리프가 명시한 정확한 해법을 그대로 채택 — 임의 선택이 아니라 지정된 선례를 따름.
