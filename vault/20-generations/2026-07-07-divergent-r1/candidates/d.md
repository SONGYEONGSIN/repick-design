# Candidate D — Soft Organic Playful

**아키타입**: 소프트 오가닉 플레이풀 (Soft Organic Playful)

repick을 "따뜻하고 친근한 중고 친구"로 재해석했다. 크림(#FFF9F2)을 베이스로 피치(#FFE0D6/#FF9B7A), 민트(#D4F5E9/#2F7A5E), 옐로우(#FFF3C4/#E7A93C) 파스텔 삼색을 사용하고, 모든 컨테이너·카드·버튼·숫자 배지를 비대칭 `border-radius` 값으로 만든 손그림 느낌 블롭 형태로 통일했다. 배경에는 느리게 모양이 변하며 떠다니는 대형 블롭 3개(`@keyframes blobMorph` + `floatSlow`)를 배치해 화면 전체가 살아 숨쉬는 듯한 인상을 준다. 카피는 "안 쓰는 물건도 다시 사랑받게 해줄게요 🐻"처럼 의인화·이모지·반말에 가까운 다정한 톤을 사용했고, CTA는 쿠키/막대사탕 이모지로 장식한 필 버튼(`rounded-full`)에 부드러운 컬러 그림자(`box-shadow` blur+offset)를 적용해 말랑한 촉감을 시각적으로 표현했다. 섹션 구성은 히어로 → 통계 블롭 3개 → Why(3 카드, 각기 다른 블롭 모양) → How it works(숫자 배지 3단계) → 손그림풍 말풍선 테스티모니얼 → 그라데이션 블롭 CTA 배너 → 점선 보더 푸터로, 딱딱한 그리드 대신 원형·곡선 리듬으로 시선을 유도한다. 전체적으로 "편안하고 사랑스러운" 느낌을 극단까지 밀어붙여, 기존 에디토리얼/미니멀 챔피언과 완전히 다른 촉각적·정서적 경험을 제공한다.
