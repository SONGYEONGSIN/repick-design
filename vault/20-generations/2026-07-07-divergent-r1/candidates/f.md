# Candidate f — 바이퍼웨이브 / 비비드 그라데이션 맥시멀리즘

**아키타입**: 80s 신스웨이브·베이퍼웨이브. 마젠타·시안·퍼플 네온 그라데이션, 다중 레이어 text-shadow/box-shadow 글로우, 스캔라인 오버레이, perspective(rotateX) CSS 원근 그리드 바닥, 줄무늬 그라데이션 석양(sun), 홀로그램 무지개 보더(hue-rotate 애니메이션 카드).

**핵심 컨셉**: repick을 "미래에서 도착한 중고 포털"로 재정의. 히어로는 네온 석양 위에 뜬 초대형 글로우 헤드라인 + 원근감 있는 그리드 바닥이 화면 아래로 스크롤되는 듯한 애니메이션으로 몽환적 깊이를 만든다. 기능 3종(AI 비전 스캐너/홀로그램 가격 리포트/네온 마켓 매칭)은 무지개 그라데이션 보더가 회전하는 글래스 카드로, 통계 티커는 다크 퍼플 밴드에 시안 네온 숫자로, 쇼케이스 상품 카드는 그라데이션 워시 배경 위 이모지+가격 상승률 배지로 구성. 전체적으로 채도 최대·글로우 최대의 80년대 레트로퓨처 미학을 극단까지 밀어붙였다.
