# Candidate C — 터미널/모노스페이스 CLI

**아키타입**: 해커 콘솔 / CRT 터미널 미학

**핵심 컨셉**: repick을 "판매자가 재고를 넘기면 AI 엔진이 명령어처럼 실행되는 큐레이션 시스템"으로 재정의. 검은 배경 위 매트릭스 그린(#3dff7a)과 앰버 가격 포인트(#ffb000), 시스템 모노스페이스 폰트, 깜빡이는 커서, box-drawing ASCII 아트 스캔 로그, `$ repick --curate` 같은 prompt형 CTA, 섹션 제목을 전부 `# comment` 스타일로 처리해 화면 전체가 하나의 터미널 세션처럼 읽히게 구성했다. 통계는 `[OK]` 로그, 프로세스는 `[STEP n/5]` 타임스탬프, 상품 목록은 `ls /inventory` 결과 테이블, 상세 설명은 `man repick` 페이지 포맷으로 표현해 "AI가 돌리는 엔진"이라는 인상을 기술적·긱하게 극대화했다. CRT 스캔라인 오버레이와 은은한 glow 애니메이션으로 화면 자체가 살아있는 콘솔처럼 느껴지도록 마감.
