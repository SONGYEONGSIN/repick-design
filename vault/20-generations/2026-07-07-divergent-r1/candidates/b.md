# Candidate B — Y2K 레트로웹 (Chrome & Sparkle)

**아키타입**: 2000년대 초 개인 홈페이지/포털 감성의 Y2K 레트로웹. 크롬 메탈릭 그라데이션 텍스트, 반짝이는 별(✦✧★), 홀로그램 무지개 그라데이션, 둥근 베벨(bevel) 3D 버튼, 스크롤 마퀴 티커, 픽셀풍 방명록, 히트 카운터, "Best Viewed at 1024×768" 뱃지 등 밀레니엄 웹 클리셰를 자신 있게 총동원.

**핵심 컨셉**: "다시 유행하는 건 옷만이 아니다" — Y2K 패션이 다시 뜨는 지금, 그 시절 웹 UI 자체를 리바이벌해서 repick의 "중고=재유행" 메시지를 형식과 내용 모두에서 겹쳐 보여준다. 촌스러움을 숨기지 않고 블링블링하게 밀어붙여 향수와 재미를 동시에 자극하는 발산형 랜딩.

**구성**: 상단 마퀴 티커 → 레트로 툴바 네비 → 크롬 텍스트 히어로 + 반짝이 필드 + 히트카운터 → 홀로그램 스탯 바 → 베벨 카드 아이템 그리드(6종) → 모노스페이스 방명록(3개 후기) → 무지개 그라데이션 최종 CTA → 웹링 뱃지 풋터.

**기술**: 단일 `page.tsx`, Tailwind v4 유틸리티 + `<style>` 내 커스텀 키프레임(marquee/twinkle/blink/shine)으로 애니메이션 구현. 외부 이미지·폰트 CDN 없이 시스템 폰트(Impact/Arial Black 폴백)와 이모지·유니코드 장식만 사용. 반응형 375~1280px, 단일 h1(`RE:PICK`), 포커스 가능한 링크/버튼에 `focus-visible` 링 스타일 적용.
