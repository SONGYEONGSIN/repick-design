# Candidate A — 네오브루탈리즘 맥시멀리즘

**아키타입**: Neo-Brutalism Maximalism (펑크 중고 마켓)

충돌하는 형광 원색(마젠타 #FF2FBD, 시안 #00C2FF, 라임 #ADFF2F, 옐로 #FFEA00, 오렌지 #FF6B00)을 두꺼운 검정 보더(border-4)와 하드 오프셋 섀도우(`shadow-[8px_8px_0_0_#000]`)로 가두고, 라운드는 전면 제거. 스티커/뱃지(★, HOT, NEW, -57% 등)가 카드 모서리에서 회전각을 달리하며 겹쳐 붙고, 헤드라인은 전부 대문자·블랙 웨이트에 텍스트 섀도우로 눌러 찍은 인장처럼 처리했다. 상단엔 검정 배경 위 형광 마퀴 티커가 무한 스크롤하며 "못생겨도 착해", "가품 0%" 같은 펑크한 카피를 흘려보낸다.

레이아웃은 히어로 → 마퀴 → 통계 스트립(회전된 4개 박스) → 다크 배경 피처 3카드(교차 회전) → 라임 배경 상품 그리드(스트라이프 패턴 플레이스홀더 + 할인 뱃지) → 화이트 배경 스티키노트 후기 → 블랙 CTA → 옐로 푸터 순. 모든 인터랙티브 요소는 hover 시 -translate + 섀도우 확장으로 "떠오르는" 촉감을 주고, focus-visible에는 대비되는 형광 아웃라인을 적용해 키보드 접근성을 확보했다.

repick을 "AI가 다시 골라주는 얌전한 리커머스"가 아니라, **골목 벼룩시장에서 스프레이 페인트로 붙여놓은 전단지** 같은 텐션으로 재정의했다.
