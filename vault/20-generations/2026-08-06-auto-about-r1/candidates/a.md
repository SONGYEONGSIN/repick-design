# Candidate a — Portage

Portage is a fictional B2B SaaS ("the operations layer that lets small manufacturers run fulfillment without hiring a full logistics department") rendered as a single-column, no-sidebar editorial scroll — hero mission statement → attributed founder pull-quote → a keyboard-operable vertical milestone timeline (six years, each collapsed by default and expanded via a real `aria-expanded` button) → a category-chip-filtered values grid with a live "Showing N of M" count → a five-person team strip using deterministic inline-SVG monogram avatars (fixed hex per person, no photos/remote hosts) → a careers CTA band. A sticky scroll-spy nav (`IntersectionObserver`-driven, `aria-current`) tracks section position as a third wired interaction. Light theme, amber accent only, `--font-display-grotesk` for headline type, exactly 3 route-wide font-weight classes (`font-normal` / `font-semibold` / `font-black`).
