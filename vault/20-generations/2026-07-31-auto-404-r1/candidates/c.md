# c — Harbor (search-focused)

Secondhand marketplace SaaS, white + teal-600 accent. Centered search input is the page's
subject, filtering a fixed listing catalog live (deterministic, no network). Popular-category
chips and search suggestions both write into the same query state, so every secondary path
resolves through the working search rather than dead-ending. Single primary CTA ("Back to
home") plus one mailto contact link.
