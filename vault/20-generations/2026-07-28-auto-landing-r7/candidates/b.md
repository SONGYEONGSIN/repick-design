## b — Confidence Equalizer

The hero replaces every prior single-number "trust badge" with a five-channel vertical bar-chart equalizer: each bar is one of the AI's real matching criteria (Taste Profile, Size, Budget, Condition Grade, Market Price), its height a fixed, already-computed contribution to the overall match score, with the total (96%) counting up via a deterministic tabular-nums step (framer-motion `animate()`, no `Math.random`/`Date.now`/`new Date`) synced to a staggered fixed-delay `scaleY` fill per bar (transform-only, `transformOrigin: bottom`, never animating height/width itself) — gated by `prefers-reduced-motion` so bars and the counter render at final state immediately with no stuck `opacity:0`. This is a pure output-visualization hero per the r5 learning (the AI already scored the match; the widget displays the result rather than requiring input to produce one) — the first bar-chart/equalizer form in the corpus, distinct from r5a's radial dial gauge (a circular single-value gauge vs. this multi-bar comparative breakdown) and from every input-manipulation hero (r1 console, r3c slider calculator, r6c estimate certificate, r4c compare tabs). Each bar is independently selectable via click or a roving-tabindex arrow-key pattern (`role="tablist"`/`role="tab"`, one tab-stop, Arrow/Home/End navigation) and swaps an adjacent evidence panel to that channel's real finding sentence — manipulation here explores an existing result rather than generating one, satisfying the r3 "manipulation = felt value" principle on real data instead of decoration. The equalizer card also keeps the matched product's photo, verified-seller line, and before/after price permanently on file beneath the chart, so product + proof stay in the first fold per the r2 learning. The product-preview section ships four parallel rich cards (overcoat, tote, denim jacket, boots), each always showing its match-score tag, condition grade, verified-seller badge, and before/after discount at rest (never hover/focus-gated, touch-safe per the r3/r6 learning) — hover/focus adds a purely additive fourth interaction (color intensify + icon micro-scale on the already-visible "strongest channel" line), on top of scroll-triggered `whileInView` reveals used throughout and the hero bar-selection/count-up pair, giving four distinct interaction types total. Copy is English-only, near-monochrome with the single `#6E56CF` accent always present at rest, exactly three font weights (400/600/800 via Tailwind classes only, no `next/font` import), the three-tier tracking scale (eyebrow/caption/stat), and a `<lg`/`lg:` clamp split on both the hero and closing headlines to avoid 375px overflow.
