run: `auto-landing-r7` · target: `landing` · date: 2026-07-28 · routes: `/landing-evolve/r7/{a,b,c}`

## 후보 개요
- **a — "Split-Flap Departure Board"**: 공항/기차역 스플릿플랩(솔라리) 보드 은유의 히어로. 카테고리 탭(Outerwear/Bags/Shoes/Tops)을 전환하면 4행 매물 테이블(매칭%·등급·가격)이 결정론적 스크램블-정착 애니메이션으로 재생·재계산된다. output-visualization + 탭 조작 결합형.
- **b — "Confidence Equalizer"**: 5개 매칭 기준(Taste/Size/Budget/Grade/Price)을 세로 바 차트로 분해해 보여주는 output-visualization형 히어로. 바 선택(roving tabindex)이 근거 패널을 실시간 갱신하고 총점이 tabular-nums 카운트업된다.
- **c — "AI Annotation Scan"**: 실제 제품 사진 위에 5개의 포커스 가능한 주석 핀을 배치해 AI가 실제로 검사한 항목(원단·재봉·태그·마모·색상)을 순차 공개하는 output-visualization형 히어로. 핀 선택 시 근거 문장 + 러닝 매칭 스코어 카운트업.

## 하드게이트 (SCORES.md 상세)

## 스크린샷 재촬영 — 1차 캡처 결함 발견·수정
1차 캡처(`waitUntil:'load'` + 600ms 대기, 스크롤 없음)는 (1) a의 flap-board 스크램블이 최대 지연 ~864ms로 아직 정착 전 상태를 포착했고 (2) `whileInView` 스크롤 리빌 섹션이 전혀 스크롤되지 않아 히어로 아래 전 섹션이 빈 화면으로 촬영됨(3후보 전부 동일 증상 — 후보 결함 아님). 스크롤-스루 패스(350px 스텝, 90ms 대기) + 히어로 정착 대기(1.6s)를 추가해 12장 전부 재촬영. 이 결함으로 최초 1회 lens1·lens2 판정을 폐기하고 재실행했다(아래는 재촬영본 기반 최종 판정만 기록).

또한 이 샌드박스의 아웃바운드 네트워크 정책이 임의 외부 이미지 CDN(Unsplash/Picsum 등)을 차단함을 확인(`$HTTPS_PROXY/__agentproxy/status`에서 403 gateway rejection 확인) — 3후보 전부 제품 사진이 스크린샷에서 빈 박스로 렌더링되나 이는 프로덕션에서는 재현되지 않는 샌드박스 한정 결함이라 judge에게 명시 고지하고 사진 자체의 부재는 감점 대상에서 제외하도록 지시했다.

## 3렌즈 판정 (블라인드 — 재촬영 스크린샷 4폭 + 소스 기반, 서로 독립, 이미지 CDN 차단 고지 포함)

### 렌즈1 — DNA 준수 (brief 렌즈)
**순위: a > c > b**
- a(1위): 라이브 플랩보드 자체가 에디토리얼 밀도 장치(ghost "01", Fig.01-04 캡션)이자 3카드 프리뷰가 match%/등급/인증/할인 전부 상시노출, 카피가 hover 종속을 전혀 주장하지 않아 카피-코드 간 괴리가 없음.
- c(2위): "no hover required to see the proof" 카피로 상시노출 원칙을 가장 명시적으로 재확인하고 핀 인터랙션이 실제 접근성 버튼(aria-label)이나, 히어로 장치가 단일 사진+핀이라 a/b보다 데이터 밀도가 낮고 카드에 스크림 그라데이션이 하나 더 있음.
- b(3위): DOM 자체는 상시노출을 지키나(hover는 강조색만 강화) ProductPreview 카피가 "Hover or focus a card to see which channel carried it"라고 명시해 브리프의 "hover 종속 리빌 금지" 프레이밍과 카피 차원에서 정면으로 충돌 — 코드는 준수해도 카피가 DNA와 어긋나는 유일한 후보.

### 렌즈2 — 상용 완성도 + 에셋·인터랙션 풍부도
**순위: b > a > c**
- b(1위): `Equalizer.tsx`의 5채널 바 차트가 진짜 결과-분해 위젯(장식 아님) — 매칭 스코어가 어떻게 구성됐는지 시각적으로 설명하며 데스크톱에서 가장 Stripe급 완성도. 모바일 카드에 alt텍스트-배지 겹침 2건.
- a(2위): 사진 차단과 무관하게 히어로 가치 전달이 3초 내 완결(탭 전환 → 테이블 재계산), 정착 상태 가독성 확보. 모바일 카드에서 alt텍스트-배지 겹침 1건.
- c(3위): "Nothing escapes the scan" 카피는 강하나 히어로 전체가 사진에 의존적이라 사진이 없으면 핀만 떠 있는 빈 사각형으로 읽힘 — 3후보 중 "사진 단독 의존" 위험이 가장 큼. 모바일 카드 alt텍스트-배지 겹침 3건(최다).

### 렌즈3 — 아키타입 차별성 (구조적 신규성)
**순위: c > b > a**
- c(1위): 실제 제품 사진 위에 직접 얹는 주석 핀 탐색 장치는 기존 어떤 폼(콘솔·다이얼·증명서·타임라인·필름스트립 등)에도 없던 진짜 신규 구조 — output-visualization 축에서 가장 신선.
- b(1위 동률 아님, 2위): 5채널 바 차트 분해는 신규 지오메트리(첫 바/이퀄라이저형)이나 "단일 매물 스코어 위젯" 계열 자체는 r5a(다이얼)와 같은 상위 범주.
- a(3위): 카테고리 탭이 데이터 테이블/보드를 재계산하는 구조는 r4c(비교표+탭)·r1a(라이브 콘솔)의 재조합에 가까워 스킨(플랩보드)만 신규 — 구조적으로는 가장 재탕.

## 집계 — 완전 3파전 동률

| 1위 | a | b | c |

1위표가 a/b/c에 정확히 1표씩 분산된 **완전 동률**. [[curation-criteria]] 축적 기준(2026-07-25, Q2 답변)의 3파전 동률 tie-break 규칙 적용: *"완전 동률 시 brief 렌즈(렌즈1) 우선을 유지하되, archetype 렌즈(렌즈3)가 그 후보를 최하위로 명시 판정했으면 동률 우승서 제외하고 나머지 중 brief 1위 재적용."*

- 렌즈1(brief) 1위 후보 = **a**.
- 렌즈3(archetype)의 a 순위 확인 → **3위(최하위)**. → 제외 조건 **성립**.
- a를 동률 우승서 제외 → 나머지 {b, c} 중 렌즈1(brief) 우선순위 재적용: 렌즈1 순위(a > c > b)에서 a를 제외하면 **c > b**.
- 따라서 예외 적용, 재적용 결과: **승자 = c**.
