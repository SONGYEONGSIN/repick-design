# Business / 창의 / c — 인터랙티브 셀러 대시보드 투어

## 컨셉

일반적인 B2B 랜딩은 스크린샷이나 일러스트로 "이런 기능이 있어요"라고 설명한다. 이 후보는 설명 대신
**실제로 만져보게** 한다. 랜딩 페이지 안에 4단계(재고 관리 → AI 프라이싱 → 매칭 현황 → 정산 리포트)로
구성된 셀러 대시보드 목업을 넣고, 각 화면 위에 번호가 매겨진 핫스팟(초록 pin)을 12개 배치했다.
방문자가 핫스팟을 클릭하면 우측 정보 패널에 해당 기능의 이름·핵심 지표·설명이 카드로 나타난다.
가입도, 로그인도 없이 "지금 이 화면에서" 제품을 체험하는 셀프 데모다.

## 왜 새로운가

- 정적 스크린샷/영상 대신 **클릭 가능한 라이브 목업**을 랜딩 안에 직접 심었다 — 실제 대시보드를
  써보는 것 같은 감각을 준다.
- 핫스팟은 대시보드 UI의 실제 위치(아바타 아이콘, 상태 배지, 슬라이더, 차트, 타임라인 등)에
  붙어 있어 "설명"이 아니라 "발견"에 가깝다.
- 우측 정보 패널은 체크리스트 + 진행률(단계별 N/3, 전체 N/12)을 겸해, 방문자가 얼마나
  탐색했는지 스스로 확인하며 끝까지 둘러보게 만드는 게임적 요소를 준다.
- 탭 전환·핫스팟 클릭·이전/다음 네비게이션·진행 dot까지 모두 키보드/스크린리더로 접근 가능한
  형태로 설계해 데모 UI이면서도 실전 배포 기준을 충족한다.

## 구조

1. 헤더: repick Business 로고 + 내비(제품 둘러보기/도입효과/도입문의) + 데모 요청 CTA
2. 히어로: "가입 없이, 지금 대시보드를 눌러보세요" — 인터랙티브 데모 배지, 스크롤 CTA
3. 투어 섹션(`#tour`): 4단계 탭 + 브라우저 크롬 프레임 목업(핫스팟 pin) + 우측 정보 패널
   (기능 체크리스트 + 선택된 핫스팟 설명 카드) + 이전/다음 + progress dot
4. ROI 섹션: 재고 회전 −42%, AI 매칭 정확도 94%, 전환율 ×2.3, 회수율 87%
5. 고객사 로고 스트립(CSS 텍스트)
6. 데모 요청 폼(회사명/담당자명/이메일/문의내용)
7. 푸터

## 기술 메모

- `'use client'` 컴포넌트, `useState`로 `activeStep` / `activeHotspot` / `visited`(단계별 방문 핫스팟 배열) 관리
- 핫스팟은 대상 요소를 `relative` 래퍼로 감싸고 pin을 절대 위치(`-top-2.5 -right-2.5`)로 붙이는 방식이라
  뷰포트 크기와 무관하게 항상 대상 위에 정확히 고정된다(좌표 % 방식의 취약점 회피)
- 접근성: `role="tablist"/"tab"/"tabpanel"`, `aria-selected`, `aria-controls`, 핫스팟 `aria-pressed` +
  `aria-label`, 정보 패널 체크리스트가 핫스팟의 키보드 대체 경로 역할
- 오프라인 렌더: 외부 이미지 없음, CSS 도형 + 이모지(🖱️🔔⬇🧾)로 시각 요소 구성
