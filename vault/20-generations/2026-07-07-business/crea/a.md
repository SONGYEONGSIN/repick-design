# Business · 창의 · a — 재고 회전율 ROI 시뮬레이터

## 컨셉

B2B 랜딩의 관습(히어로 카피 → 기능 나열 → 가격 문의)을 뒤집어, **계산기를 히어로 그 자체**로 세운다.
셀러/기업 방문자가 "월 판매 재고량"과 "평균 판매 단가" 두 값만 입력하면(`'use client'`,
`requestAnimationFrame` 기반 카운트업 애니메이션), repick Business 도입 시 예상되는

- 재고 회전율 개선 (업계 평균 2.1회/월 → 개선 배율 1.62배 적용)
- 월 예상 추가 매출
- 월 보관비용 절감액
- 연간 예상 총 효과

를 실시간으로 다시 계산해 "원장(ledger)"처럼 보여준다. 계산 가정치(회전율 평균, 개선율, 보관비용률)는
숨기지 않고 카드 하단에 명시해 신뢰를 얻는다 — 블랙박스 AI 약속이 아니라 **투명한 산식**으로 도입을 정당화.

## 시각 언어

- 톤: Industrial/Utilitarian × Editorial 믹스 — "재무 원장·터미널" 은유.
- 배경: 짙은 그린-블랙(`#08110d`) + 미세한 가로선 반복 패턴(회계 장부 라인 은유, 40px 간격, 5% 옵서큐리티).
- 강조색: 민트 그린(`#6ffcb2`, 수익/개선), 앰버(`#ffb454`, 절감/비용 관련) — 색 자체가 "이익 vs 비용 절감"을 구분하는 정보 신호로 기능.
- 숫자는 전부 `font-mono`로 원장 특유의 고정폭 숫자 정렬감을 살림 (Geist Mono, 오프라인 기본 폰트 재사용).
- 슬라이더는 `accentColor`로 민트 통일, range + number input 동시 제공(정밀 입력 + 직관 조작 모두 지원).

## 구조

1. 히어로 = ROI 계산기 (2열: 입력 패널 / 결과 원장). 최상단에서 바로 "숫자로 증명"을 시작.
2. 파트너 스트립 (CSS 텍스트, 익명화된 업종 라벨 — 실존 브랜드 미사용).
3. 셀러 도구 3종 (AI 매칭 판매 / 실시간 대시보드 / API 연동).
4. "숫자로 증명된 효과" — 계산기 결과와 같은 톤의 요약 통계 3종 재확인.
5. 데모 요청 폼 (회사명/담당자/이메일/연락처, 클라이언트 사이드 제출 확인만 — 오프라인 렌더 제약 준수).

## 차별점

경쟁 B2B 랜딩 대부분은 "문의해 주세요" CTA 하나로 끝난다. 이 후보는 **방문자가 직접 숫자를 만져보게** 해서
"우리 회사라면 얼마나 벌 수 있는가"를 스스로 답하게 만들고, 그 결과값을 그대로 들고 데모 요청으로 넘어가게 한다.
