# Business · Creative · f — 셀러 온보딩 여정 스텝

**컨셉**: "가입 → 재고 연동 → AI 매칭 시작 → 첫 판매"까지 셀러가 실제로 밟는 4단계 여정을 인터랙티브 스텝퍼(`'use client'`)로 보여준다. 각 노드를 클릭하면 해당 단계의 소요시간·설명·결과 지표가 상세 패널에 즉시 반영되고, 확인한 단계 수만큼 상단 진행률 바가 채워진다 — "시작이 이렇게 쉽다"를 설명이 아니라 체험으로 증명하는 B2B 랜딩.

- 경로: `app/src/app/pages/business/crea/f/page.tsx`
- 컴포넌트: `Landing` (default export)
- 인터랙션: 스텝 노드 클릭 / 이전·다음 버튼 / 진행률 바(방문한 단계 비율) / 데모 요청 폼 제출(로컬 상태로 완료 화면 전환)
- 구성: 헤더 → 히어로 → 여정 스테퍼(4단계 상세 패널) → 성과 지표 3종 → 파트너 로고 스트립(CSS 텍스트) → 데모 요청 폼 → 푸터
- 오프라인 렌더: 외부 이미지/폰트 CDN 미사용, 유니코드 체크마크/화살표만 사용
