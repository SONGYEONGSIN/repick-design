## 방향
기존 생성물·챔피언·design-principles DNA를 전부 무시하고 백지에서 시작. 배정된 아키타입 "브루탈 코퍼레이트"를 코스튬처럼 끝까지 밀어붙였다 — 초대형 컨덴스드 타이포(대문자, `tracking-tighter`, `font-black`, `text-8xl`급), 굵은 흑백 블록(`border-2`~`border-4` 각진 보더, 라운딩 전무), 노출 그리드(고정 세로 가이드라인 + 섹션마다 배경 워터마크 큰 숫자 01~04), 큰 숫자 지표를 accent red로 강조, 각진 버튼(호버 시 흑/백/레드 반전), 직설적 카피("감이 아니라 데이터로 판다", "숫자로 증명한다")로 "숫자로 말하는 B2B"를 구현.

## 고른 참조
- 외부 레퍼런스 없음. 스위스 그리드 시스템 / 브루탈리스트 연차보고서(annual report) 미학을 참조 소스로 삼되 실제 이미지·폰트는 사용하지 않고 Tailwind 유틸리티만으로 구현.
- `pages-content.md`의 Business 브리프(히어로 가치제안 / ROI·지표 / 셀러 도구 / 고객 로고 스트립 / 데모 요청 폼)를 그대로 구조에 반영.

## 핵심 결정
- 배경을 화이트 페이퍼(`oklch(98% 0 0)`)로, 텍스트를 잉크 블랙(`oklch(14% 0 0)`)으로 설정 — 기존 다크 톤 variant들과 극단적으로 다른 극명한 대비 선택.
- 단일 accent는 강렬한 레드(`oklch(57% 0.22 29)`) 하나만 사용, 지표 숫자·구분자·CTA에만 집중 배치해 "경고/강조" 신호로 기능하게 함.
- 헤더 하단에 KPI 마퀴 티커(무한 스크롤, `prefers-reduced-motion` 대응)를 추가해 "숫자로 말한다"는 컨셉을 스크롤 전부터 각인.
- 클라이언트 스트립 섹션만 흑백 반전(잉크 배경 + 페이퍼 텍스트)한 "스탬프 밴드"로 처리해 리듬 변화를 줌.
- 모든 보더는 각진 2~4px 굵은 선(`rounded` 클래스 일체 미사용)으로 통일, 얇은 헤어라인 대신 블록 대비로 "코퍼레이트 리포트" 인상을 강화.
- 폰트는 시스템 산세리프(`font-sans`) 그대로 사용하되 `font-black` + `uppercase` + `tracking-tighter` 조합으로 컨덴스드 임팩트를 대체 구현(외부 폰트 CDN 금지 제약 준수).

## 사용 font-weight
- font-bold (700) — 라벨, 배지, 보조 텍스트, 카피
- font-black (900) — 헤드라인, 통계 수치, 섹션 타이틀, 버튼, 클라이언트 워드마크

## 색 hex (oklch → 근사 hex)
- 배경(paper): oklch(98% 0 0) ≈ #FAFAFA
- 전경(ink): oklch(14% 0 0) ≈ #1F1F1F
- accent(red): oklch(57% 0.22 29) ≈ #D0301B
