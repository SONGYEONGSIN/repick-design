# auto-landing-r11 후보 b — Cutline

**한 줄 컨셉**: 24개 매물이 (컨디션 점수 × 가격) 평면에 흩어져 있고, 사용자가 대각선 임계선의 **양 끝을 각각 끌어** "최악 컨디션에 낼 값 / 최고 컨디션에 낼 값"을 정하면 필드가 갈린다. 탈락한 매물은 사라지지 않고 **속이 빈 링으로 제자리에 남아**, 옆의 ledger 가 "네 규칙이 지금 얼마를 포기시키고 있는지"를 금액으로 적는다. **필터는 자기 비용의 증거를 지우지만, 선은 못 지운다** — 그게 리스트로 대체 불가능한 이유다.

**초기 상태에서 이미 자르고 있는 것** (`r9/c` delta 대응) — 기본값 base $170 / top $280, 천장 = `170 + 2.973 × (condition − 62)`. **24개 중 7개가 조작 전에 이미 선 위에 있다**:

| 매물 | 초과 |
|---|---|
| Shearling Winter Boots (85점 / $244) | **$6 over** |
| Down Mountain Parka | $29 |
| Waxed Canvas Duffle | $36 |
| Cotton Gabardine Trench · Field Watch · Top-Handle Bag · Cashmere Wrap Coat | $59 · $75 · $122 · $151 |

그리고 **필드 전체 최고 매치(97%) Cashmere Wrap Coat 가 선 위**에 있어, 첫 화면 요약 문장이 이미 "가장 강한 매치가 네 선 밖에 있다"를 말한다. 가장 아까운 탈락작(6달러 차)에 라벨칩이 붙어 있어 **아무도 건드리지 않은 화면이 스스로 논증한다.**

**인터랙션 — 동시 갱신 8면**

| 조작 | 갱신 |
|---|---|
| base 핸들 드래그 + 방향키/PageUp/Home·End (`role=slider`) | 24점 통과/탈락 · 킵존 폴리곤+기울기 · `17 of 24` 카운트 · 3스탯 · ledger 3행+`and N more` · 숏리스트 4장의 **구성과 순서** · 카드별 `$X under`+헤드룸 바 · 요약 문장(aria-live) = **8면** |
| top 핸들 | 동일 8면 (기울기가 바뀌어 고컨디션 매물만 선택적으로 되살아난다) |
| 프리셋 Tight/Balanced/Open | 동일 8면 — 드래그 안 하는 심사자용 1클릭 시연 |
| Verified sellers only 토글 | 8면 + 탈락 사유가 `$X over` → `Unverified` 로 바뀌고 ledger 라벨 교체 |
| ledger 행 hover/focus | 해당 점 1.55배 확대 + 링 강조, 필드 라벨칩 전환 |
| 카드 hover/focus | 같은 결속 — **표↔플롯 양방향** |
| 스크롤 리빌 · 인용부호 시차(±28px, 텍스트 미탑승) | 연출 |

`motion-reduce` 시 `initial={false}` 로 진입 상태 자체를 건너뛴다(잔존 `opacity:0` 없음).

**390px 대책** ★ — **플롯을 SVG 좌표가 아니라 % 절대배치 HTML 로 그렸다.** 점(12px)·핸들(56×28px)·라벨·축 숫자가 전부 CSS px 라 뷰포트가 줄어도 **물리 크기가 안 줄어든다.** SVG `<text>`/`<circle>` 이었으면 viewBox 스케일에 눌려 5px 글자와 24×24 미달 타깃이 됐을 것이다 — 부수 효과로 "SVG text 대비 문제" 자체가 사라진다. SVG 는 그리드/킵존/선만 담당하고 `preserveAspectRatio="none"` + `vector-effect="non-scaling-stroke"`. 좌우 패딩 12% 대칭으로 **양 끝 핸들이 334px 패널 안에 완전히** 들어온다. 종횡비 3단(`5/4` → `sm:16/9` → `lg:2/1`), 핸들에 `touch-action: none`, 데이터 좌표를 흩어 최소 간격이 모바일에서도 x 4%(13px) 이상.

**본문 폭** — 컨테이너 `max-w-[1180px]`, 문단 캡 `max-w-[32rem]`=512px. 15px Pretendard, 평균 advance ≈0.5em ≈7.5px → **512/7.5 ≈ 68자**(상한 75 아래 9% 여유). 34rem 이면 ≈72.5자로 3%밖에 안 남아 한 단계 줄였다 — **폭 검증의 "딱 맞음은 실패" 원칙을 줄 길이에도 적용**.

## 브리프에 없던 것

**① 두 축이 무엇인가** — ② 가로=AI 컨디션 점수(62~99), 세로=호가($20~$500) ③ 세로를 가격으로 두면 임계선이 `ceiling(condition)` 함수가 되어 **"이 품질이면 이만큼까지 낸다"는 문장으로 읽히는 규칙**이 된다. 반대로 두면 같은 뜻이지만 카피가 어색해진다. **임의**

**② 임계선의 자유도** ★ — ② 값 하나가 아니라 **양 끝 핸들 2개**(오프셋+기울기) ③ 값 하나면 수평선이라 사실상 1차원 컷이 되어 **`v11`(1차원 순위)과 논증이 겹친다.** 두 끝을 따로 끌면 "컨디션 1점당 얼마"라는 **기울기 자체가 사용자 선호**가 되고, 그때만 2차원 좌표가 필요해진다. **중복 금지 도출**

**③ 핸들 값 범위와 스텝** — ② base [140,340] / top [220,480], 스텝 $5, PageUp $25, 최소 간격 $40 ③ 데이터에서 역산 — 최저 위치에서도 12개 이상·검증판매자 4명 이상이 남아 **숏리스트 4장이 절대 비지 않고**, 최고 위치에서는 전 매물 통과해 "선이 예산보다 넓다" 빈 상태가 뜬다. 최소 간격 $40 은 기울기가 음수가 되는(좋은 물건에 돈을 덜 내는) 무의미한 규칙을 막는다. **역산**

**④ 탈락 표시 방식** — ② 채움 원 → **속 빈 링**(테두리 2px zinc-500) + opacity 0.70 + 위치 + ledger 텍스트 라벨 ③ "색만 금지"를 **형태·투명도·위치·라벨 네 가지로 동시에** 충족. zinc-500(4.84:1)은 **비텍스트 3:1 하한을 넘기는 가장 옅은 회색**(zinc-400 은 2.62:1 미달). **조항 도출 + 계산**

**⑤ accent 선택과 대비** — ② lime-700 `#4D7C0F`(채움·선·막대) + lime-800 `#3F6212`(소형 텍스트·포커스) + lime-100 `#ECFCCB`(킵존 워시) ③ 금지 목록 중 가장 덜 쓰인 축(lime 1건). 직접 계산: lime-700 위 **흰색 5.00:1 통과 / 어두운 잉크 3.93:1 미달** → 채움 위 소형 텍스트 전부 흰색(`r10/a` 를 세 번째 accent 에서 재유도). lime-800 은 흰 배경 7.07:1 이라 11px 액센트 텍스트에 안전. **직접 계산**

**⑥ 숏리스트 카드의 정의** — ② "현재 통과한 매물 중 매치 상위 4개", 사진 없이 스펙시트 ③ `r6/a` 를 지키되 카드 구성이 선과 함께 **바뀌게** 만들어 조작이 카드까지 재계산하도록. 사진을 뺀 것은 `r7/c` 판정 + 게이트 리스크. 대신 카드마다 헤드룸 바를 넣어 사진 자리를 **선과의 관계**로 채웠다. **delta 도출**

**⑦ ledger 정렬 기준** — ② 초과액 오름차순(동률 시 매치 내림차순), 상위 3행 + `and N more` ③ **"가장 아깝게 놓친 것"이 맨 위**에 오면 선을 조금만 올려도 되찾을 수 있다는 사실이 즉시 읽힌다. 큰 금액 순이면 절대 못 살 물건이 먼저 와서 조작 동기를 못 만든다. **임의**

**⑧ 검증 토글의 탈락 사유 표기** — ② `$X over` 대신 `Unverified` 로 라벨 교체, 카드 판매자 행도 `ShieldAlert + Unverified` 로 분기 ③ 같은 "탈락"이라도 이유가 다르면 다음 행동이 다르다(선을 올릴지, 토글을 끌지). **관행**

**⑨ 포커스 표시** — ② `focus-visible:outline-2 outline-offset-2 outline-lime-800`(잉크 밴드에선 `outline-lime-300`), `outline-none` 전면 미사용 ③ 명명 색 유틸을 쓴 것은 임의 hex 가 색/폭 추론에 걸릴 여지를 없애기 위해. **클리핑 방지를 위해 핸들·점을 `overflow-hidden` 레이어 바깥에 형제로 배치**했다(아웃라인이 잘리지 않게). **정본 함정 도출**

**⑩ 점을 키보드 대상에서 뺀 것** ★ — ② 24개 점은 `aria-hidden` 장식, 동일 정보는 ledger 버튼·카드에서 키보드 접근 ③ **`target-size`(24×24)가 하드페일 감사라 12px 점 24개를 포커스 가능하게 두면 390px 에서 확실히 깨진다.** 점이 유일한 정보원이 아니게 설계해 정보 손실 없이 탭 순서를 8개 컨트롤로 유지. **게이트 역산**

**⑪ 웨이트 3종의 구체값** — ② 400 / 600 / 800 ③ `<strong>`·`<b>`·`<th>` 같은 UA 기본 bold(700) 요소를 **한 개도 안 쓰는** 방식으로 미지정 기본까지 3종에 고정. 강조는 전부 `font-semibold` 스팬. **정본 이행**

**⑫ 브랜드·카피** — ② "Cutline", 헤드라인 `Draw the line. / See what it costs.` ③ 형태(임계선)와 논증(그 선의 비용)을 한 단어에 담고, 히어로 카피가 곧 이 작품이 리스트와 다른 이유를 말하게 두 문장으로. **임의**

**⑬ 결정론** — ② 24개 좌표·점수·할인율이 전부 모듈 상수, 파생값은 순수함수, **`toLocaleString` 대신 수동 천단위 그룹핑** ③ `toLocaleString` 은 서버/브라우저 ICU 차이로 문자열이 갈릴 수 있어 **하이드레이션 불일치**를 만든다. **관행 + 게이트 역산**
