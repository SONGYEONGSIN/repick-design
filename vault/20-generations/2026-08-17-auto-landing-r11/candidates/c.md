# auto-landing-r11 후보 c — Running Ledger

**한 줄 컨셉**: 한 건의 거래에 대해 "검수가 없었다면 잃었을 돈"을 항목별로 기장한 **결산이 끝난 장부**를 첫 화면에 제시하고, 스크롤은 그 총액이 **어디서 나왔는지를 증빙으로 분해**한다. 장부를 고른 이유는 논증이 "신뢰"가 아니라 **금액**이기 때문 — 금액은 열끼리 대조하는 게 아니라 한 열로 합산돼 하나의 결론에 도달한다(그래서 `v7` 비교표로 퇴화하지 않는다).

**스크롤 0 지점** — `r9/c` delta 를 **역전 구조**로 풀었다. 총액이 주어져 있고 스크롤이 하는 일은 그 총액의 **출처를 증명**하는 것이다:
- 왼쪽: h1 `Every check we run has a number attached.` → 액센트 룰 안에 `Protected on this one order` + **`$435`**(display-wide, clamp 4.25rem) → `48x the $9 inspection fee`
- 오른쪽: **장부 카드 전체가 이미 펼쳐져 있다** — 4항목(`+$40`·`+$85`·`+$310`·`$0`), 점유율 바, 총계 푸팅, 컨트롤 3종
- 아래 행: 풀태깅 매물 4장(match%+근거 · 등급+노트 · 인증+실적 · 정가/할인가/할인율 전부 상시노출)

감사 구간의 sticky 바가 `$X of $435 evidenced` 로 **총액을 항상 동반**해 0/35/70/100% 어느 캡처 지점에도 결론이 화면에 있다. `audited` 카운터는 `current` 를 0으로 초기화해 홀로 `$0` 이 찍히는 프레임이 없다.

**인터랙션 — 스크롤 외 4종 (요구 3종 초과)**

| 조작 | 동시 갱신 면 |

## 브리프에 없던 것

**a. 액센트 hex 확정** — ② teal `#0F766E`(+딥 `#0B4F4A`, 틴트 `#E3F1EF`) ③ 회피 목록 중 장부/회계 도메인에 의미가 붙는 유일한 축이고, **직접 계산**했다: 흰 배경 5.47 · 페이퍼 5.01 · 틴트 위 4.72 — 전부 본문 AA 통과라 **한 hex 를 소형 텍스트·채움·보더에 전부** 쓸 수 있다. 파생 틴트가 불필요해 near-monochrome 이 더 깨끗해진다. **임의 + 직접 계산**

**b. accent 채움 위 잉크 색** — ② 흰색 ③ 실측 흰색 on `#0F766E` = **5.47:1**, 어두운 잉크 = **2.63:1**(대형 3:1 기준조차 미달). **violet 에서보다 격차가 더 크다** — 정본 §Color Tokens 의 "어두운 잉크" 조항이 이 accent 에서도 반대다. `data.ts` 팔레트 주석에 4개 실측치를 남겼다. **`r10/a` delta 이행 + 독립 재확인**

**c. 포커스 표시 관용구** ★ — ② `focus-visible:outline-2 + outline-offset-2 + outline-[#0F766E]` **+ `focus-visible:shadow-[0_0_0_3px_#C7E7E2]`** ③ `outline-none` 을 **어디에도 안 쓰고**(자기취소 회피) `ring`+`ring-offset` 도 안 쓴다(v4 투명). 둘 중 하나가 엔진에서 죽어도 나머지가 픽셀을 그리도록 **outline 과 box-shadow 를 이중으로** 걸었다 — 소스 리뷰로 안 보이는 결함이라 중복이 정당하다. **정본 함정 도출 + 방어적 중복**

**d. 폰트 웨이트 3종 배정** — ② 400(미지정 기본) / 600 / 800 ③ Tailwind preflight 가 `h1~h6` 를 `font-weight: inherit` 로 리셋하므로 미지정 렌더 굵기가 400 하나로 수렴한다. `font-medium`(500)·`font-bold`(700)를 **한 번도 안 썼고** `<strong>`/`<b>`(preflight `bolder` 잔존)도 전 파일에서 배제했다. **정본 + 프레임워크 실측**

**e. 본문 폭 / 줄 길이** — ② 컨테이너 `max-w-[1180px]`, 문단 `max-w-[58ch]~[62ch]` ③ `ch` 로 못 박으면 **활자가 바뀌어도 상한이 따라온다** — px 환산은 폰트 교체 때 같은 숫자가 다른 줄 길이를 낳는다. 1180 은 히어로 12-col 비대칭(5/7)용이지 문단 폭이 아니다. **정본 지시 이행**

**f. 4번째 항목의 `$0` 처리** ★ — ② `$0` 을 그대로 쓰고 총액에 합산하지 않으며, 토글 대신 자물쇠 칩 `Nothing you could have caught` ③ 0을 총액에 녹이면 총액은 커지지만 장부의 신뢰가 죽는다. 감사 블록 본문에 **"A ledger you can trust has to be able to write a zero"** 로 0 자체를 논거로 썼다. 이 행만 토글이 없는 것이 "숙련도로 막을 수 없는 손실"이라는 별도 논점을 만든다. **임의**

**g. 항목별 토글의 의미론** ★ — ② **"I would have caught this"** — 회의적인 방문자가 자기 안목으로 해당 항목을 스스로 상각하는 제스처 ③ 켜기/끄기 필터가 아니라 **반론을 초대하는** 조작이라 논증이 강해진다(둘을 상각해도 `$310` 이 남고 배수 34x). 형태가 사진 레이어가 아니라 장부 상각이라 `v12` 와 안 겹치고, 열을 안 늘리므로 `v7` 로도 퇴화하지 않는다. **임의**

**h. 수수료·배수 산식** — ② `fee = max($9, round(주문금액 × 2%))`, 배수 = `round(총액/fee)` ③ 슬라이더가 움직여도 배수가 **함께 변해야** 조작이 논증을 강화하므로 분모를 상수가 아닌 함수로. 하한 $9 는 저가 주문에서 배수가 비현실적으로 폭발하는 것을 막는다. **임의**

**i. 금액 스케일링 규칙** — ② 기준가 대비 선형 비례 후 **$5 단위 반올림** ③ 실제 인보이스에 나올 수 없는 `$41.7` 을 막고, 기준가에서는 정의값과 정확히 일치한다(전부 5의 배수로 설계). `Math.round` 만 쓰므로 결정론 유지. **임의**

**j. 스크롤 리빌을 쓰지 않기로 한 결정** ★ — ② **콘텐츠에 `opacity:0` 진입을 하나도 안 썼다.** framer-motion 은 진행바 · 점유율 바 `scaleX`(`initial={false}`) · `onViewportEnter` **상태 갱신**에만 ③ 캡처가 4개 스크롤 지점을 픽셀로 판정하고 **리빌 미발동이 곧 빈 프레임**이 된다. 스탬프도 숨김→표시가 아니라 `Further down` ↔ `Evidence read` **두 상태 모두 가시**로 만들어, JS 가 죽어도·reduced-motion 에서도·언제 찍혀도 완전한 콘텐츠가 나온다. **게이트 역산**

**k. 카테고리 3종 선정** — ② Sneakers / Handbag / Outerwear ③ 레포에 주제가 검증된 고정 unsplash 사진이 있는 품목으로 맞췄다. 시계는 통제된 사진이 없어 `no-random-image-host` 의 취지에 걸릴 위험이 있고, 사진 없이 넣으면 다른 둘과 증빙 밀도가 어긋난다. **레포 자산 참조**

**l. 모바일 첫 폴드 순서** — ② 390px 에서 카피+총액 → **매물 레일(가로 스냅)** → 장부 카드. `lg` 부터 명시 `col-start`/`row-start` 로 카피(5)+장부(7) ③ 정본의 "제품+증명은 첫 폴드"가 하드 조항이라 좁은 폭에서 매물을 장부보다 위로. 장부는 폴드에 걸쳐 시작하므로 결론은 이미 그 위에 있다. **정본 이행**

**m. sticky 바 배경 불투명** — ② 완전 불투명 `#F5F5F2`(반투명+blur 안 씀) ③ `color-contrast` 가 2차 승격 하드페일인데 **반투명 배경 위 텍스트는 axe 가 실배경을 확정 못 해** incomplete/fail 로 갈릴 수 있다. 스크롤 중 배경이 계속 바뀌는 요소라 위험이 상시적이다. **게이트 역산**
