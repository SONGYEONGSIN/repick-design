# Features — 발산 a — Bauhaus

원색 3색(빨강 #D22630 / 파랑 #1E4FA0 / 노랑 #FFCC00)과 검정·백지만 사용하는 정통 바우하우스 포스터 문법. 4개 핵심 기능(취향학습·AI매칭·신뢰검증·실시간알림)을 12-컬럼 그리드 위 비대칭 색면(7:5, 5:7)으로 배치하고, 각 카드를 단색 배경 + 큰 번호(01~04) + 원/삼각/사각 기하 아이콘의 CSS 미니 비주얼로 표현했다. 취향학습은 mix-blend-multiply로 겹치는 3원색 원, AI매칭은 3×3 그리드 중 하나를 링으로 타겟팅, 신뢰검증은 원+삼각+뱃지의 인장(seal) 구성, 실시간알림은 동심원 pulse(animate-ping)+알림 뱃지로 표현. 헤더·CTA·푸터까지 흑백 그리드선과 원색 포인트만으로 통일해 "기능이 아니라 포스터"처럼 보이게 밀어붙였다.
