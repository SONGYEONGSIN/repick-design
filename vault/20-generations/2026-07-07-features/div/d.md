# Features — 발산 d — 사이버펑크 HUD

- **경로**: `app/src/app/pages/features/div/d/page.tsx`
- **아키타입**: 사이버펑크 HUD (SF 전투 인터페이스)

## 컨셉

repick의 4개 기능(취향 학습 · AI 매칭 · 신뢰 검증 · 실시간 알림)을 "미래 전투기 조준 HUD가 부팅되어 리커머스 시스템을 스캔하는" 화면으로 재구성했다. 딥 블랙(#050608) 배경 위에 네온 시안(#00fff2)·마젠타(#ff2ee6)·앰버(#ffb800) 3색이 각 모듈을 식별하고, 전체 화면에는 스캔라인 오버레이와 수직으로 흐르는 스캔 빔이 상시 재생된다. 히어로 `<h1>`은 RGB 채널이 어긋나는 글리치 애니메이션을 CSS `clip-path` + `attr(data-text)` 트릭으로 구현했고, 4개 기능 패널은 모서리를 깎아낸 `clip-path` 각진 프레임 + 브래킷(⌐ ¬ L 형) 모서리 장식을 둘렀다. 각 모듈은 `MOD_0X :: CODE.NAME` 형태의 모노스페이스 데이터 라벨을 달고, 하단에는 CSS만으로 만든 미니 비주얼(취향 학습=펄스 바 그래프, AI 매칭=레이더 스윕, 신뢰 검증=인증 헥사곤, 실시간 알림=핑 레이더)이 통계 수치와 함께 배치된다. 히어로 하단의 리드아웃 스트립(ACTIVE MODULES / MATCH RATE / UPTIME)과 CTA 버튼의 hover 시 컬러 반전 채움 효과로 "시스템이 살아있다"는 느낌을 강화했다.
