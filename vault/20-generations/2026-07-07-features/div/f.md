# Features — 발산 f — 웹 1.0 / GeoCities 브루탈

90년대 초기 홈페이지를 아이러니하게 재현한 Features 페이지. 노란-검정 공사중 마퀴 배너, 별 타일 보라색 배경 위 무지개색 손글씨 h1, 3D 베벨(Windows 95 크롬) 네비게이션과 "800×600 최적화 / 넷스케이프 내비게이터 4.0 / 56K 모뎀 지원" 뱃지 줄, 4개 기능(취향 학습·AI 매칭·신뢰 검증·실시간 알림)을 낡은 "표" 스타일 창(제목 바 + 스펙 표)으로 나열하고 하나엔 회전한 반짝이는 "NEW" 딱지를 붙였다. 검정 배경에 LCD 그린 오도미터 방문자 카운터와 가짜 웹링 이전/랜덤/다음 링크, 시안색 밑줄 클래식 링크, 마지막은 핫핑크 CTA 섹션과 mailto 푸터로 마무리. Times New Roman 계열 세리프 본문 + Comic Sans 계열 제목 폰트(시스템 폰트만), 깜빡임/트윙클/마퀴 애니메이션은 `prefers-reduced-motion`에서 비활성화.
