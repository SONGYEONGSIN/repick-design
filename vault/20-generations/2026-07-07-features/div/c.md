# Candidate C — Features — 아르데코 극장 프로그램

**아키타입**: 아르데코(Art Deco) — 1920s 게츠비, 금색+짙은 녹/검정, 대칭 기하 장식, 선버스트·지그재그, 우아한 세리프, 사치스러운 이중 프레임

**핵심 컨셉**: 4개 기능을 "취향이 오르는 무대"라는 극장 프로그램(playbill)으로 재구성했다. 히어로는 대형 선버스트(repeating-conic-gradient)를 배경 삼은 금박 그라데이션 타이포("취향이 오르는 무대")로 막을 연다. 그 아래 "오늘의 상연 프로그램" 목차 섹션은 실제 옛날 극장 프로그램처럼 ACT I~IV 라벨과 점선 리더(dotted leader)로 각 막의 앵커 링크를 나열한다. 본문은 취향 학습·AI 매칭·신뢰 검증·실시간 알림을 각각 ACT I~IV로 명명해, 이중 금테 프레임(outline-offset 겹침) + 네 모서리 코너 선버스트 장식 안에 배치했다. 각 막은 공통 선버스트 메달리온 아이콘 외에 기능별로 다른 미니 CSS 비주얼을 갖는다 — 취향 학습은 부채꼴로 펼친 카드(♥ 찜·◈ 클릭·✦ 구매), AI 매칭은 다섯 개의 점이 한 줄기 빛으로 수렴해 다이아몬드 보석 하나가 되는 컨버전스, 신뢰 검증은 리본 달린 이중원 봉인(seal) 메달, 실시간 알림은 중심에서 퍼지는 동심원 펄스(reduced-motion 대응). 마무리는 "지금, 객석에 착석하세요" CTA를 같은 이중 프레임+코너 장식 카드로 감싸 금색 버튼으로 닫는다. 실전 UI 계층(h1 단일, 시맨틱 섹션/ol, focus-visible ring, sr-only 헤딩)은 유지하면서 시각적으로만 아르데코 극장 코스튬을 끝까지 밀어붙였다.
