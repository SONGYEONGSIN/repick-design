# Features · 창의 모드 · 후보 e

## 컨셉

**"이 가죽자켓이 당신에게 오기까지"** — repick의 4개 핵심 기능(취향 학습 · AI 매칭 · 신뢰 검증 · 실시간 알림)을 나열식 기능 소개가 아니라, 팔리지 않던 가죽자켓 한 벌이 한 사람의 옷장에 도착하기까지의 여정을 **상품 1인칭 시점**으로 서술하는 스크롤 내러티브로 재구성했다. 각 챕터는 감성적 문단(자켓의 독백)과 그 문단이 실제로 가리키는 기능의 명확한 설명 카드(제목 + 한 줄 설명 + CSS 미니 비주얼)를 나란히 배치해, "이야기로 읽되 기능은 정확히 안다"를 동시에 만족시킨다.

## 구조

1. **Hero** — h1 "이 가죽자켓이 당신에게 오기까지" + 여정 예고
2. **Ch.1 취향 학습** — 자켓이 태어나기 전부터 쌓인 사용자의 찜/클릭 흔적 회고 + 취향 히트맵 CSS 비주얼
3. **Ch.2 AI 매칭** — 수만 벌 중 몇 초 만에 골라지는 순간 + 매칭 바 차트(하이라이트 펄스) 비주얼
4. **Ch.3 신뢰 검증** — 상태/시세/판매자 검증을 받는 순간 + 3종 게이지 바 비주얼
5. **Ch.4 실시간 알림** — 가격 하락과 함께 울리는 알림 + 벨 핑 애니메이션 비주얼
6. **Closing** — 여정의 종착, 4개 기능 요약 그리드 + CTA

## 인터랙션

- 우측 고정 챕터 네비게이션(IntersectionObserver로 현재 챕터 하이라이트, 클릭 시 스무스 스크롤)
- 상단 얇은 스크롤 진행률 바
- 짝수/홀수 챕터 배경 명암 교차(크림 ↔ 다크 브라운)로 여정의 리듬감 부여
- 모든 애니메이션 `prefers-reduced-motion` 대응

## 톤 & 팔레트

가죽/빈티지/순환경제 은유에 맞춘 웜 뉴트럴 팔레트(크림 `#f6f1ea`, 잉크 `#2b2118`, 카멜 액센트 `#a85c32`) + 세리프(내러티브 타이틀) × 산세리프(UI/기능 카드) 조합. 완전 CSS 자체 구현(외부 이미지·아이콘 폰트 없음), 오프라인 렌더 가능.
