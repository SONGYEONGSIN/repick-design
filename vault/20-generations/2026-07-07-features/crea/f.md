# Features — 창의 후보 f

## 컨셉

"중고 살 때 고민을 기능으로 답하기" — 중고 구매자의 진짜 불안 네 가지("가짜면 어떡하지", "내 취향 아니면 어떡하지", "나만 비싸게 사는 거 아닐까", "좋은 매물 놓치면 어떡하지")를 Q&A 형식의 대화형 고민 선택기로 던지고, 사용자가 고른 고민마다 그에 대응하는 repick 기능(신뢰 검증 / 취향 학습 / 가격 추적 / 실시간 알림)을 답으로 제시한다. 기능을 스펙 나열이 아니라 "사용자가 이미 품고 있던 걱정에 대한 대답"으로 재구성한 서사 구조.

## 구조

1. 히어로 — "중고 거래, 사실 걱정이 한둘이 아니죠" 문제 제기
2. 고민 선택기 (인터랙티브 탭) — 4개 걱정 칩 선택 → Q(걱정) / A(기능명 + 설명 + 미니 시나리오 + CSS 비주얼) 패널 전환
   - 신뢰 검증: 검증 체크리스트 팝인 + VERIFIED 스탬프
   - 취향 학습: 취향 태그 + 매칭률 도넛(conic-gradient)
   - 가격 추적: 하락하는 바 차트 + "-18%" 하이라이트
   - 실시간 알림: 다크 카드 위 알림 버블 슬라이드인
3. 전체 요약 그리드 — 4개 고민×답을 한눈에 스캔 가능하게 재노출 (인터랙션 건너뛰는 사용자 대비)
4. 브릿지 스트립 — "이 네 가지가 가능한 이유는 AI 매칭 하나" (숨은 다섯 번째 기능을 엔진으로 연결)
5. 최종 CTA

## 비고

- 팔레트는 신뢰(emerald)와 긴급/알림(amber) 대비로 구성, cream(stone-50) 배경으로 기본 blue-600/gray-50 조합을 피함.
- 모든 비주얼은 CSS-only(conic-gradient, keyframes) — 외부 이미지/폰트 없이 오프라인 렌더.
- 탭 패턴은 `role="tablist"`/`aria-selected`/`aria-live`로 접근성 확보, 단일 h1 유지.
