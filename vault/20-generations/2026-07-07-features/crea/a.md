# Features — 창의 모드 후보 a

## 컨셉

설명을 읽게 하는 대신 **직접 만지게 한다**. Features 페이지의 핵심 기능 ①취향 학습을 실제로 체험할 수 있는 미니 플레이그라운드로 구현 — 사용자가 취향 태그(빈티지/미니멀/스트리트/러블리/클래식/스포티/오버사이즈/데님)를 토글하면, 12개 목업 매물 카탈로그가 실시간으로 재정렬되고 각 카드에 AI 매칭률(%)이 애니메이션 바로 표시된다. 태그를 하나도 안 고르면 "인기순" 기본 추천을, 태그를 고를수록 겹치는 태그 수 기준으로 매칭률이 계산되어 상위 6개만 노출된다. 일치 매물이 없으면 빈 상태 UI로 태그 조정을 유도한다. 나머지 3개 기능(AI 매칭 / 신뢰 검증 / 실시간 알림)은 CSS-only 마이크로 비주얼(필터 바, 체크리스트, 펄스 알림 벨)로 짧게 요약해 데모 섹션에 시선이 집중되게 했다.

## 왜 새로운가

일반적인 "기능 소개 + 스크린샷" 나열 대신, 페이지 자체가 기능의 작동 방식을 증명하는 **살아있는 데모**다. 방문자가 "취향 학습이 뭔가요"라는 설명을 읽는 게 아니라, 태그를 눌러보며 "아, 이렇게 매칭률이 바뀌는구나"를 스스로 발견한다.

## 기술 노트

- `'use client'` 단일 컴포넌트, `useState`/`useMemo`로 클라이언트 사이드 매칭 로직 구현 (외부 API/이미지 없이 오프라인 렌더 가능)
- 매칭률 = (선택 태그와 아이템 태그의 교집합 수 / 선택 태그 수) × 100, 내림차순 정렬 후 상위 6개
- 카드 시각 요소는 전부 그라디언트 + 이모지 (외부 이미지 CDN 미사용)
- `aria-pressed`, `role="group"`, `aria-live="polite"`로 태그 토글과 추천 변경을 스크린리더에도 전달
- 반응형: 태그는 `flex-wrap`, 카드 그리드는 `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`
