# Features · 창의 후보 b — AI 파이프라인 시각화

기능 나열형 3-컬럼 그리드를 버리고, "기능 = 흐름"이라는 명제를 문자 그대로 화면에 구현했다. 하나의 상품 카드("빈티지 러닝화")가 repick의 4단계(취향학습→AI매칭→신뢰검증→실시간알림)를 좌에서 우로 통과하며, 각 정거장을 지날 때마다 카드 내부 콘텐츠가 실시간으로 변형된다 — 학습 단계에서는 찜/클릭 태그가 하나씩 튀어 오르고, 매칭 단계에서는 스캔 라인이 훑고 지나가며 일치율 배지가 뜨고, 검증 단계에서는 체크리스트가 순차로 채워지고, 알림 단계에서는 가격 하락 푸시가 바운스로 도착한다. 4.2초 간격 자동 재생 + 정거장 버튼 수동 클릭(아이콘 선택 시 자동재생 정지) 두 가지 조작을 모두 지원하며, `prefers-reduced-motion`을 감지해 애니메이션 지속시간을 즉시 0에 가깝게 낮춘다. 진행 라인은 정거장 중심(12.5/37.5/62.5/87.5%)에 정확히 정렬되어 카드 위치·라인 채움·상단 아이콘 활성 상태가 항상 동기화된다. 단계별 강조색(회색/보라/에메랄드/호박)은 헤더·CTA의 통일된 바이올렛 톤 위에서 각 단계의 성격(중립 관찰/AI/신뢰/경보)을 색으로도 서사화한다. 하단에는 JS 없이도 읽히는 4단 리캡 그리드와 실제 앵커(#pipeline, #cta, #top)로만 연결된 CTA를 배치해 배포 가능한 완결성을 확보했다.
