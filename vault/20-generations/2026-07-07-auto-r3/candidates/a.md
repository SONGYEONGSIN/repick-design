# Candidate A — 매거진 그리드 극단

## 방향
R2a("타이포 위계 극대화")가 확립한 near-mono + 비대칭 좌측정렬 + accent 극소량 원칙을 계승하되, 레이아웃 자체를 **불규칙 매거진 그리드**로 밀어붙였다. 12-col 그리드에서 모든 블록이 정확히 3분할/균등폭으로 떨어지지 않도록 col-span/col-start를 의도적으로 어긋나게(5+gap+6, 7+gap+4 등) 배치해 여백 자체가 열(column)처럼 기능하게 했다. 헤드라인은 좌측 3-col 아이바로우와 나란히 배치되는 넓은 9-col 블록으로, 배경엔 거대한 접힌 폴리오 넘버 "01"을 5% 불투명도 워터마크로 깔았다. 값 3분할은 균등 그리드 대신 5/4/3-col 비대칭 폭 + 단마다 다른 세로 오프셋(mt-16/mt-32)으로 계단식 잡지 레이아웃을 만들고, 넘버 크기도 01>02>03 순으로 점감시켜 위계를 스케일로 다시 강조했다. 소셜프루프는 인용구(7-col)와 사이드바 팩트박스(4-col, 세로 스택)로 나눠 8번째 컬럼을 의도적 여백(거터)으로 비웠다. 각 섹션 상단에 "01/02/03/04" 폴리오 라벨을 이어 붙여 페이지 전체가 하나의 인덱스처럼 읽히게 했다. 리터럴 그리드 모티프(3×3 셀, 중앙 accent 점)를 Hero 우측에 배치해 "그리드"를 은유가 아니라 실제 도형으로도 보여준다.

## 고른 참조
- `dala.design.md` — pure void(#000 근접) 배경 위 단일 accent, weight 400/스케일 신뢰 원칙, 카드/보더 없는 플로팅 타이포 → 여기선 hairline border(white/10)를 최소한의 구획 도구로만 사용.
- `monopo-saigon.design.md` — 프로젝트 리스트를 "카드"가 아닌 "풀블리드 로우"로 다루는 편집적 리듬, 텍스트-좌/이미지-우 비대칭 교차 배치, 0px 급진적 샤프 코너(여기선 rounded-md 최소화로 절제 계승), 46px+ 섹션 갭의 여유.
- 1회차 승자 C / R2 승자 a (`design-ledger.jsonl`) — near-monochrome + accent 극소량 고정, 헤드라인 clamp 초대형 스케일 대비 원칙 그대로 승계.

## 핵심 결정
- 12-col 그리드에서 col-span/col-start 합이 정확히 12가 되도록 설계해 CSS Grid auto-placement가 같은 행에 자연 배치되도록 함(명시적 grid-row 미사용, 버그 위험 최소화).
- Hero: 아이바로우(3-col) + 헤드라인(9-col) 같은 행, 서브헤드(5-col)+CTA(6-col) 다음 행, 3×3 리터럴 그리드(4-col) 그 다음 행 — 8-col 여백을 의도적으로 남겨 비대칭 강조.
- 값 3분할: 5/4/3-col 비대칭 폭 + lg:mt-16/lg:mt-32 계단식 오프셋, 넘버 크기 점감(5.5rem→4rem→3rem)으로 스케일 위계 재확인.
- 소셜프루프: 인용(7-col) / 사이드바 팩트박스(4-col, 세로 스택 — 기존 가로 4분할 stat row 대신 편집적 사이드바 형태로 차별화), 8번째 컬럼 여백 거터.
- 폴리오 라벨(01~04)을 섹션마다 반복해 페이지 전체를 "인덱스"로 읽히게 함 — 신규 hex 없이 기존 4토큰만 사용.

## Font Weights (3종)
- 400 (font-normal) — 본문, 캡션, 폴리오 라벨, 통계 라벨
- 600 (font-semibold) — 로고, 내비, h3, 버튼, 아이바로우
- 800 (font-extrabold) — h1/h2, 폴리오 워터마크 넘버, 블록쿼트, 통계 수치
