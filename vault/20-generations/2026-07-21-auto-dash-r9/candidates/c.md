# r9 · candidate c — Currents (Revenue Attribution Flow)

**Currents — Revenue Attribution Flow**는 B2B SaaS 레브옵스(RevOps) 팀을 위한 상용급 대시보드로, 배정된 **Sankey형 다단 흐름도** 아키타입을 그대로 구현했다: 화면을 지배하는 단일 시각화는 3단 컬럼(획득 채널 5개 → 가입 시점 플랜 티어 4개 → 90일 후 결과 4개) 사이를 잇는 리본 형태의 흐름도로, 각 노드의 높이와 각 리본의 두께는 전부 실제 흐름량(고객 수 또는 신규 MRR, 토글 가능)에 비례하며 채널→티어, 티어→결과 두 홉에서 각각 5×4=20개, 4×4=16개, 총 36개의 리본이 실제로 분기(한 채널이 4개 티어 모두로 갈라짐)하고 합류(한 티어가 5개 채널 모두에서 유입)한다 — 단일 경로가 좁아지는 깔때기도 아니고, 고정 토폴로지의 단일 파이프라인 노드-엣지도 아니다. 데이터 계층(`data.ts`)은 결정론적 정수 분배(최대 나머지법 `distributeInts`)로 채널→티어, 티어→결과 가중치 행렬을 순서대로 분배하기 때문에, 모든 노드에서 "유입 합=유출 합=노드 총합"이 산술적으로 항상 성립한다(채널 합계·티어 합계·결과 합계가 전부 동일한 총 신규 계정 수로 수렴 — 30일 기준 2,380건, Playwright로 렌더된 실제 SVG `aria-label` 수치를 합산해 재검증 완료). MRR도 티어별 고정 ARPU를 계승시켜 3개 컬럼 전체에서 동일한 총합(30일 $826,070)으로 보존된다.

**인터랙션 6종** (요구 최소 4종 상회, 전부 `'use client'` 실동작·`motion-reduce` 게이팅): ① 노드/리본 호버 또는 키보드 포커스 시 SVG 내부 좌표 기준 툴팁(정확한 고객 수·신규 MRR·source 대비 비중 %) + `aria-live` 스크린리더 미러링 ② 노드/리본 클릭 또는 Enter/Space 키 선택 → 우측 상세 패널(`DetailPanel.tsx`, 유입/유출 브레이크다운 + 12주 추세 스파크라인) 동기화 + 연결된 리본만 강조하고 무관한 리본은 opacity로 감쇠하는 "흐름 추적" 효과 + 하단 테이블 행 하이라이트(스크롤 동기화) ③ 하단 "Flow paths" 테이블 실제 정렬(aria-sort, From/To/Accts/New MRR/Share) + 홉 필터(전체/채널→티어/티어→결과) + 텍스트 검색 ④ 지표 토글(Customers / New MRR) — 리본 두께·노드 높이·히어로 숫자·컬럼 부제까지 전부 재계산 ⑤ 기간 세그먼트(7D/30D/90D) 토글 — 전체 흐름 재계산 ⑥ ⌘K 커맨드 팔레트로 13개 노드(채널/티어/결과) 검색 후 선택 시 다이어그램 실제 DOM 포커스까지 이동. 결과(90일 후) 노드는 유지(에메랄드)·확장(스카이)·다운그레이드(앰버)·이탈(로즈) 시맨틱 톤을 리본 색에도 반투명 승계해 이탈 경로를 색+라벨 병행으로 즉시 가독시킨다.

**아키타입 배제 목록과의 구조적 차이**: DAG/노드-엣지 파이프라인(#15)은 단일 경로 고정 토폴로지의 얇은 베지어선인 반면, 본 후보는 컬럼당 4~5개 노드가 서로 다른 개수의 상대 컬럼 노드와 실제로 다대다 분기·합류하며 리본 두께가 유량을 인코딩한다(파이프라인은 두께가 균일). 스텝형 퍼널(#20)은 한 지표가 단조 감소하는 단일 좁아지는 경로인 반면, 본 후보는 각 컬럼이 여러 병렬 노드를 갖고 컬럼 간 전체 합이 보존되며(단조 감소 없음 — 예: 결과 컬럼 총합도 2,380으로 채널 컬럼과 동일) 리본이 서로 교차한다. 트리맵(#19)·리더보드(#16)·코호트 히트맵(#17)·오빗(#18) 등 다른 단일-지배 시각화 계열과도 기하가 다르다.

**레이아웃/컴포넌트 시스템**: 좌측 사이드바(브랜드 락업 Waves 아이콘 + 워크스페이스 스위처 + lucide 섹션 nav + 하단 유저) + 상단바(⌘K 검색 버튼·Export 액션·알림·아바타 메뉴, 헤더 컨트롤 전부 개별 h-11/44px) + 히어로 인라인 스탯(4카드 가로줄 대신 대형 숫자 1개 + 보조 스탯 4개 변주) + 전폭 Sankey 카드 + 하단 상세패널(4/12)+테이블(8/12) 12-col 그리드. 전역 `font-sans`(Pretendard) 단일, 세리프/디스플레이 폰트·추가 `next/font` import 없음, 숫자는 전부 `tabular-nums`+`Intl.NumberFormat`. 라이트는 white/zinc-50 캔버스+zinc-200 헤어라인+shadow-sm, 다크는 zinc-950/900 표면+white/10 보더, 보조 텍스트는 라이트 zinc-500 이상/다크 zinc-400 이상을 전 상태(기본/선택/필터/토글 뒤)에서 유지. 페르소나(Dana Whitfield, Revenue Operations Lead, `dana.whitfield@currentshq.io`, Unsplash 아바타)는 세션 컨텍스트와 무관한 완전 가상 인물.
