# DECISION — auto-landing-r4 (target: landing)

블라인드 라벨 매핑(심사 시 미공개, 집계 후 공개): ALPHA = b(포인터 틸트 쇼케이스+필름스트립) · BETA = c(AI 매칭 대조표 — 인터랙티브 비교 테이블) · GAMMA = a(매치 카드 스택 — 스와이프 덱)

## 렌즈1 — 정본 DNA 준수

**랭킹: 1위 BETA(c) · 2위 GAMMA(a) · 3위 ALPHA(b)**

- BETA(c): 탭 조작이 5개 비교 기준 전체를 실시간 재계산시키며 매물 증명이 처음부터 펼쳐져 있어 "조작=가치체감"과 "증명 상시노출"을 가장 정확히 구현. 소스에 "기본으로 첫 행을 열어 정지 상태에서도 실사 매물 증명이 보이게 함(hover 전용 리빌 금지 원칙)" 주석 확인.
- GAMMA(a): 핵심 배지·할인율은 드래그 중에도 상시노출되고 조작이 실제 새 매물 데이터로 이어지지만, 매칭 근거 세부 텍스트는 클릭 전까지 접혀 있어 완전한 상시노출에는 살짝 못 미침.
- ALPHA(b): 정지 상태 증명 노출과 폰트/트래킹 규칙은 잘 지켰으나, 헤드라인이 앞세운 핵심 인터랙션(포인터 3D 틸트)이 가치 데이터와 결속되지 않은 순수 장식 모션이라 delta 2("인터랙션은 가치 명제와의 결속으로 평가") 위반 소지.
- no-winner 아님 — 3후보 모두 근모노크롬·폰트 3종·트래킹 3단·5단 구조·상시노출 기본 원칙 준수, 차이는 인터랙션-가치 결속 정도.

## 렌즈2 — 상용 SaaS 랜딩 완성도(Linear·Stripe·Vercel급) + 에셋·인터랙션 밀도

**랭킹: 1위 BETA(c) · 2위 ALPHA(b) · 3위 GAMMA(a)**

- BETA(c): 비교표 히어로가 인터랙션(탭 전환)과 증명(5기준 재계산 데이터)을 가장 밀도 높게 결속시켜 상용 SaaS "왜 우리인가" 섹션급 완성도.
- ALPHA(b): 틸트 카드+필름스트립의 마감·접근성(role=tablist+roving tabindex, pointerType 체크, reduced-motion 존중)은 최상급이나 틸트 모션이 정보 전달보다 촉각적 장식에 가깝다.
- GAMMA(a): 실행 품질(포인터+키보드+aria-live)은 준수하나 스와이프 인터랙션의 가치 결속과 증명 데이터 밀도가 상대적으로 가장 얕다.
- 3후보 모두 delta(정지 상태 상시 노출) 명확히 준수, hover/focus 전용 리빌 위반 없음.

## 렌즈3 — 아키타입/형태 차별성 (v0~v5 + landing-evolve 누적 13개 형태 대비)

**랭킹: 1위 BETA(c) · 2위 GAMMA(a) · 3위 ALPHA(b)**

- BETA(c): 카테고리 탭+아코디언 대조표는 기존 13개 중 명시적 `<table>` + 탭 + 아코디언 조합 사례가 없어 가장 신규. "비교"라는 주제는 r2/a와 겹치나 인터랙션 문법(드래그 vs 탭+아코디언)과 시각 오브젝트(카드 vs 표)가 뚜렷이 다름.
- GAMMA(a): 틴더식 드래그 스와이프 카드 스택 — "드래그" 조작 문법은 r2/a(우승작, 드래그비교)와 계열 중복이나 목적·오브젝트(순수 큐레이션 브라우징 스택)는 신규.
- ALPHA(b): 포인터 3D 틸트카드는 v2(포인터 spotlight) 계열의 형태 변주(글로우→3D 기울임)에 가까워 차별성이 가장 낮음.

## 하드게이트 요약
- static: a/b/c 전부 1차 위반 0건.
- sweep: a/c 1차 통과, b는 필름스트립 table-overflow(27px, 전 데스크톱 폭) 1회 수정(gap 2.5→2, 썸네일 96→80px) 후 통과.
- lighthouse a11y(≥95 하드게이트): a는 1차 91(color-contrast/heading-order/target-size) → 1회 수정 후 100. b는 수정 후 1차 측정 99. c는 1차 99. perf(기록만): a 96, b 95, c 95.

## LEARN 델타(§5에서 append 예정)
승자 c의 판정 사유에서 재사용 가능한 delta 1개를 추출: "탭/카테고리 전환이 표·비교 데이터 전체를 재계산하는 구조는 슬라이더·드래그형 조작 못지않게 '조작=가치체감' 원칙을 구현하며, 명시적 `<table>` 기반 대조 UI는 랜딩 누적 형태 중 아직 소진되지 않은 신규 아키타입이다."
