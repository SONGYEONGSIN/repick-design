# 후보 b — 포인터 틸트 쇼케이스 + 필름스트립 히어로

경로: `app/src/app/landing-evolve/r4/b/` (`page.tsx` + `ui.tsx` + `Showcase.tsx` + `data.ts`)

## 한 줄 컨셉
히어로 우측에 단일 스포트라이트 매물을 3D 포인터-틸트 카드로 크게 보여주고,
하단 가로 필름스트립(6개 매물 썸네일)으로 스포트라이트를 전환한다 — "AI가 고른
매물 하나를 실물처럼 손에 쥐고 돌려본다"는 감각으로 신뢰(컨디션 실측)를
체감시키는 구조.

## 핵심 인터랙션 (4종)
1. **포인터 틸트** — `Showcase.tsx`의 `TiltCard`. `useMotionValue`(raw rotateX/Y) →
   `useSpring`(관성 보간) 체인. 각도는 카드 경계 내 포인터 상대좌표(px/py, 0~1)의
   결정론적 함수이며 `Math.random`/`Date.now` 없음. `pointerType === "touch"`와
   `useReducedMotion`을 게이팅해 터치·모션축소 사용자는 정적 카드로 수렴.
   회전각에서 파생된 `useTransform`+`useMotionTemplate` 방향성 드롭섀도우로
   입체감을 보강(배경 글로우 아님 — 카드 자체의 그림자만 이동).
2. **필름스트립 선택 전환** — 썸네일 클릭 시 스포트라이트가 즉시 해당 매물로
   전환되고, `useEffect([index])`에서 rotateX/Y를 0으로 명시 리셋.
3. **필름스트립 키보드 내비게이션** — `role="tablist"` + 각 썸네일
   `role="tab"`/`aria-selected`/`aria-controls="spotlight-panel"`, roving
   tabindex(선택 탭만 `tabIndex=0`). `ArrowLeft`/`ArrowRight`(순환)/`Home`/`End`로
   이동 후 새 탭에 `focus()`.
3.5. 스포트라이트 카드는 `role="tabpanel"`로 필름스트립과 연결.
4. **스크롤 트리거 섹션 진입** — 제품 프리뷰 그리드 카드, 가치 3분할, 소셜프루프,
   최종 CTA가 `whileInView`(once, margin -80px)로 순차 등장. 히어로 좌측 카피는
   mount 시 stagger 시퀀스.

모든 인터랙션은 장식이 아니라 "매물을 실물처럼 검수해보는" 전환 동선에
직결된다 — 틸트는 컨디션 신뢰를 체감시키고, 필름스트립은 "AI가 여러 개를
골랐다"는 선택지를 탐색하게 한다.

## 증명 상시노출 (r3 delta 준수)
스포트라이트 카드 정면(hover/focus 이전 최초 렌더)에 다음이 항상 존재:
- 매칭% 배지(우상단, accent 배경)
- 컨디션 등급 배지(좌상단, S/A + 등급 설명)
- 인증 셀러 배지(BadgeCheck + 거래건수)
- before/after 가격(취소선 리테일가 + repick가 + `-N%` 할인 배지)
- AI 매칭 근거 3줄(체크리스트)
hover 전용 리빌 요소 없음. 터치 기기에서도 동일하게 전부 보임.

## 중복 회피 근거
- **r2/a(우승, 드래그 비교)**와 다름: r2/a는 두 이미지(before/after) 사이를
  핸들로 드래그해 비교하는 2D 슬라이더. b는 이미지가 1장(단일 스포트라이트)이고
  포인터는 드래그가 아니라 위치 추적으로 3D 회전을 만든다 — "비교"가 아니라
  "검수(돌려보기)" 감각.
- **v2-bento(포인터 spotlight 글로우)**와 다름: v2-bento는 정적 카드 배경에
  커서를 따라다니는 radial glow(2D 조명 효과)를 얹는다. b는 글로우를 전혀
  쓰지 않고 카드 자체가 `rotateX/rotateY`로 물리적으로 기울어지는 3D 변환이며,
  배지들은 `translateZ`로 레이어 분리되어 틸트 시 시차(패럴랙스)까지 생긴다.
- **r3/a(매서너리 그리드 + hover 리빌)**와 다름: b는 그리드가 아니라 단일
  스포트라이트 + 가로 스트립이고, 무엇보다 hover 리빌을 쓰지 않는다(감점 사례
  재발 방지).
- **r1/a(스캔 콘솔)·r3/b(대화 트랜스크립트)**와 다름: 진행률 애니메이션이나
  대화 로그가 아니라 사용자가 직접 조작하는 3D 오브젝트 상호작용.
- 제품 프리뷰 섹션(Fig.02)은 필름스트립과 다른 3개 매물을 정적 리치 카드
  그리드로 보여줘 "AI가 여러 매물에 동일 기준을 적용했다"는 걸 별도로 증명—
  r2/a의 `ProductPreview` 패턴(히어로 인터랙션 + 별도 정적 증명 섹션)을
  계승하되 카드 레이아웃과 데이터는 독립.
