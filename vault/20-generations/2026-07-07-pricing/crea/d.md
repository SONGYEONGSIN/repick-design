# Pricing — 창의 모드 후보 d

## 컨셉: 게임화(레벨업) Pricing

요금제를 "결제 티어"가 아니라 **게임 레벨업 시스템**으로 재구성했다. Free → Pro → Business를 LV.01 탐색가 / LV.02 매칭 마스터 / LV.03 길드 마스터라는 게임 등급으로 표현하고, 각 레벨은 "해금된 능력"(퀘스트 완료 스타일 체크리스트)과 "성장 게이지"(33% / 66% / 100% 진행바)로 보여준다. 진행바 아래에는 다음 레벨에서 잠금 해제될 능력을 🔒 미리보기로 노출해 업그레이드 동기를 자연스럽게 유도한다.

정보 구조는 실전 요금제 페이지의 필수 요소(가격, 기능, 비교, FAQ, CTA)를 그대로 담되 표현만 게임화했다:

1. **레벨 선택 탭 + 캐릭터 카드** — 인터랙티브 탭(`useState`)으로 Lv.1/2/3 전환, 선택된 레벨의 가격·태그라인·해금 능력·성장 게이지·다음 레벨 미리보기를 카드 하나에 표시.
2. **레벨업 로드맵** — 3개 노드를 점선으로 잇는 스킬트리형 요약 뷰. 세 레벨을 한눈에 비교하는 보조 내비게이션 역할.
3. **능력치 비교표** — RPG 스탯 시트처럼 5칸 점(pip)으로 매칭 속도·추천 정밀도·알림 반응 속도 등을 시각화. 단순 체크마크 표보다 정보 밀도와 재미를 동시에 확보.
4. **퀘스트 Q&A** — FAQ를 게임 용어(레벨업/레벨다운)로 리프레이밍.
5. **최종 CTA** — "Lv.1부터 시작" 문구로 무료 시작 유도.

다크 게임 HUD 톤(#0B0B16 배경 + 틸/골드/마젠타 레벨별 accent)으로 시각적으로도 "레벨업 화면" 느낌을 강화했다. 재미 요소가 정보(가격·기능·비교)를 가리지 않도록 각 섹션은 표준 프라이싱 페이지가 요구하는 데이터를 빠짐없이 유지한다.
