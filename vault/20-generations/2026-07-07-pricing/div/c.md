# Candidate C — Pricing — 콜라주/스크랩북

**아키타입**: 아날로그 콜라주 / 스크랩북 (찢은 종이·마스킹테이프·핀·손글씨·회전 레이어)

**핵심 컨셉**: "중고 = 조각을 모아 쓰는 것"이라는 은유를 요금제 구조에 그대로 얹었다. 코르크보드 질감 배경 위에 Free·Pro·Business 3티어를 각각 다른 색의 종이 조각(인덱스카드/폴라로이드/크래프트 봉투)으로 표현하고, 찢어진 종이 가장자리(clip-path 조각선)·마스킹테이프·압정·빨간 잉크 스탬프("인기")로 고정해 실제로 스크랩북에 붙여둔 것처럼 보이게 했다. 헤드라인·섹션 제목·FAQ 라벨은 손글씨 커서브 폰트로, 티어 비교는 영수증처럼 찢어진 상단/하단 가장자리를 가진 카드 안에 표(table)로 배치했다. FAQ는 포스트잇 3장이 압정에 매달려 살짝 흔들리는(sway, reduced-motion 대응) `<details>` 아코디언, 최종 CTA는 가위 커트라인(cut-line)으로 둘러싼 쿠폰처럼 마감했다. 실전 UI 계층(h1 단일, table caption/scope, focus-visible ring, sr-only 텍스트)은 그대로 유지하면서 시각적으로만 아날로그 콜라주 코스튬을 끝까지 밀어붙였다.
