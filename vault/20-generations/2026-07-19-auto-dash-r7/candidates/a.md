# r7 · candidate a — Apogee (Orbit Canvas)

**Apogee — Lifecycle Intelligence**는 고객 성공(CS)팀을 위한 상용급 SaaS 대시보드로, 배정된 **Orbit Canvas** 아키타입을 그대로 구현했다: 5개 동심원 궤도(Trial→Activated→Retained→Expanded→Churned, 안쪽=초기 단계)를 대형 SVG로 그리고 50개 고객 계정을 궤도 위 점으로 결정론적으로 배치하는데, 각도는 가입 경과일, 반지름은 헬스 스코어(밴드 내에서 건강할수록 바깥=확장 방향)로 계산하며 Churned는 바깥쪽 점선 "이탈 궤도"로 분리해 표기한다 — 중심 코어에는 표시 계정 수가 실시간으로 집계되고, 우측 고정 상세 패널(선택 고객의 헬스 스파크라인·최근 이벤트·담당 CSM·다음 액션)과 하단 라이프사이클 전환 테이블이 병존한다. **인터랙션은 6종**으로 브리프 최소 4종을 상회한다: (1) 궤도 점 호버/키보드 포커스 시 크로스헤어 라인 + `role="status"` 툴팁으로 고객명·단계·헬스 표시, (2) 점 클릭/Enter 선택 시 우측 상세 패널과 하단 테이블 행이 동시 하이라이트 동기화, (3) 단계 필터 칩(범례 겸용, aria-pressed)으로 보이는 점 개수·센터 숫자·평균 헬스·이탈 위험·테이블이 실제 재계산, (4) 기간 세그먼트(7D/30D/90D) 토글로 헬스 재산정 → 반지름 변경 → 점이 `transform` 트랜지션으로 실제 이동(motion-reduce 게이팅), (5) 전환 테이블 실제 정렬(고객·헬스변화·시점, aria-sort), (6) ⌘K 커맨드 팔레트로 계정 검색 후 선택 동기화. 궤도의 각도/반지름 좌표는 인덱스 기반 pseudo-random 해시로 완전 재현 가능하며 삼각함수 좌표는 소수 2자리로 반올림했다(Math.random·Date.now·new Date 미사용, 합계는 단일 CUSTOMERS 소스에서 파생해 정합). **next/image는 3곳**(상단바 유저 아바타, 사이드바 유저 아바타, 우측 상세 패널의 선택 고객 담당자 아바타)에서 실존 Unsplash ID를 width/height·alt 지정·unoptimized 없이 사용해 최소 2곳 요건을 충족한다. **타이포는 전역 font-sans(Pretendard) 단일**이며 숫자/코드에만 tabular-nums를 적용했고 세리프·디스플레이·장식 폰트나 next/font 추가 import는 전혀 없다. 완성도는 브리프 필수 앱 셸(사이드바 브랜드 락업+워크스페이스 스위처+lucide 섹션 nav+하단 유저, 상단바 ⌘K·알림·아바타 메뉴, 헤더 컨트롤 개별 44px), 일관된 Card/Badge/SegmentedControl/정렬 테이블 컴포넌트 시스템, 12-col 그리드와 table-fixed % 수납(1280~1920 전 구간 카드 수납·모바일 드로어), 순백 zinc-50/white 캔버스 + zinc-200 헤어라인 + shadow-sm의 절제된 표면과 AA 대비(라이트 표면 보조 텍스트 zinc-500 이상 엄수)로, Mercury·Asana·Coinbase 급의 "단일 지배적 시각화 + 상세 패널 + 데이터 테이블" 레퍼런스 완성도를 목표로 한다 — DAG/히트맵/리더보드와 같은 급의 지배적 시각화이되 궤도-반지름-각도라는 전혀 다른 기하를 사용한다.
