## c — Parallax

제품 분석/BI 리포팅 SaaS(Metabase/Looker류). **BI 리포트 캔버스 아키타입** — 화면 주인공은 서로 다른 크기의 위젯 7개(대형 WAU 트렌드 차트 col-span-8, MRR/이탈률 스택 카드, 채널별 신규가입 바차트, 활성화 퍼널, 디바이스 도넛, 상위 페이지 테이블)가 12-col 그리드에 동거하는 "리포트 캔버스" — 단일 지배적 히어로 없이 여러 위젯이 동급. 좌측 아웃라인 레일(위젯 목록 + 기간/세그먼트 공유 필터) 조작 → 3×3 결정론적 시나리오 매트릭스에서 전 위젯 동시 리렌더. 트렌드 차트 크로스헤어(키보드 접근)+테이블 실제 정렬/필터+아웃라인 클릭→위젯 스크롤·하이라이트+⌘K. 기존 히어로+벤토(r2/b)·분할워크벤치(r2/c, 편집폼↔프리뷰)·덴스그리드(r3/c)와 달리 "다수 피어 위젯 리포트" 구조.
