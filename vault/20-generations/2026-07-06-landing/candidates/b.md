# 후보 B — 대비 중심 (Contrast-first)

**방향**: Linear의 절제된 다크 UI 언어를 기본기로 삼되, 히어로 타이포 스케일을 극단적으로 키워(text-7xl~[84px]) 본문(text-sm~lg)과의 크기 대비를 크게 벌리고, 액센트(#6E56CF)를 배경 전체가 아닌 CTA·배지·숫자 등 "클릭/기억되어야 할 지점"에만 고채도로 집중 배치해 시선을 강제로 유도했다. 히어로 배경엔 단일 blur 글로우(보라, 70% 지점에서 투명 소실) + 5% 불투명 그리드 텍스처만 얹어 장식적 그라디언트 남발을 피했고(design-principles.md 금지 항목 준수), CTA 버튼은 solid accent + 이중 shadow(테두리 링 1px + 확산 glow)로 다크 배경 위에서 튀어 보이도록 만들어 "눈에 꽂히는 CTA" 요구를 충족했다. 히어로 하단엔 실제 제품 UI를 흉내낸 카드 그리드 목업(테두리 1px + 라운드 8~12px)을 배치해 Linear의 "실제 화면 노출로 신뢰 증명" 관성을 차용했다. 3분할 가치 섹션은 얇은 stroke 아이콘 + 카드 hover 시 보더만 accent로 전환하는 절제된 인터랙션, 소셜프루프는 숫자 크기를 4xl→6xl로 급격히 키워 "증명은 형용사가 아니라 크기로" 원칙을 반영했다.

**참조**: `vault/10-references/linear.design.md` (다크+고대비+단일 액센트 글로우, 좁은 카드 보더, UI 스크린샷 노출, 형용사 대신 명제형 카피)

**핵심 결정**:
- 헤딩과 본문의 크기 대비를 의도적으로 극대화 (h1 최대 84px vs 본문 14~18px)
- 액센트는 전체 색면이 아닌 포인트(배지/CTA/숫자/hover 보더)로만 사용
- 그라디언트는 히어로·CTA 패널 각 1개 blur 글로우로 제한 (design-principles 금지 조항 준수)
- CTA 버튼에 보더 링 + 확산 그림자 이중 처리로 다크 배경 대비 강조

**색 (hex)**:
- `#0B0B0F` — 배경 (base)
- `#101014` — 카드/패널 배경 (elevated)
- `#FFFFFF` — 전경/헤딩 텍스트
- `#A1A1AA` — 보조 텍스트 (muted)
- `#71717A` — 3차 텍스트 (footer/캡션)
- `#D4D4D8`, `#E4E4E7` — 본문 강조 텍스트
- `#6E56CF` — accent (CTA, 배지, 글로우)
- `#7C64DA` — accent hover
- `#A78BFA`, `#C4B5FD` — accent 밝은 변형 (배지 텍스트, 태그, 그라디언트 텍스트 끝점)
