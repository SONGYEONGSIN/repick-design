## variant b — 챔피언 정련 (API 회복 프로브)

**방향**: 현재 챔피언 `page.tsx`(Hero → 미리보기(상품 카드) → 가치 3분할 → 소셜프루프 → 최종 CTA)를 그대로 계승. 방향 전환 없이 디테일 3곳만 정련.

**참조**: 새 외부 참조 없음 — 챔피언 자체를 소스로 삼아 내부 일관성만 점검(기존 vault/00-principles/design-principles.md 원칙 준수 확인).

**핵심 정련**:
1. **프리뷰 카드 반응형 스택** — 상품 카드 그리드를 `grid-cols-2`(모바일 2단)에서 `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`로 변경. 375px에서 카드 폭이 좁아 매칭%·가격 텍스트가 눌리던 문제 해소, 1열 스택으로 카드 내부 여백과 썸네일 그리드가 온전히 숨쉬도록 함.
2. **섹션 캡션 일관성** — 최종 CTA 섹션의 캡션이 다른 섹션(`0X — 라벨`, text-xs font-semibold uppercase tracking-[0.28em]) 패턴과 달리 `Fig. 05 — 시작`(11px 캡션 톤)으로 어긋나 있던 것을 `05 — 시작`으로 교체, 다른 섹션 이규브로우와 동일한 타이포 클래스로 통일.
3. **시각 리듬 재확인** — 프리뷰/가치/신뢰 섹션의 `py-24 lg:py-36` + `mt-16 lg:mt-24` 리듬이 이미 일치함을 확인, 별도 수정 없이 유지(불필요한 변경 회피).

**결과**: 레이아웃/카피/색 구조 변경 없음. 반응형 안정성과 섹션 캡션 시스템 일관성만 개선.

**font-weight (3종 유지)**: `font-normal`, `font-semibold`, `font-extrabold`

**색 (hex, 변경 없음)**:
- 배경: `#0B0B0F`
- 텍스트 기본: `#FFFFFF` (white)
- 보조 텍스트: `#A1A1AA`
- 액센트: `#6E56CF`
