# Round 2026-07-07-auto-r7 — Candidate c

## 방향
"작동 방식 3-step 내러티브 탐색" — 챔피언(2026-07-07-auto-r6 b) 구조를 그대로 계승하고, 03 "방식" 섹션(가치 3분할)만 프로세스 내러티브로 재설계했다. 기존 스태거드 오프셋(lg:mt-16/32, 크기 감소 넘버) 대신 **3열 동일 높이 + 상단 커넥팅 레일(accent 아웃라인 dot 3개, 얇은 white/10 라인)**로 "01→02→03이 순서대로 진행된다"는 흐름을 시각적으로 명시했다. 각 스텝에는 ghost 넘버(white/15) 옆에 **미니 SVG 다이어그램**을 배치 — 취향 학습은 네트워크 그래프(노드 3개, accent 노드 1개), AI 큐레이션은 폭이 좁아지는 필터 바(하단 바만 accent), 신뢰 검증은 체크리스트(첫 체크만 accent). 다이어그램마다 accent를 1개 요소에만 부여해 "정지 상태에서 존재감 유지 + 극소량" 원칙을 지켰다. 참고할 vault/10-references 파일이 존재하지 않아(디렉토리 비어있음) 별도 외부 레퍼런스 없이 design-principles.md와 챔피언 구조 자체를 기준으로 진행.

## 핵심 결정
- 레일+dot은 desktop(lg)에서만 노출, 모바일은 기존처럼 border-t 구분선 + 세로 스택 유지 → 반응형 단순성 확보.
- 다이어그램 박스(`h-14 w-14`, border+`bg-white/[0.02]`)는 상품 프리뷰 카드의 격자 목업과 톤을 맞춰 기존 "Fig." 스타일 언어와 이질감 없게 함.
- 헤딩 카피 "세 가지 방식으로" → "세 단계로 다시 고릅니다", 서브카피 "단계별로" → "3단계로"로 미세 조정해 프로세스 프레이밍 강화.
- 그 외 섹션(Hero/Preview/Proof/CTA/Footer)은 챔피언과 동일 — 변경 범위를 03 섹션에 surgical하게 한정.

## 사용 font-weight
- `font-extrabold` (800) — 헤드라인, ghost 넘버, 통계 수치
- `font-semibold` (600) — 라벨/제목/CTA
- `font-normal` (400) — 본문/캡션

## 색 hex
- `#0B0B0F` — bg
- `#FFFFFF` — fg (opacity 변주: /15, /10, /[0.02~0.06] 등)
- `#A1A1AA` — muted
- `#6E56CF` — accent (다이어그램 내 1개 요소, dot 아웃라인, CTA, 강조 텍스트에만 극소량 사용)
