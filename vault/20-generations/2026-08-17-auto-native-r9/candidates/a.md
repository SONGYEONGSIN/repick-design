# auto-native-r9 후보 a — Meetup spot picker

**한 줄 컨셉**: 직거래 만남 장소를 **"누가 더 걷느냐"**로 고르는 화면. 질의 헤더(어디서 출발·언제) → 공간 캔버스(답) → 바텀시트(고른 장소) 3단 골격. 낯선 두 사람이 장소를 못 정하는 진짜 이유는 안전이 아니라 **공정성**이라 논증을 공간에 뒀다. 후보 5개는 각자 두 개의 도보시간(`8·9`)을 항상 달고 있고, 음영 밴드는 "두 사람의 도보차 3분 이내" 영역 그 자체 — 아무것도 열지 않아도 무엇을 고르는 중이고 무엇이 후보인지 보인다.

**밴드를 안 쓴 이유**: 회피가 아니라 **할 말이 없어서**. 이 화면엔 차단 조건이 없다(추천이 기본값이라 항상 한 곳이 선택돼 있다). 막힌 이유를 말할 게 없는 화면의 상태기계 밴드는 빈 밴드다. 커밋 컨트롤은 시트 안, 커밋 대상 바로 옆에 두고 항상 활성.

지도 SDK 없음. 좌표계를 직접 두고 `react-native-svg`(이미 `src/charts` 가 쓰는 것)로 그렸다. **도보 분은 하드코딩이 아니라 좌표에서 계산**한다(`walkMinutes = round(distance × 22)`) — 손으로 적으면 그림과 숫자가 갈라지므로.

**인터랙션 7종**

| 조작 | 증명 갱신 |
|---|---|
| 마커 탭(후보 5) | 시트 교체 + 선택 마커 accent + **두 다리 재작도**(내 쪽 accent 파선 / Jordan 쪽 ink2 점선). 증명이 새 장소로 옮겨간다 |
| **Leaving from [Home\|Work]** | 앵커 핀 이동 → 마커 5개 왼쪽 숫자 전부 재계산 → **공정 밴드가 통째로 다른 모양으로 다시 그려진다**(Home 좁은 띠 / Work 넓은 쐐기). 공정 집합이 `{s1,s2,s3}`→`{s1,s2,s5}` 로 갈리고 추천이 s1→s5 로 뒤집힌다. 조작이 증명을 **다시 계산**한다 |
| Meeting [2 PM\|7 PM\|10 PM] | 닫힌 장소 마커가 파선 테두리 + `Closed` **글자**로(색만이 아니라), 요약 줄이 `2 of 5 … · 2 closed`, 시트 슬롯 노트 교체. 10 PM 엔 몰이 닫혀 Work 추천이 s1 로 복귀 |
| 핸들 탭 / Details | 시트가 56px 자라고 지도는 그만큼 **균일** 축소(왜곡 없음). 핸들을 `Pressable` 로 만든 건 드래그 안 되는 그랩바는 없는 제스처를 약속하는 거짓말이라서 |
| Propose this spot | 시트 하단이 다크 확정 카드로 + `alert`/`polite` 낭독. 선택·출발지·시각 중 **무엇이든 바뀌면 제안 자동 무효화** |
| Switch (맥락 등장) | 추천 ≠ 현재 선택일 때만. 사용자가 고른 선택을 몰래 옮기지 않으면서 "지금은 저게 더 공정하다"는 계속 말한다 |
| Pick X instead (맥락 등장) | 선택한 곳이 그 시각에 닫혔을 때 주 버튼이 복구 액션으로 교체 — 비활성 버튼 + "왜 안 되는지 찾아보세요"를 만들지 않는다 |

## 브리프에 없던 것

**① 공간 표현의 정확도 계약** — ② 도보 분을 좌표에서 계산(`MINUTES_PER_UNIT = 22`)하고 공정 밴드를 **초점이 두 사람인 쌍곡선의 정확한 등위집합**으로 작도. 분류 플래그도 반올림된 분이 아니라 **원거리차**로 판정해 밴드와 같은 술어를 쓰게 함 ③ 브리프는 "좌표는 고정값·계산"만 요구했지 그림과 숫자의 일치는 안 시켰다. 직선 띠로 그리면 두 앵커가 가까운 Work 상태에서 **틀린 그림**이 된다(실제 영역은 벌어진 쐐기). 판정자가 마커 위치와 숫자를 대조할 수 있으므로 거짓말이 남으면 안 된다. **임의 + 관행**

**② 후보 개수와 좌표 배치** — ② 5개, 라벨 충돌을 손계산해 배치(s3/s4·s1/s5 쌍을 두 번 이동) ③ 5는 라벨이 안 겹치면서 "공정 3 / 불공정 2" 대비를 만드는 최소치. 3개면 밴드가 논증할 게 없고 7개면 390px 에서 핀이 뭉갠다. **임의**

**③ 무엇을 "공정"이라 부를 것인가** — ② `EVEN_GAP = 3분`, 추천은 "공정 ∩ 영업중" 안에서 **총 도보 최소**(동률이면 격차 작은 쪽) ③ 격차 우선 정렬이면 둘 다 20분 걷는 곳이 둘 다 5분인 곳을 이겨 직관과 어긋난다. 규칙을 숨기지 않고 화면에 문장으로 명시(`Even = you and Jordan walk within 3 minutes of each other`). **임의**

**④ 시각 축의 존재 자체** — ② 슬롯 3개(2 PM/7 PM/10 PM, 고정 날짜 `Sat, Aug 22`) + 장소별 영업/비영업 + 슬롯별 상황 노트 ③ 브리프는 "지도 + 바텀시트"만 줬으나 **닫힌 카페는 후보가 아니다** — 시각이 없으면 후보 목록이 거짓이 된다. 동시에 이 축이 지도 상태와 시트를 함께 바꿔 조작이 증명을 강화하는 두 번째 경로가 됐다. **관행**

**⑤ 두 컨트롤의 위치** — ② `Leaving from`·`Meeting` 둘 다 헤더, 시트는 선택된 장소 정보만 ③ 처음엔 시각을 시트에 두려 했으나(영업정보는 장소 속성) 브리프가 시트 역할을 못박았고, 둘 다 **질의 파라미터**라 한곳에 모아야 3단이 성립. 플로팅 칩은 Work 앵커 핀과 좌표가 겹쳐 기각. **임의(문면 존중)**

**⑥ 지도 투영·리사이즈 규칙** — ② 콘텐츠 박스를 **양축 동일 배율**로 맞춰 중심 정렬, 높이 `clamp(winH×0.46, 300, 470)`, 상세 열면 −56px ③ `preserveAspectRatio="none"` 류 비균일 스케일은 거리 인상을 왜곡. `onLayout` 대신 `useWindowDimensions` 로 첫 프레임부터 확정 렌더. **임의**

**⑦ 통화 표기 제거** — ② `₩` 글리프 0개(주문 줄은 품목만) ③ `tabular-nums` 캐스케이드 함정은 ₩ 가 트리 안에 있을 때만 발동한다. 만남 장소 화면에 가격은 논증에 기여하지 않으므로 **함정을 피한 게 아니라 필요 없는 걸 뺐다** — `tabular-nums` 는 분 표기에 자유롭게 썼다. **다른 작품 참조**

**⑧ 지도 위 라벨 노출 정책** — ② 이름 라벨은 **공정한 후보 + 현재 선택**에만, 나머지는 숫자 알약만 ③ 5개 전부 이름을 달면 390px 에서 겹친다. "이름이 붙은 = 둘 다에게 공정한"이라는 의미까지 실려 축소가 곧 정보가 됐다. **관행 + 충돌 계산**

**⑨ 장소 고유명** — ② 실제 상호 대신 `Yeonnam 24h Mart`·`Riverside Mall`, 역·경찰서·공원 같은 공공 지명만 실명 ③ 더미 데이터에 살아있는 상표를 박는 걸 회피. 로마자 표기라 영문 전용에 저촉 안 됨(한글 0자). **관행**

**⑩ 제안 후 상태의 수명** — ② 선택·출발지·시각 중 하나라도 바뀌면 `proposed` 해제 ③ "7 PM 에 저기서 봅시다"를 보낸 뒤 10 PM 으로 바꿨는데 확정 카드가 그대로면 화면이 거짓말을 한다. 되돌리기도 파괴적 확인 없이 즉시 허용(아직 아무것도 확정되지 않았으므로). **임의**

**⑪ 다크 표면 사용처** — ② 확정 카드와 "You" 앵커 핀만 `ink` + `onInk`/`onInkMuted` ③ 토큰 주석대로 다크 위 글자는 전용 역할 토큰만. 회색 칩(`border`) 위에는 `faint`(3.76) 대신 `muted`(6.05)만 쓰도록 스타일을 갈랐다. **다른 작품 참조**

**⑫ 그랩바의 의미** — ② `Pressable`(role=button, `accessibilityState.expanded`)로 만들어 탭으로 여닫음 ③ 드래그를 구현 안 한 채 그랩바만 그리면 **없는 제스처를 약속**하게 된다. 탭 가능한 핸들은 실제 iOS 시트에도 있는 동작. **카탈로그 참조(제스처 어포던스)**
