## b — Quay

고객지원 통합 인박스(Front/Intercom/Zendesk급, 워크스페이스: Fernbank Outfitters — 아웃도어 리테일러). **커뮤니케이션 스레드형 3~4열 아키타입** — 기존 마스터-디테일(r4/a, 2열: 목록+상세)이나 이번 라운드 동료 3-페인 트레이딩 터미널(a, 레일+차트+상세)과 달리 대화가 주인공이다. 항상 동시 노출되는 열: 큐 레일(받은편지함/할당됨/긴급/대기/해결/보관, 각 미읽음 카운트 배지, 앱 셸 사이드바와 시각적으로 분리된 tint된 서브 nav) → 대화 리스트(발신자 아바타+이름+미리보기+타임스탬프, 미읽음 점+굵기 병행 표시, 검색+정렬 토글) → 메시지 스레드(고객/상담원 말풍선, 상태 세그먼트 토글, 답장 작성창 실 로컬 state) → 고객 메타 패널(태그, LTV/등급/가입일 통계, 7일 응답시간 크로스헤어 스파크라인, 정렬 가능한 이전 티켓 테이블, aria-sort). 2xl 미만에서는 메타 패널이 오버레이 드로어로, lg 미만에서는 큐 레일이 칩 스크롤러로 접히지만 lg 이상에서는 항상 3열 이상(큐+리스트+스레드, 2xl+에서 4열) 상시 표시 — 목록 클릭→우측 상세의 단순 2열로 퇴화하지 않음. 인터랙션: ① 응답시간 스파크라인 크로스헤어 툴팁(키보드 Arrow/Home/End) ② 이전 티켓 테이블 실제 정렬(aria-sort 토글) ③ 정렬 세그먼트(Newest/Unread first) ④ 대화 선택 → 리스트 하이라이트+스레드+고객 메타 3중 동기화(필수) ⑤ ⌘K 커맨드 팔레트, 추가로 큐 필터 실제 리스트 필터링·상태(Open/Pending/Resolved) 실 토글·답장 전송(로컬 state append)까지 전부 실동작. 앱 셸 사이드바(브랜드 Quay + 워크스페이스 스위처 팝오버 + Inbox/Contacts/Reports/Automations nav + 하단 유저)는 화이트+인디고 활성 필 스타일로, 인박스 내부 큐 레일은 zinc-50 틴트+좌측 액센트 바 스타일로 명확히 분리했다.
