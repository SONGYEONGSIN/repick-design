# Candidate B — Corvid: incident command board

One-line concept: a dark, emerald-accented incident-response kanban — five status columns (Reported → Triaging → Mitigating → Monitoring → Resolved) of SEV1–SEV4 production incidents, each card always showing severity, assignee, SLA countdown and a live error-rate sparkline, with a persistent "pin" driving a slim inspector strip and a fully separate ephemeral hover preview.

## Implementation summary

- **Route**: `app/src/app/dash-evolve/r30/b/page.tsx`, client tree in `dashboard-app.tsx` + `board.tsx`, `card.tsx`, `compact-list.tsx`, `inspector-strip.tsx`, `hover-preview.tsx`, `filter-bar.tsx`, `sidebar.tsx`, `topbar.tsx`, `command-palette.tsx`, `ui.tsx`, `data.ts`.
- **Domain**: Corvid, an incident-command platform for the fictional "Aurora Systems" SRE org. 24 hand-authored incidents across 8 services (Auth Gateway, Edge CDN, Search Index, Notification Fanout, Realtime Sync, Mobile API Gateway, Data Pipeline, Media Pipeline) and 6 squads, with 8 fictional assignees.
- **Determinism**: all ages/SLA figures are minutes-before-a-fixed-`ANCHOR` integers baked directly into `data.ts`; sparklines come from a pure `Math.sin`-based generator with fixed seed/base/amplitude/trend per incident, rounded to 2 decimals; org-wide totals and column aggregates are always `reduce`d from the same `INCIDENTS` array (never hand-typed), so every subtotal reconciles. No `Math.random`, `Date.now()`, or argument-less `new Date()` anywhere. A manual `formatCompact`/`formatMinutes` replace `Intl` compact notation.
- **Layout**: sidebar + topbar shell; page header with an inline stat strip (open/SEV1/breaching/avg-resolve, derived from data); filter/sort/view control row; a slim always-visible Inspector strip; then the board itself as the dominant element. At `xl:` (1280px+) the shell locks to `h-dvh`/`overflow-hidden` and the board fills the remaining height via a flex chain, with each column independently `max-h`/`overflow-y-auto` (CSS Grid, not `overflow-x-auto`, for the track) — below `xl` everything reverts to normal document scroll with per-column caps.
- **Interactions (5)**: (1) keyboard- and pointer-reachable sparkline crosshair (focus/hover/arrow-keys scrub a 7-point trend, inline numeric readout, no floating tooltip); (2) severity filter chips + "Breaching SLA" chip + a three-way sort (SLA / Age / Severity) with direction toggle, driving both the board's per-column order and the compact list's row order through one shared `compareIncidents` comparator; (3) Board/Compact-list view toggle swapping the dominant layout between the kanban grid and a real sortable `<table>` (caption, scope, `aria-sort`); (4) pin vs. hover split — clicking a card sets a persistent `pinnedId` that drives only the narrow Inspector strip, while hovering/focusing any card sets an ephemeral `hovered` state guarded by `hoveredId !== pinnedId`, rendered as a `position: fixed` popover computed from a measured `DOMRect` (so it's never clipped by a scrolled column) and marked `aria-hidden` because the same copy is already exposed to assistive tech via each card's `aria-describedby`; (5) ⌘K command palette searching incidents by title/service/squad/owner, selecting one clears filters, force-switches to board view and smooth-scrolls the card into view.
- **Theme/typography**: dark (zinc-950/900, `white/10` borders, zinc-50 primary, zinc-400 secondary floor), single emerald accent used sparingly (brand, focus ring, "on-track"/"met" SLA state); severity and SLA states get their own semantic hues (red/orange/amber) independent of the brand accent. No display face — `--font-sans` everywhere. Exactly 3 rendered weights (`font-normal` default, `font-medium`, `font-semibold`); every native-bold element (`<th>`) is explicitly reset to the chosen weight.
- **Completeness**: sortable table, tabs-like segmented controls, badges, a slim inspector "card", generative SVG sparklines (no chart library), 44px-tall uniform topbar controls, single `h1` with `h2`s for the inspector and each column, semantic `<dl>`-free stat blocks, skip link, and a rewritten two-line `SlaPill` specifically to survive truncation at the ~186px column width the board hits at 1280px.

## What wasn't in the brief

- I dropped the initially-planned embedded sparkline inside the Inspector strip to keep it genuinely "narrow" per the brief's own caution against a rail/detail-style widget — it's text/badge-only.
- I added a `resolvedTodayCount` to `TOTALS` that the UI doesn't currently surface (kept for future use / reconciliation transparency) rather than deleting it.
- The brief's crosshair/tooltip interaction was written as a floating tooltip in my head first; I replaced it with an inline numeric readout (no overlay) specifically to avoid any clipping risk from the per-column `overflow-y-auto`, and reserved the one `position: fixed` overlay in the whole page for the hover-preview popover, which needed it because it's genuinely anchored to an arbitrary, possibly-scrolled card.
- I pre-pin one incident (`inc-111`, a breached SEV1) by default on load, purely so the Inspector strip and the "breached" visual state are visible at first paint without requiring an interaction — not specified either way in the brief.
