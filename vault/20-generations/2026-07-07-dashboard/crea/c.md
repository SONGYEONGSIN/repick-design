# Dashboard · 창의 c — 취향 지도 (Taste Constellation Dashboard)

**컨셉**: 로그인 후 대시보드를 상품 "리스트"가 아니라 사용자의 취향을 나타내는 **밤하늘 별자리 지도**로 재구성했다. 화면 중앙에 "나" 노드가 있고, 그 주위로 취향 카테고리(미니멀·빈티지·스트리트·아웃도어·홈리빙·클래식) 노드가 취향 강도(가중치)만큼 크기가 커진 별로 떠 있으며, AI가 매칭한 실제 매물은 해당 카테고리 근처 좌표에 반짝이는 별(✦)로 배치된다 — SVG 라인이 중심→카테고리→상품을 성좌처럼 연결한다. 리스트를 스크롤하며 "훑어보는" 대신, 지도를 "탐색"하며 내 취향의 모양을 공간적으로 발견하게 만드는 것이 핵심 발상이다.

**인터랙션**: 별(상품)을 클릭하면 지도 하단 패널에 가격·매칭률 프로그레스 바·찜하기/보러가기 CTA가 뜬다. 중심의 "나" 별을 클릭하면 선택이 초기화된다. 지도 아래 "오늘의 AI 추천" 가로 스크롤 카드 목록은 매칭률 순으로 동일 데이터를 리스트 형태로도 제공해, 지도(탐색)와 리스트(스캔) 두 소비 방식을 동시에 지원한다 — 브리프의 "상품 리스트" 요구도 충족.

**실전성**: 좌측 내비(홈/추천/찜/설정), 상단 요약 스탯 4개(오늘의 추천/찜/절약액/매칭률), 우측 최근 활동/알림 사이드바 등 대시보드에 요구되는 정보 구조는 모두 유지하되, 메인 콘텐츠 영역만 지도 은유로 재구성했다. 모든 별·노드 좌표는 고정 상수(hydration-safe), 애니메이션은 Tailwind 내장 `animate-pulse`/`animate-ping` + `motion-safe:` 접두사로 reduced-motion을 존중한다. 외부 이미지/폰트 없이 CSS·SVG·이모지만으로 오프라인 렌더된다.
