# Dashboard · 창의 f — 게임 진행형 대시보드

**컨셉**: 로그인 후 대시보드를 "오늘의 쇼핑"이 아니라 "오늘의 던전 공략"으로 재구성했다. 화면 최상단은 레벨(Lv.7 빈티지 헌터)·XP 게이지(340/500)·7일 스트릭 트래커로 이루어진 히어로 패널이 차지하고, 브리프의 4개 요약 스탯(오늘의 추천/찜/절약액/매칭률)은 각각 "오늘의 퀘스트 수"·"수집함"·"절약 골드(목표 게이지 포함)"·"감정 스탯"으로 재명명해 게임 UI 문법으로 번역했다. 메인 영역은 진행률 바 + XP 보상 태그가 붙은 "이번 주 퀘스트" 목록(완료 시 실제로 클릭해 보상을 수령하는 인터랙션 포함)과, 레어도 등급(일반/레어/에픽)이 매겨진 "오늘 발견한 아이템" AI 추천 리스트로 구성된다. 사이드바는 잠금/해금 상태가 시각적으로 구분되는 배지 컬렉션과 XP 획득 이력이 쌓이는 "퀘스트 로그"(최근 활동)로 브리프의 사이드 영역 요구를 대체했다. 찜하기·퀘스트 보상 수령 시 실제로 상태가 바뀌고 토스트로 XP 획득이 피드백되어, 장식이 아니라 실제 동작하는 게이미피케이션 대시보드로 완성했다. 좌측 네비(홈/추천/찜/설정)는 데스크톱 사이드바 + 모바일 하단 탭바로 반응형 대응했다.
