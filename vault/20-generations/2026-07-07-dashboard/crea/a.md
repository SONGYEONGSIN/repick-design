# Dashboard · 창의 모드 · 후보 a

## 컨셉: 아침 브리핑 대시보드 (각주형 내러티브)

로그인 직후 화면을 "스탯 카드 나열"이 아니라 **개인 비서의 브리핑 한 문단**으로 재구성했다.
접속 시 짧은 로딩(스켈레톤 펄스)을 거쳐 "좋은 아침이에요, 민준님"과 함께 밤사이 있었던 일을
하나의 서술형 문장으로 들려준다 — "밤사이 매물이 3건 들어왔고, 그중 자켓은 12% 내려갔고,
찜한 테이블은 오늘 자정에 마감돼요." 문장 속 숫자는 논문 각주처럼 위첨자 마커(¹²³)로
표시되며, 클릭하면 아래 "브리핑 근거" 섹션의 해당 카드로 스크롤 + 하이라이트된다.
즉 대시보드가 주장(브리핑)과 근거(추천 리스트·가격 하락 상세·마감 임박 카드)를 각주로
연결하는 구조 — 데이터를 먼저 던지고 사용자가 해석하게 하는 대신, 이야기를 먼저 들려주고
"왜 그런지" 확인하고 싶을 때만 파고들 수 있게 한다. 요약 지표 4개(매칭/확인/절약액/매칭률)는
브리핑 카드 하단에 조용한 서브라인으로, 오른쪽 컬럼엔 최근 활동 타임라인을 배치했다.
좌측(데스크톱)/하단(모바일) 내비게이션은 실제 로그인 앱처럼 홈·추천·찜·설정 4탭 구조.
