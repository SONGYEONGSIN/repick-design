# Dashboard · div · f — 신문 1면 대시보드

**컨셉**: 로그인 후 대시보드를 조간신문 1면처럼 편집한다. 세리프 마스트헤드 "THE
REPICK TIMES"가 유일한 h1로 자리하고, 상단 유틸리티 바(호수·날짜·조간 표기), 좌우
귀퉁이 박스(오늘의 리픽 지수 / 사용자 인사 + Pro 구독 도장), 스탯 4개를 증권 시세표
형태의 티커 바로, 좌측 사이드바를 신문 지면 목차(로마 숫자 I~IV, 홈/추천/찜/설정)로,
"오늘의 AI 추천" 상품 리스트를 톱기사 + 드롭캡 리드문 + 후속 기사(halftone 사진
placeholder, 특종/속보 스탬프, 매칭률 바이라인)로 배치했다. 우측 사이드바는 속보
티커(최근 활동), 사설 박스(AI 학습 업데이트 안내), 점선 테두리의 구독 광고 박스로
구성. 이중선(border-double)과 실선 규칙, 점선 구분선으로 지면감을 강화하고 오프라인
렌더를 위해 시스템 세리프 스택과 CSS radial-gradient 하프톤만 사용했다.
