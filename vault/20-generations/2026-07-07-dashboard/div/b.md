# Dashboard · div · b — Neumorphism (Soft UI)

단일 배경색(#e5e9f0)에서 모든 요소를 이중 그림자(inset+drop)로 "조각"해 만든 촉각적 대시보드. 카드·아이콘 배지·네비 아이템·매칭률 게이지까지 전부 같은 표면 재질로 통일하고, 눌림(inset) 상태로 "현재 위치·활성 상태"를 표현한다(좌측 네비 활성 항목, 찜 버튼 눌림). 컬러는 바이올렛(#4b3fe0, AI/매칭)과 민트그린(#1f7a52, 검증/절약) 두 액센트만 최소 사용해 단조로운 그레이 표면 위에서 정보 위계를 잡았다. 좌측 전체 네비(홈/추천/찜/설정)는 모바일에서 상단 알약형 아이콘 바로 전환. 스탯 카드 4개(오늘의 추천/찜/절약액/AI 매칭률) 중 마지막은 conic-gradient 기반 순수 CSS 게이지로 표현. 콘텐츠는 실제 리커머스 매물(나이키·샤넬·캐논·아이폰)로 채워 목업이 아닌 실사용 화면처럼 구성했다.
