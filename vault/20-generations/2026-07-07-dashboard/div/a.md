# Dashboard — 발산 a — 브루탈 데이터

**아키타입**: 브루탈 데이터 (raw data terminal)

블룸버그/트레이더 터미널을 리커머스 대시보드에 이식했다. 검은 배경, Geist Mono 전면 사용, 굵은(2px) 화이트 보더로 모든 셀을 구획하고, 단 하나의 시그널 컬러(#d9ff3f, 산성 라임)로만 강조 표시(절약액·매칭률·활성 네비·긍정 델타·태그)한다. 상단에는 CSS-only 무한 스크롤 티커 테이프가 가격 변동/매칭 이벤트를 실시간 시세처럼 흘려보내고, 좌측 네비는 `01 홈 / 02 AI 추천 / 03 찜 / 04 설정`처럼 넘버링된 커맨드 목록으로 표현했다. 메인은 카드 그리드 대신 "오늘의 AI 추천"을 조밀한 원장(元帳) 스타일 표 — 순위/상품/카테고리/정가(취소선)/판매가/절약/매칭률 바(bar)/상태 태그 — 로 압축했고, 우측은 타임스탬프 로그 형태의 "최근 활동" 피드로 장식 없이 정보 밀도를 극대화했다. 하단엔 시스템 상태 바(SYSTEM ONLINE · SCAN 건수 · LAST SYNC · UPTIME)를 배치해 살아있는 터미널처럼 마무리했다. 반응형은 375px에서 좌측 네비가 상단 가로 네비로, 표는 가로 스크롤되는 구조로 전환된다.
