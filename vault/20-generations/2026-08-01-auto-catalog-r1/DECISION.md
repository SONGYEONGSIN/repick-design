# DECISION — auto-catalog-r1

타깃: `catalog` (카탈로그 미충족 타입 우선 추첨 — 신규 타입 라운드 1회차)
후보: a — Loopwire(좌 필터 레일+그리드, dark, emerald, `--font-display-grotesk`) · b — Overlook(상단 필터바+매거진 그리드, dark, amber, `--font-display-wide`) · c — Fathom(분할 탐색, light, rose, `--font-display-mono`)
전 후보 하드게이트 생존(SCORES.md 참조 — c는 1차 a11y 94(color-contrast 2건 + landmark-one-main 부재) → `text-emerald-700`/`text-orange-700`로 색 교체 + 결과영역을 `<main>`으로 승격, 재게이트 100). judge는 general-purpose 에이전트 3개 병렬 파견, 렌즈별 근거 분리 — 원문 발췌.

## 렌즈 1 — 프로파일 준수 (brief-catalog §1·§2, page-brief-core)

랭킹: **a > b > c**

- **a (Loopwire)**: §1/§2 최다 충족 — 필터 레일에 후보별 실시간 facet count(필터 배제 계산 포함), 칩 전부 개별 해제 가능 + `sr-only` 라벨, 무필터 시 "No filters applied" 명시(숨은 상태 없음), 빈 상태 2클릭 도달 + Clear-all. 감점: `lg` 미만에서 결과 수·칩 행이 sticky가 아니라 스크롤 시 어떤 필터가 적용됐는지 화면 밖으로 나감(§2 "화면만 보고 알 수 있어야" 부분 위반).
- **b (Overlook)**: a의 그 감점 지점을 정확히 보완 — 카운트·칩이 sticky 바 안에 상시 체류. 결함: 390px에서 sticky 바가 뷰포트의 약 45%를 항상 점유, `bg-zinc-950/95`가 반투명이라 카드 텍스트가 비쳐 보임(1280/390 다수 프레임), `data.ts` 확인 결과 2필터 조합만으로는 빈 결과 경로가 없음(3필터 조합 필요 — §1.5 빈 상태 재현성 약함), 매거진 표준 카드는 dek 생략.
- **c (Fathom)**: 필터 가시성 구조 자체는 가장 강함(비스크롤 헤더에 칩 상주) + 행 밀도 최고(8개 필드)지만 **실측 규칙 위반**: `preview-pane.tsx:123` `font-bold` + `font-semibold`/`font-medium` + 미지정 기본 400 텍스트(`page.tsx:142,183`)로 라우트 내 **렌더 웨이트 4종**(page-brief-core §4 "정확히 3종" 위반). 단 이 규칙은 `curation-criteria` Q13 판정에 따라 **하드페일이 아니라 기록 전용**(gate.mjs `weights` 게이트가 명시적 유틸리티 클래스만 세어 3종으로 통과시킨 것과 별개로, 실제 렌더 웨이트는 4종 — 정책상 하드페일 미적용이라 탈락 사유는 아님, 다음 정제 게이트 항목으로 별도 기록).

## 렌즈 2 — 상용 완성도 (Airbnb·Linear 이슈목록·커머스 검색급)

랭킹: **a > c > b**

- **a**: 전 스윕에서 밀도 유지(1920 4열→1440 3열→390 1열), 카드가 카테고리·verified·이름·dek·가격·installs·rating을 tabular-nums로 전부 표기, 이미지 파손(unsplash 프록시 차단, 환경 제약)에도 `aspect-square`+예약 배경으로 레이아웃 완전 유지, 배지는 사진과 분리된 행. 모션은 정보성(sticky 헤더 압축, 8개 상한 스태거)이며 `motion-reduce` 게이팅.
- **c**: 행 크래프트는 셋 중 최고(아이콘+텍스트 병행, 장식 모션 0)지만 **치명적 마감 결함**: `preview-pane.tsx`의 루트가 `w-full`/`flex-1` 없이 `max-w-2xl`로 수축돼 1440px에서 ~570px, **1920px에서 뷰포트 우측 절반 이상(~1000px)이 빈 백색**으로 남음 — §1.1 "결과 그리드가 화면의 주인공" 자체가 흔들림.
- **b**: 타입의 절제선을 랜딩 쪽으로 넘음 — 1920 히어로가 화면 절반을 비움, 390에서 첫 결과가 폴드 아래로 밀림(§5 "스크롤 없이 초기 화면만 봐도 가치 전달" 위반 근접). 매거진 변형이 밀도 대신 빈 공간(`mt-auto` 스트레치로 ~250px 홀)을 만들고 마지막 행이 8/24만 채워짐.

## 렌즈 3 — 아키타입 차별성

랭킹: **c > a > b**

- **c**: 입력축(선택→우측 페인 갱신)·출력축(뷰포트락 리스트+페인) 둘 다 나머지와 가장 멀리 떨어짐 — 문서 스크롤이 아예 없는 유일한 구조.
- **a**: 지정 아키타입(좌 레일+그리드)을 교과서적으로 실현, 상세는 모달 오버레이라 c의 상주 페인과 겹치지 않음.
- **b**: 지정 아키타입(상단 바+매거진)을 실현했으나 a와 출력축(문서 스크롤 카드 그리드+load-more) 공유 — 입력축(상주 260px 레일 vs 상단 바)과 그리드 균등성 차이로 재탕은 아니나 차별성 폭이 셋 중 가장 얕음.

## 집계

1위 표: a(렌즈1, 렌즈2) 2표 vs c(렌즈3) 1표 → **다수결 승자: a (Loopwire — 좌 필터 레일+그리드)**.
차별성(렌즈3 c 1위)과 완성도(렌즈1·2 a 1위)가 상충하는 구도로, [[curation-criteria]] "차별성 ↔ 완성도 상충 시 판정 방향"(2026-07-31, landing r2/r3·login r1에서 재현된 L3 원칙 — 완성도 다수결 우선)이 이번에 타깃을 하나 더 넘겨 재현됐다. c는 렌즈1·렌즈2 양쪽에서 독립적으로 같은 결함(프리뷰 페인이 컬럼을 채우지 못해 1920에서 대형 백색 공백)을 지적받아 신뢰도가 높다.
