# a — Loopwire (commerce)

Loopwire is a workflow-automation platform's integrations marketplace on a true zinc-950/900 dark canvas with an emerald accent, its wordmark and h1 set in Space Grotesk Display. The layout is the classic left filter rail (category checkboxes with live facet counts, pricing checkboxes, minimum-rating pills, a verified-only switch) beside a dense result grid of 27 deterministic integrations, each card carrying a photo, category + status badge, price, install count, and star rating. Interactions: filter apply/remove with an always-visible removable-chip row and "Clear all," a sort select showing its current value (Most installed/Highest rated/Newest/Name A–Z), a grid/list view toggle, live result-count updates, and card-select into a right-side detail drawer with an install-toggle CTA — plus "Load 9 more" pagination and a zero-result empty state. A sticky header compresses on scroll and cards stagger in on mount, both fully settled under `prefers-reduced-motion`.
