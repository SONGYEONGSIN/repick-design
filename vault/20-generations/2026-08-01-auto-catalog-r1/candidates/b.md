# b — Overlook (editorial)

Overlook is an independent research-and-culture dispatch archive on a true zinc-950/900 dark canvas with an amber accent, set in Archivo Display for the masthead. The layout is a top filter bar (topic toggle chips, access segmented control, format select) over a magazine grid with a single hero card, periodic wide cards, and standard cards — column-span and image-aspect variation only, never row-span, to keep it overflow-safe at every width. Interactions: multi-topic filter apply/remove with a removable-pill summary row, a sort select showing its current value (Newest/Most read/Longest/Shortest), a grid/list view toggle, a live `aria-live` result count, and "Load more" pagination; an empty state clears every filter in one click. Distinct from a market/commerce read by staying editorial (reading-time and read-count metrics instead of price) and by picking amber over the catalogue's crowded violet and typical e-commerce hues.
