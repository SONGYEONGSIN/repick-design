# Candidate c — Referral Program

A read-only record screen showing the user's standing invite link/code, two derived stat tiles (friends joined, credits earned), and a fixed `FlatList` of five past referrals each with a join date, status chip (Credited/Pending), and per-referral credit amount. Per GENERATION.md §3 this is a finished-record screen with no blocked step, so it uses a persistent bottom action bar (not a blocked/ready/done state machine) whose single real action is "Share Invite Link," wired to React Native's built-in `Share.share()` (no clipboard package is installed, and nothing new was installed — `Share` is a core RN export). The bar's confirmation sentence only flips to success on an awaited `Share.sharedAction` result; a dismissed share sheet or a thrown error reports its own honest, distinct sentence instead of faking success, all inside one `accessibilityLiveRegion="polite"` container with the transition itself carrying `accessibilityRole="alert"`. The summary stats (`friendsJoinedCount`, `creditedTotal`, `pendingCount`) are all reduced/filtered from the same `referralEntries` array the list renders, and a referral's credit only counts toward the total once its status is `"credited"` — a pending referral's amount is excluded until it flips, so the headline numbers can't drift out of sync with the list underneath them.
