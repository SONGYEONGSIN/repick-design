# Candidate a — Saved Addresses

A buyer's saved-shipping-addresses list (Home, Work, Mom's House, Lake Cabin) rendered via a real `FlatList`, each row showing recipient/street/city/zip and a "Default" badge for the one address currently marked default. Tapping "Set as default" on any other row moves that badge via a real `defaultAddressId` state transition (never more than one at a time); tapping "Delete" flips that row's own surface — not a band, not a modal, not a system `Alert` — into a Cancel/Confirm pair inside an `accessibilityLiveRegion="polite"` container, where the confirmation sentence itself carries `accessibilityRole="alert"` and Confirm actually filters the address out of state. There is no screen-level band: every confirmation is local to its row, satisfying the per-row destructive-confirm generalization in GENERATION.md §3-4 without reusing any band/session-screen style-key names, and a `ListEmptyComponent` covers the all-deleted edge case with a real message instead of a blank screen.
