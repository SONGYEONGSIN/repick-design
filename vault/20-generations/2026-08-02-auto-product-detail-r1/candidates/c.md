## Candidate C — `product-detail-evolve/r1/c`

**Torvex** (fictional industrial motion-control brand) — SKU detail page for the **LA-640 series**, a 24V precision linear actuator sold across five stroke-length configurations to automation integrators. Macro-skeleton: a **master-detail layout with a persistent configuration rail**, not a hero-image/buy-box split — a narrow left rail (vertical + sticky on desktop, a locally-scrollable horizontal strip on mobile) lists all five SKUs with their stroke, price and selection state always visible, driving a dense right-hand "engineering datasheet" whose always-visible summary band (`h1`, price, quick-spec strip, lead time, primary CTA) sits above a four-tab data sheet (Specifications / Documentation / Compatibility / Reviews). Five live, informational interactions: (1) the variant rail itself — selecting a configuration live-recomputes price, the quick-spec strip, the media-gallery alt text and the documentation filenames; (2) a compact media gallery (photo / dimensional drawing / in-application) with focusable thumbnail navigation swapping the main image; (3) native `<details>` accordion groups (Mechanical / Electrical / Environmental / Certifications) inside the Specifications tab, each a semantic `<table>` with `caption`/`scope`; (4) a "Compare configurations" switch that adds a second SKU's column to every spec table with arrow+delta diff badges (icon + text, never color alone); (5) a Reviews panel with a five-way star filter and a helpful/recent/rating sort over an `aria-live`-announced result count, plus a rating-distribution bar list. A bonus IntersectionObserver-driven condensed order bar appears only once the always-visible summary scrolls out of view, echoing the same SKU/price/CTA rather than gating them. Light theme, neutral zinc scale with a single AA-safe **blue** accent (`blue-600`/`blue-700`, chosen over gold/orange after the other two blind candidates both landed on warm gold-family accents), `--font-display-mono` on the wordmark/`h1` (the round's least-used allowed display face, fitting the engineering-datasheet register), exactly three Tailwind weight classes (`font-normal`/`font-medium`/`font-semibold`) route-wide.
