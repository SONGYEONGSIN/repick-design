# DECISION — auto-product-detail-r1

타깃: `product-detail` (신규 · 프로파일 부재 — [[page-brief-core]] §"타입 프로파일 목록" 규정대로 코어만으로 생성. 이 라운드의 승자 사유가 향후 `brief-product-detail.md` 초안의 씨앗이 된다.)

## 후보
- **a — Fernway**: P2P 정품 인증 리세일 마켓플레이스, 스니커 리스팅 상세. 히어로 미디어 + 수평 "인스트루먼테이션 레저"(사이즈 선택 즉시 가격/컨디션/호가수 재계산) + 수평 탭 스트립.
- **b — Fenwick Audio**: USB-C 오디오 인터페이스 SKU 페이지. 상시노출 오버뷰 밴드 + 풀블리드 세로 내러티브(갤러리→스펙→비교→리뷰) + 데스크톱 스크롤스파이 레일. 원격 이미지 없이 결정론적 인라인 SVG 스펙 다이어그램.
- **c — Torvex**: 산업용 리니어 액추에이터 B2B 카탈로그 상세. 좌측 상시 노출 컨피규레이션 레일(마스터-디테일)이 곧 변형 선택 UI, 우측 엔지니어링 데이터시트.

## 하드게이트
- a: 전 항목 1차 통과 (a11y 100, perf 66)
- b: 전 항목 1차 통과 (a11y 96, perf 69)
- c: **1차 a11y 94 (하드페일)** → 1-fix 루프 적용, 재게이트 전 항목 통과 (a11y 100, perf 70). 상세는 SCORES.md "1-fix 루프" 절.

## JUDGE 패널 (3렌즈, 블라인드 — X/Y/Z=a/b/c)

### 렌즈1 — page-brief-core 준수
1위 b · 2위 a · 3위 c. b: 단일 h1 계층·상시 스크롤 추적 sticky nav·색만이 아닌 병행 신호·tabular-nums 일관, 4단계 스크롤 전 구간 무결점. a: 1280px에서 "Lowest ask / Condition / Asks-ships" 3열 통계 행이 CTA 버튼과 flex 공간을 다투며 줄바꿈 — 1920px로도 안 고쳐짐(전용 폭 미확보). c: sticky 주문바(backdrop-blur)에서 스크롤로 지나간 버튼 고스트가 비쳐 보임(`c-1280-s100.png`). 셋 다 실격 사유는 아님 — 상대적 craft 결함.

### 렌즈2 — 상용 완성도
1위 b · 2위 c · 3위 a. b: 가격/CTA가 sticky헤더+히어로 이중 상시노출, 컨피규레이터가 실제 가격을 라이브 재계산, 첫 스펙 아코디언 사전 오픈, 리뷰가 구체적이고 신뢰감 있음. c: 가격/스펙스트립/이중 CTA("견적 담기"+"엔지니어 상담")가 B2B 맥락에 정확히 맞는 상용 패턴, 다만 하단 디스클레이머 문구가 몰입을 다소 깬다. a: 사이즈 선택 재계산은 진짜 기능이지만 통계 행 줄바꿈 결함 + 인증 신뢰 메시지가 헤더·푸터에 거의 동일 반복되어 필러처럼 읽힘. 셋 다 no-winner 사유 아님(전원 상시노출 원칙 충족).

### 렌즈3 — 아키타입 차별성
1위 b · 2위 c · 3위 a. b: 히어로/바이박스 관행을 완전히 벗어나 단일컬럼 롱폼 + 앵커 TOC 레일 — 진짜 다른 인터랙션 모델. c: 좌측 컨피규레이션 마스터 리스트가 3번째 컬럼이자 변형 선택 UI 자체 — 구조적으로 다름(단 우측 조직은 a와 부분 유사). a: 히어로-좌/바이박스-우의 교과서적 관행 자체 — 구조적 이탈 없음. **유사성 플래그**: a와 c가 우측 콘텐츠 조직(이미지 인접 바이박스+수평 탭)에서 부분 수렴하나, c의 좌측 컨피규레이션 마스터리스트가 변형 선택의 1차 인터랙션 자체를 바꿔 완전 중복은 아님.

## 정제 조치 (§3-1)
c의 spec `<dl>`에서 아이콘이 `dt`/`dd`를 감싸는 wrapper `<div>` 안에 한 겹 더 중첩되어(`dl > div > div > dt/dd`) axe `definition-list`/`dlitem` 규칙 위반(a11y 94). 아이콘을 `dt` 안으로 이동해 `dl > div > (dt, dd)`로 평탄화, 시각 정렬은 `pl-[22px]`로 유지. 기능·시각 변화 없이 마크업 구조만 수정 — 취향/완성도 개선 아님. 재게이트 전 항목 통과, 순위 재계산 없음(a11y 결함은 애초 세 렌즈 중 어느 것도 순위 근거로 인용하지 않음).
