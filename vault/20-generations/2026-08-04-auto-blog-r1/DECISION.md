# DECISION — auto-blog-r1

타깃: `blog` (신규 · 프로파일 부재 — [[page-brief-core]] §"타입 프로파일 목록" 규정대로 코어만으로 생성. `blog-deltas-provisional.jsonl`이 이 라운드에서 처음 생성되며, 여기서 나온 delta가 향후 `blog` 프로파일의 초안이 된다.)

다양성 축: 직전 라운드(`auto-profile-r1`)가 dark/amber/mono를 썼으나 이번 라운드는 `catalog-variety.mjs` banList가 공란(직전 3라운드 테마가 dark→light→light로 2연속 동일이 아님, 액센트·활자도 반복 없음) — 강제 회피 축 없이 3후보에 서로 다른 테마·액센트·활자를 자유 배정: a=light warm-paper/rust/wide, b=light zinc/teal/mono, c=light stone/orange/wide. (세 후보 모두 라이트를 택해 카탈로그 전체 라이트 편중을 다시 키운 점은 다음 라운드 배정 시 참고 대상.)

## 후보
- **a — Northbeam**: B2B 어트리뷰션/파이프라인 애널리틱스 SaaS의 공개 블로그 인덱스. 상시노출 피처드 포스트 히어로 + 카테고리 필터/검색/정렬이 구동하는 3열 카드 그리드. 커버 아트·아바타 전부 결정론적 인라인 SVG(원격 이미지 완전 미사용). 검색·카테고리·정렬·더보기 4개 인터랙션, 전부 단일 `useMemo` 파이프라인에서 파생돼 "Showing N of M" 카운트가 항상 정확.
- **b — Stackrail**: 워크플로 오케스트레이션 SaaS의 엔지니어링 블로그. 좌 sticky 카테고리 레일(+구독 모듈) + 밀도형 텍스트 중심 리스트(카드 그리드 아님 — a·기존 catalog와 구조적으로 차별화 의도). 카테고리 필터·검색·정렬·행별 접기/펼치기·뉴스레터 폼 5개 인터랙션. 아바타도 결정론적 SVG 모노그램.
- **c — Loupe / The Loupe Journal**: 크리에이티브 리뷰 협업 툴의 저널. 월별로 그룹화되고 4종 카드 템플릿(대형 이미지/풀쿼트/소형 이미지/텍스트만)이 교차하는 에디토리얼 타임라인 + 최다열독 사이드바(주간/월간 스코프 토글)+뉴스레터 폼. 태그 필터·더보기·최다열독 스코프 토글·뉴스레터 검증 4개 인터랙션. 포스트 이미지는 picsum.photos 원격 호스트 사용.

## JUDGE 패널 (3렌즈, 블라인드)

### 렌즈1 — page-brief-core 준수 + 견고성
1위 a · 2위 b · 3위 c. a·b 둘 다 결함 없음(랜드마크·헤딩·`focus-visible`·`tabular-nums`·웨이트 3종 전부 정확) — a는 완결성에서 근소 우위(히어로+그리드 구성이 더 정제됨), b는 22개 글을 페이지네이션 없이 한 번에 렌더해 "정보 노출 제어" 인터랙션이 하나 적음. **c — 실질 결함**: `timeline.tsx`가 전 포스트 이미지를 `picsum.photos` 원격 호스트에서 로드하는데, 이 세션 환경에서 로드가 전부 실패해 데스크톱은 깨진 이미지 아이콘의 빈 회색 박스, 모바일 390px 소형 썸네일(96px)에서는 alt 텍스트("A hand holding a phone displaying a design")가 고정 컨테이너를 넘어 옆 헤드라인 텍스트로 번짐 — page-brief-core §4가 정확히 막으려던 실패 모드(고정 aspect-ratio 컨테이너가 "박스 크기"는 지켰으나 "내용 클리핑"은 못 함)이며, a 자신의 코드 주석이 이미 이 정확한 패턴을 카탈로그의 기존 회귀 사례(`catalog/brand-tile.tsx`, `profile-evolve/r1/a/listing-art.tsx`)로 인용하고 있었다 — c는 그 경고를 반영하지 못함. 3후보 공통(비차별) 관찰: 전원이 모바일에서 `hidden md:flex`/`hidden sm:flex`로 주 내비를 숨기면서 햄버거 메뉴 등 대체 접근 경로가 없어 키보드/터치로 도달 불가 — 순위엔 비차별이라 영향 없으나 기록.

### 렌즈2 — 상용 완성도
1위 a · 2위 b · 3위 c. a: 피처드 포스트가 무조건부 상시노출, "Showing N of M"·"Load N more" 라벨이 전부 동일한 `filtered`→`sorted`→`visible` 파생 체인에서 나와 불일치 불가능. b: 카테고리 카운트·총계가 전부 `.reduce`/`.length` 파생, 접기/펼치기가 진짜 클릭 기반 `aria-expanded`(hover 아님), 뉴스레터 폼에 정규식 검증+성공/에러 `role` 분리. **c — 렌즈1과 동일 결함을 재확인**: picsum 로드 실패가 전 스크린샷(데스크톱·모바일, 전 스크롤 깊이)에서 재현되는 구체적·재현 가능한 완성도 결함으로 3위 사유 — 월간/주간 스코프 토글이 달린 최다열독 위젯과 폼→확인패널 전환이 세 후보 중 가장 정교한 뉴스레터 UX였음에도 이 결함이 상쇄.

### 렌즈3 — 아키타입 차별성
1위 c · 2위 b · 3위 a. c: 월별 그룹+4종 교차 템플릿 타임라인(우 사이드바는 보조, 좌 레일 없음)은 기존 카탈로그 어디에도 없는 시간축 그룹핑+시각 리듬 조합 — a의 히어로+그리드, b의 좌레일+리스트, 기존 catalog·profile-b의 셸과도 수렴하지 않는 가장 신규 어휘. b: 좌 sticky 레일+우 콘텐츠 셸 자체는 `catalog`와 직전 라운드 `profile-r1`의 승자 b(사이드바+위젯) 셸과 구조적으로 유사 — 콘텐츠(텍스트 리스트)는 신규지만 골격은 이식(Q15 사례로 명시 인용). a: 필터→카드그리드 조합은 `catalog`(Loopwire)가 이미 확립한 입력×출력 조합의 재사용 — 가장 관행적인 "기본값" 블로그 템플릿.

## 집계
1위 표: a 2표(렌즈1·렌즈2) · c 1표(렌즈3) → **다수결 성립, tie-break 불요**. 렌즈3이 c의 골격을 가장 신규로 평가했음에도, 렌즈1·렌즈2가 c에서 동일한 구체적 결함(picsum 로드 실패로 인한 alt 텍스트 오버플로)을 독립적으로 재확인해 완성도 축에서 a를 앞세웠다 — [[curation-criteria]] "차별성 ↔ 완성도 상충 시 판정 방향"과 정합.
