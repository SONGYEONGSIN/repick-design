## 1-fix pass (one attempt each, dispatched to the same candidate's own designer agent with exact pre-diagnosed violations, per §3)

- **a**: removed the fixed `min-w-[860px]`+`overflow-x-auto` scroll wrapper entirely, made the Gantt row fully fluid (already percentage-positioned) down to <768px with no forced scrollbar. Changed bar-label `opacity-90` → full-opacity `text-zinc-50`. Dropped the custom `aria-label` on booking buttons; visible text (carrier + time) now IS the accessible name, extra detail (door/cargo/status) moved to an appended `sr-only` span.
- **b**: found the real `div#10` root cause via direct element enumeration — a `w-px` axis gridline at the 100%-scale tick extended 1px past the track edge; anchored it with `right:0` instead of `left:100%`. Changed the shared `Label` component (used only in the two flagged `<dl>`s) from `<span>` to `<dt>`. Enlarged percentile-handle hit buttons from 12×(28/56)px to `h-6 w-6 min-h-6 min-w-6` (24×24), keeping the visible tick thin via a separate `aria-hidden` decorative layer; alternated adjacent handles between `top-0`/`bottom-0` anchoring to reduce hit-box collision.
- **c**: changed the search-trigger's label/kbd-hint spans from `hidden sm:inline` to `sr-only sm:not-sr-only` so they stay in the accessibility tree below 640px. Kept `bg-lime-600`, switched Export button text from `text-white` to `text-zinc-950` (verified ≈6.5:1 by hand). Enlarged slope-chart endpoint-dot buttons from 12×12px to a 24×24px hit area (visible dot unchanged, centered inside via an `aria-hidden` inner span).
